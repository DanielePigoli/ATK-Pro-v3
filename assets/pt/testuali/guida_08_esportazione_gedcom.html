📌 Visão geral

O módulo Exportação GEDCOM da v3 é um ambiente de análise genealógica assistida: recebe textos, imagens ou documentos selecionados, utiliza um provedor de IA configurado no ATK-Pro e gera um arquivo .ged com dois arquivos CSV auxiliares.

É aberto pelo menu Serviços → Exportação GEDCOM. O nome público continua associado ao formato GEDCOM, mas o trabalho efetivo também inclui extração genealógica, uso de notas paleográficas, eventual ampliação de uma base existente e gerenciamento das chaves de IA.

O resultado deve ser verificado antes de ser importado para um software de genealogia: a IA pode ajudar a estruturar dados e relações, mas não substitui a leitura crítica das fontes.

🖥️ Interface

1. Método e entrada universal

A primeira seção permite escolher uma indicação de método e os arquivos a serem analisados. As opções Auto-Discovery, Vision IA e Refinery LLM são armazenadas como preferência, mas, na versão atual, não ativam três pipelines distintos: o processamento efetivo depende principalmente do tipo de arquivo.

  • TXT e DOCX: são lidos por meio do fluxo textual dedicado e inseridos no prompt como transcrições.
  • Outras entradas: são encaminhadas ao provedor selecionado de acordo com o fluxo de extração disponível.
  • Formatos selecionáveis: .pdf, .docx, .jpg, .jpeg, .png, .webp, .tiff, .tif, .bmp, .txt, .json e .csv.

2. Ampliar uma base existente

O botão CARREGAR BASE permite indicar uma base genealógica já existente em formato GEDCOM ou CSV. Se você não carregar nada, o módulo criará um novo trabalho. Quando uma base é carregada, o resultado é salvo automaticamente na pasta que a contém, mesmo que você tenha escolhido anteriormente outro destino.

3. Banco de dados de notas paleográficas

Esta seção vincula o trabalho genealógico aos tipos documentais e às notas operacionais. Você pode escolher o tipo de ato, recuperar uma nota salva, criar uma nova, modificá-la ou excluí-la.

As notas servem para explicar ao modelo abreviações, fórmulas locais, o idioma do documento, regras de parentesco, dúvidas de leitura ou critérios de extração.

4. Destino da saída

Escolha a pasta na qual deseja salvar o resultado. Se uma base existente tiver sido carregada, será usada a pasta dessa base. O módulo gera um arquivo genealogia_*.ged em formato GEDCOM 5.5.1 e dois arquivos auxiliares com o mesmo nome-base: *_REVISIONE.csv e *_REGISTRO_ORIGINALE.csv.

5. Motor de IA e cofre de chaves

  • Provedor: escolha o serviço de IA entre os configurados, como Claude, OpenAI, Gemini, Mistral, xAI, DeepSeek, Groq, HuggingFace ou Ollama.
  • Substituição de modelo: campo opcional para indicar um modelo específico compatível com o provedor escolhido; fica oculto quando o provedor é Gemini.
  • GERENCIAR COFRE DE CHAVES (CSV): abre diretamente o arquivo CSV do cofre.
  • INICIAR EXTRAÇÃO COMPLETA: inicia a análise e a geração do GEDCOM.

Você pode criar e remover tipos documentais personalizados. Para os tipos integrados, é possível modificar o prompt por meio de uma substituição, mas não excluir o tipo.

📝 Fluxo recomendado

  1. Prepare entradas legíveis: transcrições, imagens ou arquivos já organizados por ato.
  2. Escolha a indicação de método mais adequada ao material, tendo em mente que, na versão atual, ela não seleciona um fluxo de processamento distinto.
  3. Se estiver dando continuidade a um trabalho existente, carregue o arquivo-base GEDCOM ou CSV.
  4. Selecione o tipo de ato e adicione uma nota paleográfica concreta.
  5. Escolha a pasta de saída, o provedor e a chave.
  6. Inicie a extração completa.
  7. Verifique o arquivo .ged gerado antes de importá-lo para outros programas.

⚠️ Advertências

  • O GEDCOM gerado é uma base de trabalho, não uma prova definitiva.
  • As relações familiares, datas, locais e nomes devem ser verificados nas fontes originais.
  • Erros de OCR, transcrição ou interpretação podem se propagar para o arquivo genealógico.
  • Antes de importar o GEDCOM para softwares externos, salve uma cópia do arquivo original e verifique a existência de possíveis duplicatas.
  • Não envie a provedores externos documentos confidenciais ou sujeitos a restrições sem antes verificar os termos de uso, as condições de privacidade e as autorizações.
