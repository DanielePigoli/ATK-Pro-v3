📌 Visão geral

O Visualizador de imagens do ATK-Pro é uma ferramenta integrada para a análise de documentos genealógicos digitalizados. É aberto pelo menu Serviços → Visualização de imagens do aplicativo principal. Suporta JPEG, PNG e TIFF (incluindo arquivos com várias páginas).

📂 Formatos suportados

FormatoExtensãoNotas
JPEG.jpg, .jpegSuporte completo
PNG.pngSuporte completo
TIFF.tif, .tiffSuporte para várias páginas com navegação dedicada

🖥️ Interface e controles

🔍 Zoom

  • Roda do mouse: zoom incremental em passos de 15%
  • Botão “ + ”: Aumenta o zoom em 15%
  • Botão “ − ”: Reduz o zoom em 15%
  • Botão “Ajustar à janela”: Redimensiona a imagem para ocupar a área disponível (proporcionalmente)
  • Botão “1:1”: Visualização na resolução nativa (um pixel da imagem = um pixel da tela)

O nível de zoom atual está sempre visível no indicador percentual entre os botões + e −. O intervalo vai de 5% a 800%.

✋️ Panorâmica (deslocamento)

Clicar e arrastar: mantenha pressionado o botão esquerdo do mouse e arraste para deslocar a imagem. O cursor muda para uma mão fechada durante o arrastamento e para uma mão aberta ao passar sobre a área da imagem.

📅 TIFF com várias páginas

Para arquivos TIFF que contenham várias páginas, é exibida uma barra de navegação adicional na barra de ferramentas:

  • Campo numérico (spinbox): Insira o número da página desejada; o visualizador carrega imediatamente a página correspondente
  • Indicador “/ N”: Mostra o número total de páginas ao lado do campo numérico

Observação: cada imagem interna do arquivo TIFF é tratada como uma página distinta.

📋 Painel de metadados do arquivo complementar JSON (sidecar, painel direito)

Se, na mesma pasta da imagem, existir um arquivo JSON com o mesmo nome-base (por ex. documento.jpg → procura documento.json), o painel direito exibe os metadados em formato de tabela.

  • Botão “◄ Ocultar metadados”: Oculta o painel direito para ampliar a área de visualização da imagem
  • Botão “► Mostrar metadados”: Restaura o painel de metadados

Se nenhum sidecar JSON for encontrado, o painel direito exibe “Nenhum sidecar JSON encontrado”. Se o arquivo existir, mas não puder ser lido, o painel indica um erro de leitura dos metadados.
