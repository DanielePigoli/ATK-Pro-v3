1. INSTALAÇÃO E REQUISITOS

────────────────────────────────────────────────────────────────────────────────

SISTEMA OPERACIONAL

  • Windows: Windows 10 ou posterior (64 bits) — Professional, Home, Server
  • Linux: Ubuntu 20.04+ ou distribuições compatíveis (pacote .deb ou arquivo .tar.gz)
  • macOS: macOS 11 Big Sur ou posterior — distribuição .dmg (testes em hardware real em andamento)
  • 64 bits obrigatórios em todas as plataformas
  • Pelo menos 2 GB de RAM disponíveis (4 GB recomendados para processamento em lote)
  • 1 GB de espaço livre em disco

INSTALAÇÃO

🪟 Windows

  1. Baixe ATK-Pro-Setup-vx.x.x.exe na página oficial de lançamentos
  2. Clique duas vezes no arquivo do instalador
  3. Selecione "Executar com privilégios de administrador", se solicitado
  4. Siga o assistente de instalação (Next → Next → Install)
  5. Durante a instalação, será solicitada a seleção do idioma (20 disponíveis)
  6. Ao final, marque "Iniciar ATK-Pro" para iniciar o programa
  7. Aceite eventuais alertas do Windows Firewall/Defender

🐧 Linux

  1. Baixe ATK-Pro-vx.x.x.deb (Debian/Ubuntu) ou .tar.gz na página de lançamentos
  2. Pacote .deb: sudo dpkg -i ATK-Pro-vx.x.x.deb ou clique duas vezes no Nautilus/Files
  3. Arquivo .tar.gz: extraia e execute ./ATK-Pro a partir da pasta extraída
  4. O idioma é selecionado na primeira inicialização e salvo no arquivo de configuração do usuário

🍎 macOS

  1. Baixe ATK-Pro-vx.x.x.dmg na página de lançamentos
  2. Abra o arquivo .dmg e arraste o ATK-Pro para a pasta Aplicativos
  3. Na primeira inicialização: clique com o botão direito → Abrir (necessário para aplicativos não notarizados)
  4. O idioma é selecionado na primeira inicialização e salvo no arquivo de configuração do usuário

LOCAIS PADRÃO

🪟 Windows

  • Programa: C:\Program Files\ATK-Pro\
  • Saída do usuário: C:\Users\[SeuNome]\Documents\ATK-Pro\output\
  • Entrada (opcional): C:\Users\[SeuNome]\Documents\ATK-Pro\input\

🐧 Linux

  • Programa: /opt/ATK-Pro/ (.deb) ou pasta extraída (.tar.gz)
  • Saída do usuário: ~/Documents/ATK-Pro/output/
  • Entrada (opcional): ~/Documents/ATK-Pro/input/

🍎 macOS

  • Programa: /Applications/ATK-Pro.app
  • Saída do usuário: ~/Documents/ATK-Pro/output/
  • Entrada (opcional): ~/Documents/ATK-Pro/input/

REQUISITOS DE REDE

  • Conexão estável à Internet (obrigatória para acessar manifestos IIIF)
  • Firewall: permitir conexões HTTPS de saída (porta 443)
  • Proxy empresarial: o ATK-Pro não dispõe de um menu interno para as credenciais do proxy. Configure o proxy no sistema operacional ou no ambiente de rede e confirme com o administrador que são permitidas conexões HTTPS aos portais.

📂 CONFIGURAÇÃO DAS PASTAS

Na primeira execução, o programa cria automaticamente as seguintes pastas:

  • Windows: C:\Users\[SeuNome]\Documents\ATK-Pro\output\
  • Windows: C:\Users\[SeuNome]\Documents\ATK-Pro\output\doc\ (padrão: documentos)
  • Windows: C:\Users\[SeuNome]\Documents\ATK-Pro\output\reg\ (padrão: registros)
  • Linux/macOS: análogas abaixo ~/Documents/ATK-Pro/output/
  • Pasta input\ análoga (opcional, para arquivos de entrada)

Durante o processamento, são criadas pastas temporárias para os tiles baixados (tiles_canvas_X/) e, caso o PDF seja solicitado, arquivos temporários para gerá-lo.

Todas as pastas e todos os arquivos temporários são excluídos automaticamente ao final do processamento.

Restam apenas os arquivos finais processados (imagens nos formatos escolhidos, PDF, manifestos e metadados).

Para alterar as pastas de saída, use Menu → Configurações → "Selecionar pastas de saída". As escolhas são armazenadas e restauradas automaticamente na sessão seguinte.

⚙️ PERFIL DE RECURSOS

O comando Configurações → Perfil de recursos ajusta o paralelismo utilizado durante o download, a reconstrução das imagens e a geração dos PDFs:

  • Leve: limita os processos simultâneos e os picos de memória; recomendado para computadores menos potentes ou processamentos muito longos.
  • Equilibrado: compromisso padrão entre velocidade e estabilidade, adequado à maioria dos casos.
  • Rápido: usa mais recursos para reduzir o tempo de processamento; escolha-o apenas em computadores com desempenho suficiente.

O perfil não altera a qualidade, os direitos nem a quantidade dos documentos obtidos. Os limites prudenciais específicos de cada portal continuam tendo precedência.

3. INTERFACE PRINCIPAL

────────────────────────────────────────────────────────────────────────────────

LAYOUT DA JANELA

A janela principal do Antenati Toolkit Pro tem uma estrutura simples e intuitiva.

📝 LEGENDA DO CABEÇALHO:

  • [🔲] Ícone do programa (logotipo do Antenati Toolkit Pro)
  • "ATK-Pro" Título da janela
  • [_] Minimizar (reduz a janela)
  • [□] Expandir/Recolher (maximiza ou restaura a janela)
  • [✕] Fechar (encerra o programa com um banner de suporte)

Na parte inferior, aparece o lema latino “Qui ante nos venerunt, in memoria nostra vivunt”, para lembrar a importância das raízes e da memória coletiva.

BARRA DE MENUS

Na parte superior da janela, abaixo do cabeçalho:

[Arquivo de entrada] [Saída] [Serviços] [Documentos] [Configurações]

Cada menu contém botões e opções específicos (consulte a seção seguinte).

MENUS DISPONÍVEIS

1. ARQUIVO DE ENTRADA

Gerencia o carregamento dos registros IIIF:

├─ Exemplo de entrada
│  └─ Exibe o arquivo de exemplo (mostra o formato dos pares: modo D/R + URL)
├─ Abrir entrada
│  └─ Selecione um arquivo .txt com seus registros IIIF
│     (Deve conter pares: modo D/R na linha 1, URL na linha 2)
└─ Editar entrada
   └─ Edita o arquivo de entrada atualmente carregado
      (Adicione/remova registros, altere URL, salve as alterações)

2. SAÍDA

Gerencia o processamento e a saída:

├─ Processar
│  └─ Inicia o download, a reconstrução e o salvamento das imagens
│     (Exibe uma janela de progresso em tempo real)
├─ Abrir pasta de saída
│  └─ Abre no Explorador de Arquivos a pasta que contém os arquivos processados
└─ Exibir processamentos anteriores
   └─ Lista dos registros já processados

3. SERVIÇOS

Lista dos serviços integrados:

├─ Pesquisa assistida por IA
│  └─ Sugere portais, linhas de pesquisa e consultas genealógicas a serem verificadas
├─ Visualização de imagens
│  └─ Visualizador de imagens baixadas e/ou PDF gerados
├─ Visualização de metadados JSON
│  └─ JSON originais e metadados (genealógicos, técnicos, EXIF)
├─ OCR avançado
│  └─ Textos manuscritos do século XIX, em latim eclesiástico e do final da Idade Média
├─ Tradução de OCR
│  └─ Tradução automática dos textos extraídos para os idiomas selecionados
└─ Exportação GEDCOM
   └─ GEDCOM, Gramps, Family Tree Maker, Ancestry, MyHeritage, WikiTree etc.

4. DOCUMENTOS

Acesso a recursos e documentação:

├─ Aviso legal - Cláusulas legais e termos de uso
├─ Apresentação do autor - Histórico do autor do projeto
├─ Apresentação do projeto - História, motivações e roteiro de desenvolvimento do ATK-Pro
├─ Guia - Índice principal do guia modular
└─ Informações - Versão, direitos autorais e e-mail de contato

5. CONFIGURAÇÕES

Configuração geral do programa:

├─ Alterar idioma
│  └─ Selecione o idioma da interface (requer reinicialização)
├─ Selecionar formatos de imagem
│  └─ Escolha entre PNG, JPG, TIFF e PDF (pelo menos 1 é obrigatório)
│     PDF pode ser selecionado sozinho ou junto com os formatos de imagem
│     A escolha é armazenada e pré-selecionada automaticamente na sessão seguinte
├─ Selecionar pastas de saída
│  └─ Primeiro abre a seleção do modo de organização das pastas e, depois, as janelas de seleção:
│     • Pasta única para todos       → uma única pasta para documentos e registros
│     • Pastas separadas doc/reg     → uma pasta para todos os documentos e outra para todos os registros
│     • Pasta para cada registro     → uma pasta distinta para cada registro
│     O modo e as pastas são armazenados e restaurados na sessão seguinte
├─ Exportar configuração
│  └─ Salva as configurações atuais em um arquivo
├─ Importar configuração
│  └─ Carrega um arquivo de configurações salvo anteriormente (restaura todas as preferências e os caminhos)
├─ Verificar atualizações
│  └─ Verifica se há novas versões do programa disponíveis
└─ Fechar
    └─ Encerra o programa (exibe um banner de suporte do PayPal.me)

ALTERAÇÃO DO IDIOMA

O idioma pode ser alterado a qualquer momento através de Menu → Configurações → Alterar idioma.

O programa requer uma reinicialização para aplicar o novo idioma.

Ao reiniciar, o programa carrega automaticamente o novo idioma selecionado.

TEXTOS LOCALIZADOS

Ao alterar o idioma, são traduzidos:

  • Menus e botões
  • Mensagens de progresso
  • Caixas de diálogo de erro/aviso
  • Documentos no menu Documentos

NOTA SOBRE TIPOS DE LETRA E LAYOUT

  • Os idiomas RTL (árabe e hebraico) alteram o layout (menus/controles alinhados à direita)
  • Uma fonte UTF-8 multilíngue garante a apresentação correta
  • Se vir caracteres corrompidos no Windows, atualize para o Windows 10+ (problema raro)
