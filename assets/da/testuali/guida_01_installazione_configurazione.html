1. INSTALLATION OG KRAV

────────────────────────────────────────────────────────────────────────────────

OPERATIVSYSTEM

  • Windows: Windows 10 eller nyere (64-bit) — Professional, Home, Server
  • Linux: Ubuntu 20.04+ eller kompatible distributioner (.deb-pakke eller .tar.gz-arkiv)
  • macOS: macOS 11 Big Sur eller nyere — .dmg-distribution (test på fysisk hardware er i gang)
  • 64-bit er påkrævet på alle platforme
  • Mindst 2 GB ledig RAM (4 GB anbefales til batchbehandling)
  • 1 GB ledig diskplads

INSTALLATION

🪟 Windows

  1. Download ATK-Pro-Setup-vx.x.x.exe fra den officielle Release-side
  2. Dobbeltklik på installationsfilen
  3. Vælg "Kør med administratorrettigheder", hvis du bliver bedt om det
  4. Følg installationsguiden (Next → Next → Install)
  5. Under installationen bliver du bedt om at vælge sprog (20 tilgængelige)
  6. Når installationen er færdig, skal du markere "Start ATK-Pro" for at starte programmet
  7. Accepter eventuelle advarsler fra Windows Firewall/Defender

🐧 Linux

  1. Download ATK-Pro-vx.x.x.deb (Debian/Ubuntu) eller .tar.gz fra Release-siden
  2. .deb-pakke: sudo dpkg -i ATK-Pro-vx.x.x.deb eller dobbeltklik i Nautilus/Files
  3. .tar.gz-arkiv: pak ud og start ./ATK-Pro fra den udpakkede mappe
  4. Sproget vælges ved første start og gemmes i brugerens konfigurationsfil

🍎 macOS

  1. Download ATK-Pro-vx.x.x.dmg fra Release-siden
  2. Åbn .dmg-filen, og træk ATK-Pro til mappen Programmer
  3. Ved første start: højreklik → Åbn (nødvendigt for programmer, der ikke er notariseret)
  4. Sproget vælges ved første start og gemmes i brugerens konfigurationsfil

STANDARDPLACERINGER

🪟 Windows

  • Program: C:\Program Files\ATK-Pro\
  • Brugeroutput: C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • Input (valgfrit): C:\Users\[TuoNome]\Documents\ATK-Pro\input\

🐧 Linux

  • Program: /opt/ATK-Pro/ (deb) eller udpakket mappe (.tar.gz)
  • Brugeroutput: ~/Documents/ATK-Pro/output/
  • Input (valgfrit): ~/Documents/ATK-Pro/input/

🍎 macOS

  • Program: /Applications/ATK-Pro.app
  • Brugeroutput: ~/Documents/ATK-Pro/output/
  • Input (valgfrit): ~/Documents/ATK-Pro/input/

NETVÆRKSKRAV

  • Stabil internetforbindelse (påkrævet for adgang til IIIF Manifests)
  • Firewall: Tillad udgående HTTPS-forbindelser (port 443)
  • Virksomhedsproxy: ATK-Pro har ikke en intern menu til proxyloginoplysninger. Konfigurer proxyen i operativsystemet eller netværksmiljøet, og få administratoren til at bekræfte, at HTTPS-forbindelser til portalerne er tilladt.

  • NLNederlands (nederlandsk): Vigtigt for Nederlandene, som i 2025 er et kraftigt voksende knudepunkt for italienske akademikere.
  • HE עברית (hebraisk, RTL): Til det betydelige og aktive italienske samfund i Israel.
  • JA日本語 (japansk): Til samfundet af italienske fagfolk og fastboende i Japan.
  • SVSvenska (svensk): Sverige er den vigtigste skandinaviske destination for italienere i 2025.

Med disse sprog anslås det på baggrund af de data, der var tilgængelige ved udgangen af 2025, at kunne dække omkring 98 % af efterkommere af italienere samt italienske eller italiensktalende samfund verden over.

  • På Linux/macOS: sproget vælges ved første start og gemmes i brugerens konfigurationsfil

  • Det kan til enhver tid ændres via Menu → Indstillinger → Skift sprog
  • Programmet skal genstartes, før det nyvalgte sprog anvendes

📂 MAPPEKONFIGURATION

Ved første kørsel opretter programmet automatisk følgende mapper:

  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\doc\ (standard dokumentmappe)
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\reg\ (standard registermappe)
  • Linux/macOS: tilsvarende under ~/Documents/ATK-Pro/output/
  • Mappe input\ tilsvarende (valgfri, til inputfiler)

Under behandlingen oprettes midlertidige mapper til de downloadede tiles (tiles_canvas_X/) og, hvis PDF er valgt, midlertidige filer til genereringen heraf.

Alle midlertidige mapper og filer slettes automatisk, når behandlingen er afsluttet.

Kun de færdigbehandlede filer bevares (billeder i de valgte formater, PDF, manifest og metadata).

Brug Menu → Indstillinger → "Vælg outputmapper" for at ændre outputmapperne. Valgene gemmes og gendannes automatisk i næste session.

⚙️ RESSOURCEPROFIL

Kommandoen Indstillinger → Ressourceprofil styrer paralleliseringen, der anvendes under download, billedrekonstruktion og PDF-generering:

  • Let: begrænser samtidige processer og hukommelsesspidser; velegnet til mindre kraftige computere eller meget lange behandlinger.
  • Balanceret: standardkompromis mellem hastighed og stabilitet, egnet til de fleste tilfælde.
  • Hurtig: bruger flere ressourcer for at reducere behandlingstiden; vælg kun denne profil på tilstrækkeligt kraftige computere.

Profilen ændrer ikke kvaliteten, rettighederne eller antallet af hentede dokumenter. Portalens eventuelle specifikke forsigtighedsgrænser har fortsat forrang.

3. HOVEDBRUGERFLADE

────────────────────────────────────────────────────────────────────────────────

VINDUETS LAYOUT

Hovedvinduet i Antenati Toolkit Pro har en enkel og intuitiv opbygning.

📝 FORKLARING TIL TITELLINJEN:

  • [🔲] Programikon (Antenati Toolkit Pro-logo)
  • "ATK-Pro" Vinduestitel
  • [_] Minimer (minimer vinduet)
  • [□] Maksimer/Gendan (maksimer eller gendan vinduet)
  • [✕] Luk (afslutter programmet med et supportbanner)

Nederst vises det latinske motto “Qui ante nos venerunt, in memoria nostra vivunt” som en påmindelse om betydningen af rødder og kollektiv erindring.

MENULINJE

Øverst i vinduet, under titellinjen:

[Inputfil] [Output] [Tjenester] [Dokumenter] [Indstillinger]

Hver menu indeholder specifikke knapper og indstillinger (se næste afsnit).

TILGÆNGELIGE MENUER

1. INPUTFIL

Håndterer indlæsning af IIIF-poster:

├─ Eksempel på input
│  └─ Vis eksempelfilen (viser formatet med par: D/R-tilstand + URL)
├─ Åbn input
│  └─ Vælg en .txt-fil med dine IIIF-poster
│     (Skal indeholde par: D/R-tilstand på linje 1, URL på linje 2)
└─ Rediger input
   └─ Rediger den aktuelt indlæste inputfil
      (Tilføj/fjern poster, skift URL, gem ændringer)

2. OUTPUT

Håndterer behandling og output:

├─ Behandl
│  └─ Starter download, rekonstruktion og lagring af billeder
│     (Viser et statusvindue i realtid)
├─ Åbn outputmappe
│  └─ Åbner mappen med de behandlede filer i Stifinder
└─ Vis tidligere behandlinger
   └─ Liste over allerede behandlede poster

3. TJENESTER

Liste over integrerede tjenester:

├─ AI-assisteret søgning
│  └─ Foreslår portaler, forskningsspor og genealogiske søgeforespørgsler, der skal verificeres
├─ Billedvisning
│  └─ Fremviser downloadede billeder og/eller genererede PDF-filer
├─ Visning af JSON-metadata
│  └─ Original JSON og metadata (genealogiske, tekniske, EXIF)
├─ Avanceret OCR
│  └─ Håndskrevne tekster fra 1800-tallet, kirkelatin, senmiddelalderlige tekster
├─ OCR-oversættelse
│  └─ Automatisk oversættelse af udtrukne tekster til de valgte sprog
└─ GEDCOM-eksport
   └─ GEDCOM, Gramps, Family Tree Maker, Ancestry, MyHeritage, WikiTree, etc.

4. DOKUMENTER

Adgang til ressourcer og dokumentation:

├─ Ansvarsfraskrivelse - Juridiske bestemmelser og brugsbetingelser
├─ Præsentation af forfatteren - Baggrund om projektets forfatter
├─ Præsentation af projektet - ATK-Pro's historie, motivation og roadmap
├─ Vejledning - Hovedindeks for den modulopbyggede vejledning
└─ Information - Version, copyright, kontakt-e-mail

5. INDSTILLINGER

Generel konfiguration af programmet:

├─ Skift sprog
│  └─ Vælg brugerfladens sprog (kræver genstart)
├─ Vælg billedformater
│  └─ Vælg mellem PNG, JPG, TIFF og PDF (mindst 1 er påkrævet)
│     PDF kan vælges alene eller sammen med billedformaterne
│     Valget gemmes og forudvælges automatisk i næste session
├─ Vælg outputmapper
│  └─ Åbner først valget af mappetilstand og derefter vinduerne til mappevalg:
│     • Én mappe til alt    → én enkelt mappe til dokumenter og registre
│     • Separate mapper dok./reg.   → én mappe til alle dok., én til alle reg.
│     • Én mappe pr. post    → en separat mappe for hver post
│     Tilstanden og mapperne gemmes og gendannes i næste session
├─ Eksporter konfiguration
│  └─ Gemmer de aktuelle indstillinger i en fil
├─ Importer konfiguration
│  └─ Indlæser en tidligere gemt indstillingsfil (gendanner alle præferencer og stier)
├─ Søg efter opdateringer
│  └─ Kontrollerer, om der findes nye versioner af programmet
└─ Luk
    └─ Afslutter programmet (viser supportbanneret PayPal.me)
