1. INSTALLASJON OG KRAV

────────────────────────────────────────────────────────────────────────────────

OPERATIVSYSTEM

  • Windows: Windows 10 eller nyere (64-bit) — Professional, Home, Server
  • Linux: Ubuntu 20.04+ eller kompatible distribusjoner (.deb-pakke eller .tar.gz-arkiv)
  • macOS: macOS 11 Big Sur eller nyere — .dmg-distribusjon (testing på fysisk maskinvare pågår)
  • 64-bit kreves på alle plattformer
  • Minst 2 GB ledig RAM (4 GB anbefales for satsvis behandling)
  • 1 GB ledig diskplass

INSTALLASJON

🪟 Windows

  1. Last ned ATK-Pro-Setup-vx.x.x.exe fra den offisielle utgivelsessiden
  2. Dobbeltklikk på installasjonsfilen
  3. Velg «Kjør som administrator» hvis du blir bedt om det
  4. Følg installasjonsveiviseren (Next → Next → Install)
  5. Under installasjonen blir du bedt om å velge språk (20 tilgjengelige)
  6. Når installasjonen er ferdig, merker du av for «Start ATK-Pro» for å starte programmet
  7. Godta eventuelle advarsler fra Windows-brannmur/Defender

🐧 Linux

  1. Last ned ATK-Pro-vx.x.x.deb (Debian/Ubuntu) eller .tar.gz fra utgivelsessiden
  2. .deb-pakke: sudo dpkg -i ATK-Pro-vx.x.x.deb, eller dobbeltklikk i Nautilus/Filer
  3. .tar.gz-arkiv: Pakk ut og start ./ATK-Pro fra den utpakkede mappen
  4. Språket velges ved første oppstart og lagres i brukerens konfigurasjonsfil

🍎 macOS

  1. Last ned ATK-Pro-vx.x.x.dmg fra utgivelsessiden
  2. Åpne .dmg-filen og dra ATK-Pro til Programmer-mappen
  3. Ved første oppstart: Høyreklikk → Åpne (nødvendig for programmer som ikke er notarisert)
  4. Språket velges ved første oppstart og lagres i brukerens konfigurasjonsfil

STANDARDPLASSERINGER

🪟 Windows

  • Program: C:\Program Files\ATK-Pro\
  • Brukerutdata: C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • Inndata (valgfritt): C:\Users\[TuoNome]\Documents\ATK-Pro\input\

🐧 Linux

  • Program: /opt/ATK-Pro/ (deb) eller utpakket mappe (.tar.gz)
  • Brukerutdata: ~/Documents/ATK-Pro/output/
  • Inndata (valgfritt): ~/Documents/ATK-Pro/input/

🍎 macOS

  • Program: /Applications/ATK-Pro.app
  • Brukerutdata: ~/Documents/ATK-Pro/output/
  • Inndata (valgfritt): ~/Documents/ATK-Pro/input/

NETTVERKSKRAV

  • Stabil internettforbindelse (kreves for tilgang til IIIF-manifester)
  • Brannmur: Tillat utgående HTTPS-forbindelser (port 443)
  • Bedriftsproxy: ATK-Pro har ingen intern meny for proxyopplysninger. Konfigurer proxyen i operativsystemet eller nettverksmiljøet, og be administratoren bekrefte at HTTPS-forbindelser til portalene er tillatt.

  • HE עברית (hebraisk, RTL): For det betydelige og aktive italienske miljøet i Israel.
  • JA日本語 (japansk): For miljøet av italienske fagfolk og fastboende i Japan.
  • SVSvenska (svensk): Sverige er den viktigste skandinaviske destinasjonen for italienere i 2025.
  • ZH中文 (kinesisk): For fastboende og næringsaktører i Kina.
  • RORomână (rumensk): For det store miljøet av italienske gründere og fastboende i Romania.
  • ELΕλληνικά (gresk): For de historiske forbindelsene og fastboende på de greske øyene og i greske byer.

På grunnlag av dataene som var tilgjengelige ved utgangen av 2025, anslås disse språkene å dekke omtrent 98 % av etterkommere etter italienere samt italienske eller italienskspråklige miljøer over hele verden.

  • På Linux/macOS: Språket velges ved første oppstart og lagres i brukerens konfigurasjonsfil

  • Det kan når som helst endres via Meny → Innstillinger → Bytt språk
  • Programmet må startes på nytt før det nyvalgte språket tas i bruk

📂 MAPPEKONFIGURASJON

Ved første kjøring oppretter programmet automatisk følgende mapper:

  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\doc\ (standardmappe for dokumenter)
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\reg\ (standardmappe for registre)
  • Linux/macOS: tilsvarende under ~/Documents/ATK-Pro/output/
  • Tilsvarende input\-mappe (valgfri, for inndatafiler)

Under behandlingen opprettes midlertidige mapper for nedlastede fliser (tiles_canvas_X/) og, hvis PDF er valgt, midlertidige filer for PDF-genereringen.

Alle midlertidige mapper og filer slettes automatisk når behandlingen er ferdig.

Bare de ferdigbehandlede filene beholdes (bilder i valgte formater, PDF, manifest og metadata).

Bruk Meny → Innstillinger → «Velg utdatamapper» for å endre utdatamappene. Valgene lagres og gjenopprettes automatisk i neste økt.

⚙️ RESSURSPROFIL

Kommandoen Innstillinger → Ressursprofil styrer parallelliteten som brukes under nedlasting, bilderekonstruksjon og PDF-generering:

  • Lett: begrenser samtidige prosesser og minnetopper; egnet for mindre kraftige datamaskiner eller svært lange behandlinger.
  • Balansert: Standardkompromiss mellom hastighet og stabilitet, egnet i de fleste tilfeller.
  • Rask: Bruker flere ressurser for å redusere behandlingstiden; velg denne profilen bare på tilstrekkelig kraftige datamaskiner.

Profilen endrer ikke kvaliteten, rettighetene eller antallet av hentede dokumenter. Eventuelle portalspecifikke sikkerhetsgrenser har fortsatt forrang.

VINDUETS OPPBYGNING

Hovedvinduet i Antenati Toolkit Pro har en enkel og intuitiv oppbygning.

📝 FORKLARING AV TITELLINJEN:

  • [🔲] Programikon (Antenati Toolkit Pro-logo)
  • "ATK-Pro" Vindustittel
  • [_] Minimer (minimer vinduet)
  • [□] Maksimer/Gjenopprett (maksimer eller gjenopprett vinduet)
  • [✕] Lukkk (avslutter programmet med et støttebanner)

Nederst vises det latinske mottoet «Qui ante nos venerunt, in memoria nostra vivunt» som en påminnelse om betydningen av røtter og kollektiv erindring.

MENYLINJE

Øverst i vinduet, under tittellinjen:

[Inndatafil] [Output] [Tjenester] [Dokumenter] [Innstillinger]

Hver meny inneholder bestemte knapper og innstillinger (se neste avsnitt).

TILGJENGELIGE MENYER

1. INNDATAFIL

Håndterer innlasting av IIIF-poster:

├─ Eksempel på inndata
│  └─ Vis eksempelfilen (viser formatet med par: D/R-modus + URL)
├─ Åpne inndata
│  └─ Velg en .txt-fil med IIIF-postene dine
│     (Må inneholde par: D/R-modus på linje 1, URL på linje 2)
└─ Rediger inndata
   └─ Rediger inndatafilen som er lastet inn
      (Legg til/fjern poster, endre URL, lagre endringer)

2. OUTPUT

Håndterer behandling og utdata:

├─ Behandle
│  └─ Starter nedlasting, rekonstruksjon og lagring av bilder
│     (Viser et statusvindu i sanntid)
├─ Åpne utdatamappe
│  └─ Åpner mappen med de behandlede filene i Filutforsker
└─ Vis tidligere behandlinger
   └─ Liste over poster som allerede er behandlet

3. TJENESTER

Liste over integrerte tjenester:

├─ AI-assistert forskning
│  └─ Foreslår portaler, forskningsspor og genealogiske søk som må verifiseres
├─ Bildevisning
│  └─ Viser nedlastede bilder og/eller genererte PDF-filer
├─ Visning av JSON-metadata
│  └─ Original JSON og metadata (genealogiske, tekniske, EXIF)

5. INNSTILLINGER

Generell konfigurasjon av programmet:

├─ Bytt språk
│  └─ Velg språk for brukergrensesnittet (krever omstart)
├─ Velg bildeformater
│  └─ Velg mellom PNG, JPG, TIFF og PDF (minst ett kreves)
│     PDF kan velges alene eller sammen med bildeformatene

│  └─ Åpner først valg av mappemodus og deretter vinduene for mappevalg:

│     Modusen og mappene lagres og gjenopprettes i neste økt
├─ Eksporter konfigurasjon
│  └─ Lagrer de gjeldende innstillingene i en fil
├─ Importer konfigurasjon
│  └─ Laster inn en tidligere lagret innstillingsfil (gjenoppretter alle preferanser og stier)
├─ Se etter oppdateringer
│  └─ Kontrollerer om det finnes nye versjoner av programmet
└─ Lukk
    └─ Avslutter programmet (viser støttebanneret PayPal.me)
