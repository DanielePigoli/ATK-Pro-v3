1. Начало и требования

────────────────────────────────────────────────────────────────────────────────

ОПЕРАЦИОННАЯ СИСТЕМА

  • Windows: Windows 10 или более поздняя версия (64-разрядная) — Professional, Home, Server
  • Linux: Ubuntu 20.04+ или совместимые дистрибутивы (пакет .deb или архив .tar.gz)
  • macOS: macOS 11 Big Sur или более поздняя версия — дистрибутив .dmg (реальное оборудование в разработке)
  • 64-битный обязательный на всех платформах
  • Доступно не менее 2 ГБ оперативной памяти (4 ГБ рекомендуется для пакетной обработки)
  • 1 ГБ свободного дискового пространства

ИНСТАЛЬТАЦИЯ

Windows

  1. скачать ATK-Pro-Setup-vx.x.x.exe Официальный сайт Release
  2. Дважды щёлкните файл установщика
  3. Выберите «Выполнять с правами администратора», если это необходимо.
  4. Заклинание волшебника (Next → Next → Install)
  5. Выбор языка (20 доступных) будет запрошен во время установки.
  6. В конце проверьте «Start ATK-Pro» для запуска программы.
  7. Принять любые предупреждения от Windows Firewall/Defender

Linux

  1. скачать ATK-Pro-vx.x.x.deb (Debian/Ubuntu) .tar.gz со страницы выпуска
  2. Пакет .deb: sudo dpkg -i ATK-Pro-vx.x.x.debили дважды щёлкните файл в Nautilus/Files
  3. Архив .tar.gz: Снаружи и начать ./ATK-Pro Из извлеченной папки
  4. Язык выбирается при первом запуске и сохраняется в файле конфигурации пользователя.

macOS

  1. скачать ATK-Pro-vx.x.x.dmg со страницы выпуска
  2. Откройте файл .dmg и перетащите ATK-Pro в папку «Приложения»
  3. На первом старте: правый клик → Открытый (необходим для ненотариально заверенных приложений)
  4. Язык выбирается при первом запуске и сохраняется в файле конфигурации пользователя.

Неверные позиции

Windows

  • Программа: C:\Program Files\ATK-Pro\
  • Результат пользователя: C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • Вход (факультативно): C:\Users\[TuoNome]\Documents\ATK-Pro\input\

Linux

  • Программа: /opt/ATK-Pro/ (deb) или извлеченная папка (.tar.gz)
  • Результат пользователя: ~/Documents/ATK-Pro/output/
  • Вход (факультативно): ~/Documents/ATK-Pro/input/

macOS

  • Программа: /Applications/ATK-Pro.app
  • Результат пользователя: ~/Documents/ATK-Pro/output/
  • Вход (факультативно): ~/Documents/ATK-Pro/input/

Требования

  • Стабильное подключение к Интернету (обязательно для доступа к IIIF Manifests)
  • Брандмауэр: позволяет выходить HTTPS соединения (порт 443)
  • Компания Proxy: ATK-Pro не имеет внутреннего меню для прокси-удостоверений. Настройте прокси-сервер в операционной системе или сетевой среде и проверьте с администратором, разрешены ли HTTPS-соединения с порталами.

КАРТЕЛЬСКАЯ КОНФИГРАЦИЯ

При первом запуске программа автоматически создает следующие папки:

  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\doc\ (документы по умолчанию)
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\reg\ (регистр по умолчанию)
  • Linux/macOS: аналогичный ниже ~/Documents/ATK-Pro/output/
  • папка input\ аналоговый (опциональный, для ввода файла)

При обработке временные папки создаются для скачанной плитки (tiles_canvas_X/) и, при необходимости, PDF, временные файлы для его генерации.

Все временные папки и файлы автоматически удаляются по окончании обработки.

Остаются только обработанные окончательные файлы (изображения в выбранных форматах, PDF, манифесты и метаданные).

Для изменения выходных папок используйте меню → Настройки → «Выбрать выходные папки». Выбор хранится и автоматически восстанавливается до следующего сеанса.

ИСТОЧНИКИ

Командование Настройки → Профиль ресурса регулирует параллелизм, используемый при загрузке, реконструкции изображения и генерации PDF:

  • Легкий вес: Ограничивает современные процессы и пики памяти; указывается для менее мощных компьютеров или очень длительной обработки.
  • Сбалансированное: компромисс между скоростью и стабильностью, подходящий для большинства случаев.
  • Быстро. Используйте больше ресурсов, чтобы сократить время; выберите его только на компьютерах.

Профиль не изменяет качество, права или количество приобретенных документов. Конкретные пруденциальные пределы портала по-прежнему имеют приоритет.

Изменение языка

Язык может быть изменен в любое время с помощью меню → Настройки → Язык изменений.

Программа требует перезагрузки для применения нового языка.

При перезагрузке программа автоматически загружает новый выбранный язык.

Локализованные тесты

Изменение языка переводится:

  • Меню и кнопки
  • Прогрессивные сообщения
  • Диалоги об ошибках/заметках
  • Документы в меню Документы

ПРИМЕЧАНИЕ НА ФОНТ И ЛАЙУТ

  • Языки RTL (арабский, иврит) меняют компоновку (меню/контроль справа)
  • Многоязычный шрифт UTF-8 обеспечивает корректное отображение
  • Если вы видите поврежденные символы на Windows, перейдите на Windows 10+ (переиздание)
