📌 Descripción general

El módulo Exportación GEDCOM de la v3 es un entorno de análisis genealógico asistido: procesa textos, imágenes o documentos seleccionados, utiliza un proveedor de IA configurado en ATK-Pro y genera un archivo .ged junto con dos archivos CSV auxiliares.

Se abre desde el menú Servicios → Exportación GEDCOM. El nombre público sigue vinculado al formato GEDCOM, pero el trabajo efectivo también comprende la extracción genealógica, el uso de notas paleográficas, la posible ampliación de una base existente y la gestión de las claves de IA.

El resultado debe verificarse antes de importarlo en un programa genealógico: la IA puede ayudar a estructurar datos y relaciones, pero no sustituye la lectura crítica de las fuentes.

🖥️ Interfaz

1. Método y entrada universal

La primera sección permite elegir una opción de método y los archivos que se van a analizar. Las opciones Auto-Discovery, Vision IA e Refinery LLM se guardan como preferencia, pero en la versión actual no activan tres canales de procesamiento distintos: el tratamiento efectivo depende principalmente del tipo de archivo.

  • TXT y DOCX: se leen mediante el canal de procesamiento textual dedicado y se incluyen en la instrucción como transcripciones.
  • Otras entradas: se envían al proveedor seleccionado de acuerdo con el flujo de extracción disponible.
  • Formatos seleccionables: .pdf, .docx, .jpg, .jpeg, .png, .webp, .tiff, .tif, .bmp, .txt, .json e .csv.

2. Ampliar una base existente

El botón CARGAR BASE permite indicar una base genealógica ya existente en formato GEDCOM o CSV. Si no cargas ninguna, el módulo crea un nuevo trabajo. Cuando cargas una base, el resultado se guarda automáticamente en la carpeta que la contiene, aunque previamente hayas elegido otro destino.

3. Base de datos de notas paleográficas

Esta sección vincula el trabajo genealógico con las tipologías documentales y las notas operativas. Puedes elegir el tipo de acta, recuperar una nota guardada, crear una nueva, modificarla o eliminarla.

Las notas sirven para explicar al modelo las abreviaturas, las fórmulas locales, el idioma del documento, las reglas de parentesco, las dudas de lectura o los criterios de extracción.

4. Destino de salida

Elige la carpeta en la que guardar el resultado. Si se ha cargado una base existente, se utiliza en su lugar la carpeta de dicha base. El módulo genera un archivo genealogia_*.ged en formato GEDCOM 5.5.1 y dos archivos auxiliares con el mismo nombre base: *_REVISIONE.csv e *_REGISTRO_ORIGINALE.csv. Estos nombres técnicos permanecen en italiano por compatibilidad.

5. Motor de IA y bóveda de claves

  • Proveedor: elige el servicio de IA entre los configurados, por ejemplo Claude, OpenAI, Gemini, Mistral, xAI, DeepSeek, Groq, HuggingFace u Ollama.
  • Anulación de modelo: campo opcional para indicar un modelo específico compatible con el proveedor seleccionado; se oculta cuando el proveedor es Gemini.
  • GESTIONAR BÓVEDA DE CLAVES (CSV): abre directamente el archivo CSV de la bóveda.
  • INICIAR EXTRACCIÓN COMPLETA: inicia el análisis y la generación del GEDCOM.

Puedes crear y eliminar tipos documentales personalizados. Para los tipos integrados, puedes modificar el prompt mediante una sobrescritura, pero no eliminar el tipo.

📝 Flujo recomendado

  1. Prepara entradas legibles: transcripciones, imágenes o archivos ya organizados por acta.
  2. Elige la indicación de método más adecuada para el material, teniendo en cuenta que, en la versión actual, no selecciona un flujo de procesamiento distinto.
  3. Si estás continuando un trabajo existente, carga la base GEDCOM o CSV.
  4. Selecciona el tipo de acta y añade una nota paleográfica concreta.
  5. Elige la carpeta de salida, el proveedor y la clave.
  6. Inicia la extracción completa.
  7. Revisa el archivo .ged generado antes de importarlo en otros programas.

⚠️ Advertencias

  • El GEDCOM generado es una base de trabajo, no una prueba definitiva.
  • Las relaciones familiares, las fechas, los lugares y los nombres deben verificarse en las fuentes originales.
  • Los errores de OCR, transcripción o interpretación pueden propagarse en el archivo genealógico.
  • Antes de importar el GEDCOM en software externo, conserva una copia del archivo original y comprueba si hay duplicados.
  • No envíes a proveedores externos documentos confidenciales o sujetos a restricciones sin haber verificado las condiciones de uso, la privacidad y las autorizaciones.
