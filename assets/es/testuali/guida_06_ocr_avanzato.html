📌 Descripción general

El módulo OCR avanzado (transcripción diplomática) extrae texto de imágenes y documentos PDF mediante modelos multimodales, modelos OCR especializados y servicios HTR. Está diseñado específicamente para documentos históricos: manuscritos, actas notariales, registros parroquiales y cartas de archivo en italiano del siglo XIX, latín o dialecto.

A diferencia de los motores OCR tradicionales (Tesseract, etc.), el módulo puede interpretar la escritura en el contexto del documento y reconocer abreviaturas y fórmulas recurrentes. La salida TEI-P5 representa las líneas transcritas y, cuando se reconocen, los saltos de página, las expansiones y los pasajes ilegibles; no reproduce íntegramente la disposición gráfica original.

Se abre desde el menú Servicios → OCR avanzado de la aplicación principal.

🖥️ Interfaz — guía paso a paso

📂 Paso 1 — Selección de archivos

Haz clic en “Seleccionar archivos (Imágenes/PDF)” para abrir el selector. Puedes seleccionar varios archivos a la vez manteniendo pulsada la tecla Ctrl o Shift.

Formatos aceptados:

  • Imágenes: .jpg, .jpeg, .png, .tiff, .tif
  • PDF: cualquier documento PDF (escaneado o nativo)

El número de archivos seleccionados se muestra junto a la etiqueta. Cada archivo se procesa por separado y genera sus propios archivos de salida.

Selecciona el proveedor en el menú desplegable “Seleccionar proveedor de IA:”

El campo “Anulación del modelo (opcional)” permite sustituir el modelo predeterminado. Úsalo solo si conoces el identificador exacto y la compatibilidad visual del modelo. Para Gemini, este campo no se muestra.

Puedes introducir la credencial en el campo correspondiente o abrir la Caja fuerte. Las claves de IA se almacenan localmente en la bóveda CSV api_keys.csv: no se trata del llavero protegido del sistema operativo. La protección del perfil de usuario, las copias de seguridad y la revocación de las claves siguen siendo responsabilidad del usuario.

📄 Paso 3 — Formatos de salida

Selecciona uno o varios formatos de salida (los tres están seleccionados de forma predeterminada):

  • Texto sin formato (.txt): transcripción sin formato, máxima compatibilidad. Ideal para procesamientos posteriores (traducción, indexación).
  • Documento de Word (.docx): texto con formato, editable con Microsoft Word o LibreOffice.
  • XML TEI (.xml): formato TEI-P5 para representar la transcripción, con encabezado descriptivo, líneas y marcadores reconocidos para páginas, expansiones y texto ilegible.

Los archivos se guardan en la carpeta de destino que elegirás al iniciar el OCR.

📝 Paso 4 — Instrucciones adicionales (opcional, pero recomendado)

El campo “Instrucciones adicionales para la IA” permite personalizar el comportamiento del modelo para cada sesión de trabajo:

  • Indicar el dialecto o la variante lingüística del texto
  • Señalar las abreviaturas recurrentes y su significado
  • Especificar si deben ignorarse sellos, anotaciones marginales o sellos postales
  • Solicitar que se conserven fórmulas específicas

Ejemplos prácticos:

  • “Los nombres de los meses están en dialecto siciliano del siglo XIX. No los corrijas.”
  • “Ignora los sellos de los márgenes y las anotaciones hechas con lápiz rojo.”
  • “La abreviatura 'f.' puede significar 'hijo/a de'; 'fu' y 'q.' indican que la persona mencionada ya había fallecido.”

Archivo de instrucciones: las instrucciones utilizadas con mayor frecuencia pueden guardarse con el botón “+” y recuperarse desde el menú desplegable “Instrucciones guardadas” en las sesiones posteriores.

Las instrucciones guardadas se pueden añadir, renombrar o eliminar. El tipo de documento determina el prompt básico: además de los tipos incluidos, puedes crear, modificar o eliminar perfiles documentales personalizados.

🎯 Calibración asistida y diagnóstico (opcionales)

La calibración asistida procesa la parte superior del primer archivo seleccionado, muestra el resultado para su corrección y utiliza el texto aprobado como referencia para el procesamiento completo. Resulta útil para comprobar el proveedor, el modelo, el tipo de documento y las instrucciones antes de iniciar un lote extenso.

La opción de diagnóstico guarda información técnica adicional sobre el procesamiento. Actívala cuando necesites analizar un error o proporcionar información al soporte técnico; comprueba el contenido antes de compartirlo, ya que puede incluir datos relacionados con el documento o la solicitud.

🎓 Paso 5 — Transcripción de referencia (few-shot, opcional)

El campo “Transcripción de referencia” proporciona al modelo un ejemplo contextual de una transcripción correcta para utilizarlo en la solicitud. No entrena, modifica ni actualiza el modelo.

Cómo utilizarla:

  1. Transcribe manualmente y con precisión la primera página (o las primeras líneas) del registro
  2. Pega el texto transcrito en el campo “Transcripción de referencia”
  3. Inicia el OCR: el modelo utilizará esa transcripción como guía para todo el resto del documento

Resultado: puede mejorar la precisión, especialmente con caligrafías cursivas difíciles, abreviaturas inusuales o dialectismos locales; el efecto depende del proveedor, del modelo y de la calidad del documento.
El campo “Borrar Texto” (✖) vacía la transcripción y restablece el modo estándar.

🔍 Paso 6 — Revisión interactiva (opcional)

Marcar “Activar la ventana de revisión interactiva antes de guardar el OCR” activa un modo interactivo que se abre después de cada procesamiento:

  • Panel izquierdo: imagen original con zoom (rueda del ratón) y desplazamiento panorámico
  • Panel derecho: texto extraído mediante OCR, que se puede editar libremente
  • Botón “Aprobar y generar archivo”: guarda el texto revisado en los formatos elegidos
  • Botón “Saltar página”: descarta el procesamiento actual y pasa a la página siguiente

Resulta útil para comprobar en tiempo real la calidad del OCR y corregir errores antes del guardado definitivo. Para lotes de gran tamaño, es preferible desactivar la revisión interactiva y corregir el texto posteriormente.

▶️ Paso 7 — Inicio del OCR

Haz clic en “Iniciar OCR”. Se solicitará la carpeta de destino para los archivos de salida.

La barra de progreso muestra el avance (archivo actual / total de archivos). El procesamiento se realiza en un hilo independiente: la interfaz sigue respondiendo durante el procesamiento.

Durante los lotes, ATK-Pro actualiza una transcripción progresiva *_trascrizione_parziale.txt con los metadatos correspondientes. Este nombre técnico permanece sin traducir por compatibilidad. Si se interrumpe el procesamiento, conserva estos archivos para recuperar lo que ya se haya transcrito; no los consideres una salida definitiva hasta que el lote se haya completado y revisado.

Al finalizar, un cuadro de diálogo confirmará que se ha completado el proceso o indicará cualquier error.

🔑 Cómo obtener las claves API

Cuentas, claves, modelos y costes

Obtén las credenciales exclusivamente desde la consola oficial del proveedor elegido y no las compartas en los archivos de entrada, en las transcripciones ni en las solicitudes de asistencia. Las interfaces, los modelos, las cuotas, la disponibilidad geográfica y los precios pueden cambiar sin que se actualice ATK-Pro.

Antes de realizar un procesamiento extenso, consulta siempre la documentación y el panel de facturación de tu cuenta. ATK-Pro no garantiza planes gratuitos, cuotas mínimas ni la permanencia de un modelo específico.

💡 Consejos para obtener resultados óptimos

  • Calidad de las imágenes: las imágenes nítidas a 300+ DPI producen resultados notablemente mejores. Evita los archivos JPEG con una compresión elevada (artefactos).
  • Utiliza siempre las instrucciones adicionales: incluso unas pocas líneas de contexto aumentan significativamente la precisión en documentos dialectales o con una caligrafía inusual.
  • Primera página como referencia: transcribe manualmente la primera página y utiliza el campo “Transcripción de referencia”; la mejora en las páginas siguientes suele ser notable.
  • Lote de prueba: para lotes grandes (100+ imágenes), realiza primero una prueba con 5-10 archivos con la revisión interactiva activada antes de proceder con el lote completo.
  • TEI XML: selecciona el formato XML TEI si tienes previsto depositar la transcripción en archivos digitales académicos o compartirla con otros investigadores.
  • Guarda las instrucciones: cada serie archivística tiene sus propias características. Guarda un conjunto de instrucciones específico para cada registro o fondo tratado.
