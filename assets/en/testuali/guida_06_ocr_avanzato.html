📌 Overview

The Advanced OCR (Diplomatic Transcription) module extracts text from images and PDF documents using multimodal models, specialized OCR models, and HTR services. It is specifically designed for historical documents: manuscripts, notarial deeds, parish registers, and archival letters in nineteenth-century Italian, Latin, or dialect.

Unlike traditional OCR engines (Tesseract, etc.), the module can interpret handwriting within the context of the document and recognize abbreviations and recurring formulas. The TEI-P5 output represents transcribed lines and, when recognized, page breaks, expansions, and illegible passages; it does not fully reproduce the original graphical layout.

It opens from the Services → Advanced OCR menu in the main application.

🖥️ Interface — Step-by-Step Guide

📂 Step 1 — File Selection

Click “Select Files (Images/PDF)” to open the file picker. You can select multiple files at once by holding down Ctrl or Shift.

Accepted formats:

  • Images: .jpg, .jpeg, .png, .tiff, .tif
  • PDF: any PDF document (scanned or native)

The number of selected files is displayed next to the label. Each file is processed separately and generates its own output files.

📄 Step 3 — Output Formats

Select one or more output formats (all three are selected by default):

  • Plain Text (.txt): Plain transcription with maximum compatibility. Ideal for subsequent processing (translation, indexing).
  • Word Document (.docx): Formatted text, editable with Microsoft Word or LibreOffice.
  • XML TEI (.xml): TEI-P5 format representing the transcription with a descriptive header, lines, and recognized markers for pages, expansions, and illegible text.

The files are saved in the destination folder you select when starting the OCR process.

📝 Step 4 — Additional Instructions (Optional but Recommended)

The “Additional Instructions for the AI” field allows you to customize the model's behavior for each work session:

  • Indicate the dialect or language variant used in the text
  • Identify recurring abbreviations and their meanings
  • Specify whether stamps, marginal notes, or postage stamps should be ignored
  • Request that specific formulas be preserved

Practical examples:

  • “The names of the months are in nineteenth-century Sicilian dialect. Do not correct them.”
  • “Ignore margin stamps and red-pencil annotations.”
  • “The abbreviation 'f.' may mean 'son/daughter of'; 'fu' and 'q.' indicate that the named person was already deceased.”

Instruction archive: Frequently used instructions can be saved with the “+” button and retrieved from the “Saved Instructions” drop-down menu in subsequent sessions.

Saved instructions can be added, renamed, or deleted. The document type determines the base prompt: in addition to the included types, you can create, edit, or remove custom document profiles.

🎯 Assisted Calibration and Diagnostics (Optional)

Assisted calibration processes the upper portion of the first selected file, displays the result for correction, and uses the approved text as a reference for full processing. It helps verify the provider, model, document type, and instructions before starting a large batch.

The diagnostics option saves additional technical information about processing. Enable it when you need to investigate an error or provide information to the support team; review the content before sharing it, as it may include data relating to the document or request.

🎓 Step 5 — Reference Transcription (Few-Shot, Optional)

The “Reference Transcription” field provides the model with a contextual example of a correct transcription to use in the request. It does not train, modify, or update the model.

How to use it:

  1. Manually and accurately transcribe the first page (or the first few lines) of the register
  2. Paste the transcribed text into the “Reference Transcription” field
  3. Start OCR: the model will use that transcription as a guide for the rest of the document

Result: It may improve accuracy, especially with difficult cursive handwriting, unusual abbreviations, or local dialect terms; the effect depends on the provider, model, and document quality.
The “Clear Text” field (✖) clears the transcription and restores standard mode.

🔍 Step 6 — Interactive Review (Optional)

Selecting “Enable Interactive Review Window” activates an interactive mode that opens after each processing operation:

  • Left panel: original image with zoom (mouse wheel) and pan controls
  • Right panel: extracted OCR text, freely editable
  • “Approve and Generate File” button: saves the reviewed text in the selected formats
  • “Skip Page” button: discards the current processing result and moves to the next page

Useful for checking OCR quality in real time and correcting errors before final saving. For large batches, it is preferable to disable interactive review and correct the text afterward.

▶️ Step 7 — Start OCR

Click “Start OCR”. You will be prompted to select the destination folder for the output files.

The progress bar shows the progress (current file / total files). Processing takes place in a separate thread, so the interface remains responsive during processing.

During batch processing, ATK-Pro updates an ongoing transcription *_trascrizione_parziale.txt along with the associated metadata. If processing is interrupted, retain these files to recover what has already been transcribed; do not consider them final output until the batch has been completed and reviewed.

Upon completion, a dialog box will confirm that the process has finished or report any errors.

💡 Tips for Optimal Results

  • Image quality: Sharp images at 300+ DPI produce significantly better results. Avoid highly compressed JPEG images (artifacts).
  • Always Use Additional Instructions: Even a few lines of context significantly improve accuracy for documents written in dialect or unusual handwriting.
  • First page as a reference: Manually transcribe the first page and use the “Reference Transcription” field; the improvement on subsequent pages is often substantial.
  • Test batch: For large batches (100+ images), first run a test on 5-10 files with Interactive Review enabled before processing the entire batch.
  • TEI XML: Select the TEI XML format if you plan to deposit the transcription in academic digital archives or share it with other researchers.
  • Save the instructions: Each archival series has its own characteristics. Save a specific set of instructions for each register or fonds you process.
