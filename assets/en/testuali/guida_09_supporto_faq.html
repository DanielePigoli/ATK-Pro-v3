3. Troubleshooting and FAQ

────────────────────────────────────────────────────────────────────────────────

❓ FREQUENTLY ASKED QUESTIONS

🔵 Q: Does the program freeze while loading the manifest?

A: This is usually caused by a network timeout. Check:

  1. Check that your Internet connection works by opening a reliable page in your browser.
  2. Open the IIIF URL in your browser and copy it again from the address bar.
  3. Make sure your firewall or security software allows ATK-Pro to connect.
  4. If you use a proxy, check the operating system's network configuration.

If the problem persists, try a different URL to test the IIIF connection

🔵 Q: "File not found (404)"—what does it mean?

A: The manifest URL cannot be reached. Possible causes:

  • Expired URL (repository not updated)
  • Repository offline
  • Incorrect URL parameters (wrong manifest ID)

Solution: Check the URL in your browser before pasting it into ATK-Pro

🔵 Q: Is the download very slow or does it stop?

A: Try the following:

  1. Check Wi-Fi stability or use a wired connection if available.
  2. Try another public IIIF URL to determine whether the remote server is slow.
  3. Select the Light resource profile to reduce system load.
  4. If only one portal is affected, wait and try again later: the remote service may be congested or temporarily unavailable.

🔵 Q: Image reconstruction is slow—how can I speed it up?

A: Speed mainly depends on the IIIF server's response, image size, network performance, and the resources available on your computer.

  • Use the Light profile to reduce resource consumption, or Fast only on a suitable system.
  • Process registers with fewer pages at a time if memory or network capacity is under pressure.
  • Some portals require sequential access regardless of the selected profile.

🔵 Q: Is the output PDF corrupted or unable to open?

A: Try the following:

  1. Keep a copy for diagnosis, then remove or rename the incomplete PDF.
  2. Reload the record from Input File → Open Input and generate the PDF again.
  3. Make sure the destination is writable and has enough free space for the operation.
  4. Check the individual generated images to determine whether the problem affects only the PDF.

🔵 Q: How do I use TIFF files for archival purposes?

A: TIFF is a lossless format, making it ideal for preservation:

  1. Select TIFF as one of the image formats.
  2. ATK-Pro saves TIFF files using lossless LZW compression.
  3. Keep a copy on a separate storage device and periodically verify backup integrity.
  4. Long-term preservation also depends on storage media, redundant copies, and integrity checks—not only on the format.

🔵 Q: Can I process multiple records simultaneously (in parallel)?

A: Records in a batch are processed sequentially. Within an individual record, pages and tiles may be processed in parallel depending on the portal and resource profile.

  1. Prepare an input file containing all supported records, one after another.
  2. Select it from Input File → Open Input.
  3. Run Output → Process once.
  4. ATK-Pro automatically continues with the remaining records.

Example: If the input contains 5 records, ATK-Pro automatically processes:

  • Record 1 (download + reconstruction)
  • Record 2 (download + reconstruction)
  • ... through Record 5

Results are saved in the configured folders; you do not need to restart processing manually for each record.

🔵 Q: Where exactly are the files saved?

A: Default path:

  • Standard installation: the ATK-Pro/output folder in the user's Documents directory.
  • Portable mode: the output folder next to the executable.

You can change the destination from Settings → Select Output Folder. Default folders are created automatically whenever possible.

🔵 Q: Can I move the output files after processing?

A: Yes, final output files can be moved after processing.

After completion:

  1. Move the record folder to the new destination.
  2. The final PDF is self-contained; also preserve images and metadata if they are part of your working archive.
  3. If you plan to process the record again, keep the manifest and other source files.

🔵 Q: Sudden crashes—what should I do?

A: If the program crashes:

  1. Check atkpro.log or, when extended diagnostics are enabled, atkpro_debug.log. The location depends on the installation type: look next to the executable or in the application's working directory.
  2. Copy the error message or take a screenshot.
  3. Restart the program and repeat the operation.
  4. If the error recurs, try another IIIF record to distinguish a general issue from a manifest-specific problem.

⚠️ COMMON ERRORS AND SOLUTIONS

Error Cause Solution
"Network timeout" IIIF server is slow/offline Try again with a different URL
"Invalid IIIF format" The URL is not an IIIF Manifest Check the URL in your browser
"Disk space full" Insufficient disk space Free up space on the drive
"Permission denied" Protected/read-only folder Choose a folder belonging to your user account and make sure it is writable; avoid system or protected folders.
"URL not found (404)" Expired IIIF Manifest Check ID on the Portal
"Window not responding" Slow/resource-intensive processing Wait or click Cancel

🔵 Q: The portal is recognized, but the download is refused. Why?

A: Technical compatibility does not override access conditions. ATK-Pro refuses or restricts resources that require login or affiliated access, do not provide a stable public endpoint, are marked nodownload or do not have rights compatible with the requested operation. Open the item's public page, check the license and terms of use, and try only the supported official URL.

🔵 Q: Can I recover an interrupted OCR batch?

A: In the folder selected for OCR, check the file *_trascrizione_parziale.txt and the related metadata. They contain work saved progressively, which must be reviewed and completed before it can be considered final.
