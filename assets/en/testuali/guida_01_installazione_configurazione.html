1. INSTALLATION AND REQUIREMENTS

────────────────────────────────────────────────────────────────────────────────

OPERATING SYSTEM

  • Windows: Windows 10 or later (64-bit) — Professional, Home, Server
  • Linux: Ubuntu 20.04+ or compatible distributions (.deb package or .tar.gz archive)
  • macOS: macOS 11 Big Sur or later — .dmg distribution (testing on physical hardware is underway)
  • 64-bit is mandatory on all platforms
  • At least 2 GB of available RAM (4 GB recommended for batch processing)
  • 1 GB of free disk space

INSTALLATION

🪟 Windows

  1. Download ATK-Pro-Setup-vx.x.x.exe from the official Releases page
  2. Double-click the installer file
  3. Select "Run as administrator" if prompted
  4. Follow the setup wizard (Next → Next → Install)
  5. During installation, you will be prompted to select a language (20 available)
  6. When installation is complete, check "Launch ATK-Pro" to start the program
  7. Accept any Windows Firewall/Defender alerts

🐧 Linux

  1. Download ATK-Pro-vx.x.x.deb (Debian/Ubuntu) or .tar.gz from the Releases page
  2. .deb package: sudo dpkg -i ATK-Pro-vx.x.x.deb or double-click it in Nautilus/Files
  3. .tar.gz archive: extract and launch ./ATK-Pro from the extracted folder
  4. The language is selected on first launch and saved in the user configuration file

🍎 macOS

  1. Download ATK-Pro-vx.x.x.dmg from the Releases page
  2. Open the .dmg file and drag ATK-Pro into the Applications folder
  3. On first startup: right-click → Open (required for applications that have not been notarized)
  4. The language is selected on first launch and saved in the user configuration file

DEFAULT LOCATIONS

🪟 Windows

  • Program: C:\Program Files\ATK-Pro\
  • User output: C:\Users\[YourName]\Documents\ATK-Pro\output\
  • Input (optional): C:\Users\[YourName]\Documents\ATK-Pro\input\

🐧 Linux

  • Program: /opt/ATK-Pro/ (.deb) or extracted folder (.tar.gz)
  • User output: ~/Documents/ATK-Pro/output/
  • Input (optional): ~/Documents/ATK-Pro/input/

🍎 macOS

  • Program: /Applications/ATK-Pro.app
  • User output: ~/Documents/ATK-Pro/output/
  • Input (optional): ~/Documents/ATK-Pro/input/

NETWORK REQUIREMENTS

  • Stable Internet connection (required to access IIIF Manifests)
  • Firewall: Allow outbound HTTPS connections (port 443)
  • Corporate proxy: ATK-Pro does not provide an internal menu for proxy credentials. Configure the proxy in the operating system or network environment and confirm with the administrator that HTTPS connections to the portals are allowed.

📂 FOLDER CONFIGURATION

When run for the first time, the program automatically creates the following folders:

  • Windows: C:\Users\[YourName]\Documents\ATK-Pro\output\
  • Windows: C:\Users\[YourName]\Documents\ATK-Pro\output\doc\ (default for documents)
  • Windows: C:\Users\[YourName]\Documents\ATK-Pro\output\reg\ (default for registers)
  • Linux/macOS: corresponding folders under ~/Documents/ATK-Pro/output/
  • A corresponding input/ folder is also available (optional, for input files)

During processing, temporary folders are created for the downloaded tiles (tiles_canvas_X/) and, if a PDF is requested, temporary files are created to generate it.

All temporary folders and files are automatically deleted when processing is complete.

Only the final processed files remain (images in the selected formats, PDF, manifests, and metadata).

To change the output folders, use Menu → Settings → "Select output folders". Your selections are saved and automatically restored in the next session.

⚙️ RESOURCE PROFILE

The command Settings → Resource profile adjusts the parallelism used during downloads, image reconstruction, and PDF generation:

  • Light: limits concurrent processes and memory usage spikes; recommended for less powerful computers or very long processing tasks.
  • Balanced: the default compromise between speed and stability, suitable for most cases.
  • Fast: uses more resources to reduce processing time; select it only on sufficiently powerful computers.

The profile does not alter the quality, rights, or quantity of the acquired documents. Portal-specific precautionary limits continue to take precedence.

3. MAIN INTERFACE

────────────────────────────────────────────────────────────────────────────────

WINDOW LAYOUT

The main Antenati Toolkit Pro window has a simple and intuitive structure.

📝 HEADER LEGEND:

  • [🔲] Program icon (Antenati Toolkit Pro logo)
  • "ATK-Pro" Window title
  • [_] Minimize (minimizes the window)
  • [□] Expand/Collapse (maximizes or restores the window)
  • [✕] Close (exits the program and displays a support banner)

At the bottom is the Latin motto “Qui ante nos venerunt, in memoria nostra vivunt,” recalling the importance of roots and collective memory.

MENU BAR

At the top of the window, below the header:

[Input files] [Output] [Services] [Documents] [Settings]

Each menu contains specific buttons and options (see the next section).

AVAILABLE MENUS

1. INPUT FILE

Manages the loading of IIIF records:

├─ Sample input
│  └─ Displays the sample file (shows the pair format: D/R mode + URL)
├─ Open input
│  └─ Selects a .txt file containing your IIIF records
│     (It must contain pairs: D/R mode on line 1, URL on line 2)
└─ Edit input
   └─ Edits the currently loaded input file
      (Add/remove records, change URLs, save changes)

2. OUTPUT

Manages processing and output:

├─ Process
│  └─ Starts downloading, reconstructing, and saving the images
│     (Displays a real-time progress window)
├─ Open output folder
│  └─ Opens the folder containing the processed files in File Explorer
└─ View previous processing jobs
   └─ Lists records that have already been processed

3. SERVICES

List of integrated services:

├─ AI-assisted research
│  └─ Suggests portals, research leads, and genealogical queries to verify
├─ Image Viewer
│  └─ Viewer for downloaded images and/or generated PDFs
├─ JSON Metadata Viewer
│  └─ Original JSON files and metadata (genealogical, technical, EXIF)
├─ Advanced OCR
│  └─ Nineteenth-century handwritten texts, ecclesiastical Latin, and late medieval texts
├─ OCR Translation
│  └─ Automatically translates extracted texts into the selected languages
└─ GEDCOM Export
   └─ GEDCOM, Gramps, Family Tree Maker, Ancestry, MyHeritage, WikiTree, etc.

4. DOCUMENTS

Access to resources and documentation:

├─ Disclaimer - Legal clauses and terms of use
├─ About the author - Background of the project's author
├─ Project overview - History, motivations, and ATK-Pro roadmap
├─ Guide - Main index of the modular guide
└─ Information - Version, copyright, and contact email

5. SETTINGS

General program configuration:

├─ Change language
│  └─ Selects the interface language (restart required)
├─ Select image formats
│  └─ Selects from PNG, JPG, TIFF, and PDF (at least 1 is required)
│     PDF may be selected on its own or together with image formats
│     The selection is saved and automatically preselected in the next session
├─ Select output folders
│  └─ First opens the folder mode selection, followed by the folder selection windows:
│     • Single folder for all       → one folder for both documents and registers
│     • Separate doc/reg folders    → one folder for all documents and one for all registers
│     • Folder for each record      → a separate folder for each record
│     The mode and folders are saved and restored in the next session
├─ Export configuration
│  └─ Saves the current settings to a file
├─ Import configuration
│  └─ Loads a previously saved settings file (restores all preferences and paths)
├─ Check for updates
│  └─ Checks whether new versions of the program are available
└─ Close
    └─ Exits the program (displays the PayPal.me support banner)
