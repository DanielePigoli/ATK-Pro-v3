📌 Overview

The JSON Metadata Viewing feature in ATK-Pro is designed to display JSON files generated during document processing. It can be opened from the application's Services → JSON Metadata Viewing menu.

The viewer opens valid JSON files structured as objects, including sidecars generated by ATK-Pro. It automatically searches the same folder for an image with the same name (extensions: .jpg, .jpeg, .png, .tif, .tiff) and, if found, displays it in the right-hand panel.

If the file does not contain valid JSON or cannot be read, the application displays “Unable to read JSON file”.

🌳️ Interface

The window is divided into two side-by-side panels:

Left Panel — Metadata Table

The data in the JSON file is displayed as a two-column table:

  • Field: the name of the JSON key
  • Value: the corresponding value

Only top-level JSON fields are displayed. Fields whose names begin with _ (underscore) are omitted because they are reserved for internal use. Nested structures, such as objects or arrays, appear as text in the Value column rather than as expandable levels.

Right Panel — Image Preview

If a matching image is found, it is loaded with the same features as Image Viewing (mouse-wheel zoom, +/− buttons, Fit to window, 1:1, and drag-to-pan).

If no matching image is found, the panel displays “No matching image found”.

Showing and Hiding the Panel

  • “◄ Hide Metadata” button: Hides the left-hand metadata panel
  • “► Show Metadata” button: Restores the metadata panel
