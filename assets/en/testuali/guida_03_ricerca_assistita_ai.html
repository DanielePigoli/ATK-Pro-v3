📚 Module 03: AI-Assisted Search

📌 Overview

The AI-Assisted Search feature helps turn a genealogical question into a more organized research plan: it suggests portals, research avenues, filters, and sample queries to try manually against the available sources.

It opens from the Services -> AI-Assisted Search menu. It does not download documents or replace direct consultation of the portals: it provides practical guidance that must be verified, cited, and used with sound archival judgment.

🔍 When to Use It

  • When you start with surnames, places, and time periods but do not know which archives or portals to check first.
  • When you want to set up a search covering multiple countries, for example regarding Italian emigration to the Americas, Europe, or Oceania.
  • When you want to obtain sample queries and filters to copy into institutional portals.
  • When you need to compare alternative strategies for birth, baptism, marriage, death, military conscription, immigration, or citizenship records.

Note: results generated by an AI model are working hypotheses. They must always be verified against official sources and do not constitute genealogical evidence.

🖥️ Main Fields

Search Query

Enter the subject, place, time period, and source type. A useful example is: Rossi and Bianchi in Florence and Prato, 1850–1900, baptisms and marriages.

The more specific the request, the more useful the guidance will be: avoid overly general wording and always indicate any migrations, surname variants, or relevant historical regions.

AI Provider and Optional Model

The provider menu allows you to choose which AI service to use from those configured in the application. The optional model field is only needed if you want to specify a particular model supported by the selected provider; otherwise, it can be left blank.

Standard Prompt

The feature includes four predefined templates:

  • Detailed general search, for an initial broad survey.
  • Detailed international strategies, useful for migration paths and research outside Italy.
  • Detailed search for specific records, when you are looking for a specific type of record.
  • Advanced search with filters, when you want more structured filters, variants, and queries.

Multi-Provider

The Process with all available providers (multi-provider) option is enabled by default. If multiple keys are stored in the vault, ATK-Pro can query multiple providers and compare the results. You can disable it when you want to use only the selected provider.

📝 Personal Notes

The notes section allows you to save recurring instructions to add to the request, such as surname variants, historical boundaries, known parishes, archives already checked, or criteria to exclude.

You can create a new note, save it, retrieve it from the list, or delete it. The selected note is added to the final prompt sent to the AI provider.

💾 Results and Saving

Click SUGGEST PORTALS AND QUERIES to start processing. During processing, the window displays the status of the provider and the key slot being used.

Results can be grouped by portal, rationale, sample query, period, record type, or filters/strategies. After generation, you can save the output in text or HTML format using the buttons SAVE AI RESULTS and SAVE HTML RESULT.

🔑 Key Vault

The button MANAGE KEY VAULT (CSV) opens key management for the configured providers. The search function uses only providers for which a valid key or compatible local configuration is available.

⚠️ Operational Limitations

  • The function does not bypass logins, paywalls, technical restrictions, or portal terms of use.
  • Suggestions must be verified on the official portal before being included in documented research.
  • The availability of AI providers and models may vary over time.
  • For sensitive research, always keep a record of the sources actually consulted, not merely the AI suggestion.
