🔮 Module 08: GEDCOM Export

📌 Overview

The GEDCOM Export module in v3 is an assisted genealogical analysis environment: it processes selected texts, images, or documents, uses an AI provider configured in ATK-Pro, and generates a .ged file together with two supporting CSV files.

It can be opened from the Services → GEDCOM Export menu. Its public name remains tied to the GEDCOM format, but its actual functionality also includes genealogical data extraction, the use of paleographic notes, optional expansion of an existing database, and AI key management.

The result must be verified before importing it into genealogy software: AI can help structure data and relationships, but it is no substitute for a critical reading of the sources.

🖥️ Interface

1. Method and Universal Input

The first section allows you to choose a method preference and the files to be analyzed. The Auto-Discovery, AI Vision, and LLM Refinery options are saved as a preference, but in the current version they do not activate three separate pipelines: actual processing depends mainly on the file type.

  • TXT and DOCX: these files are read through the dedicated text pipeline and included in the prompt as transcriptions.
  • Other inputs: these are sent to the selected provider through the available extraction workflow.
  • Selectable formats: .pdf, .docx, .jpg, .jpeg, .png, .webp, .tiff, .tif, .bmp, .txt, .json, and .csv.

2. Expand an Existing Database

The LOAD DATABASE button allows you to select an existing genealogical database in GEDCOM or CSV format. If you do not load one, the module creates a new project. When you load a database, the result is automatically saved in the folder containing it, even if you previously selected a different destination.

3. Paleographic Notes Database

This section links the genealogical work to document types and operational notes. You can select the type of record, retrieve a saved note, create a new one, edit it, or delete it.

The notes are used to explain abbreviations, local formulas, the document's language, kinship rules, uncertain readings, or extraction criteria to the model.

4. Output Destination

Choose the folder in which to save the result. If an existing database has been loaded, its folder is used instead. The module generates a genealogia_*.ged file in GEDCOM 5.5.1 format and two supporting files with the same base name: *_REVISIONE.csv and *_REGISTRO_ORIGINALE.csv.

5. AI Engine and Key Vault

  • Provider: choose the AI service from those configured, such as Claude, OpenAI, Gemini, Mistral, xAI, DeepSeek, Groq, HuggingFace, or Ollama.
  • Model override: optional field for specifying a particular model supported by the selected provider; it is hidden when Gemini is selected.
  • MANAGE KEY VAULT (CSV): opens the key vault CSV file directly.
  • START FULL EXTRACTION: starts the analysis and generation of the GEDCOM.

You can create and remove custom document types. For built-in types, you can override the prompt, but you cannot delete the document type.

📝 Recommended workflow

  1. Prepare legible input: transcriptions, images, or files already organized by record.
  2. Choose the method preference best suited to the material, keeping in mind that the current version does not use it to select a separate pipeline.
  3. If you are continuing existing work, upload the GEDCOM or CSV database.
  4. Select the record type and add a specific paleographic note.
  5. Choose the output folder, provider, and key.
  6. Start the full extraction.
  7. Review the generated file .ged before importing it into other programs.

⚠️ Warnings

  • The resulting GEDCOM is a working draft, not definitive evidence.
  • Family relationships, dates, places, and names must be verified against the original sources.
  • OCR, transcription, or interpretation errors may propagate into the genealogy file.
  • Before importing the GEDCOM into external software, keep a copy of the original file and check for duplicates.
  • Do not send confidential or restricted documents to external providers without first reviewing the terms of use, privacy provisions, and required authorizations.
