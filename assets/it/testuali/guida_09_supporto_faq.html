3. Troubleshooting e FAQ

────────────────────────────────────────────────────────────────────────────────

❓ DOMANDE FREQUENTI

🔵 P: Il programma si blocca al caricamento manifest?

R: Solitamente è timeout di rete. Verifica:

  1. Verifica che la connessione Internet funzioni aprendo una pagina affidabile nel browser.
  2. Apri l'URL IIIF nel browser e copialo nuovamente dalla barra degli indirizzi.
  3. Controlla che firewall o software di sicurezza consentano le connessioni di ATK-Pro.
  4. Se usi una rete con proxy, verifica la configurazione di rete del sistema operativo.

Se problema persiste, prova con URL diverso per testare connessione IIIF

🔵 P: "File non trovato (404)" - cosa significa?

R: L'URL del manifest non è raggiungibile. Cause:

  • URL scaduto (repository non aggiornato)
  • Repository offline
  • Parametri URL errati (ID manifest sbagliato)

Soluzione: Verifica URL in browser prima di incollare in ATK-Pro

🔵 P: Download molto lento o si interrompe?

R: Prova:

  1. Verifica la stabilità della rete Wi-Fi o usa una connessione cablata, se disponibile.
  2. Prova un altro URL IIIF pubblico per capire se il rallentamento dipende dal server.
  3. Riduci il carico scegliendo il profilo risorse Leggero.
  4. Se il problema riguarda un solo portale, attendi e riprova: il servizio remoto potrebbe essere congestionato o temporaneamente indisponibile.

🔵 P: Ricostruzione immagini lenta - come accelerare?

R: La velocità dipende principalmente dalla risposta del server IIIF, dalla dimensione delle immagini, dalla connessione e dalle risorse disponibili sul computer.

  • Usa il profilo Leggero per ridurre il consumo di risorse o Veloce solo su sistemi adeguati.
  • Elabora registri con meno pagine per volta se memoria o rete sono sotto pressione.
  • Ricorda che alcuni portali impongono un accesso sequenziale indipendentemente dal profilo scelto.

🔵 P: Output PDF è corrotto o non apre?

R: Prova:

  1. Conserva una copia utile alla diagnosi, quindi rimuovi o rinomina il PDF incompleto.
  2. Ricarica il record da File input → Apri input e rigenera il PDF.
  3. Verifica che la destinazione sia scrivibile e disponga di spazio sufficiente per l'elaborazione.
  4. Controlla le singole immagini generate per capire se il problema riguarda solo il PDF.

🔵 P: Come utilizzo i file TIFF per archivio?

R: TIFF è formato lossless, perfetto per conservazione:

  1. Seleziona TIFF tra i formati immagine.
  2. ATK-Pro salva i TIFF con compressione lossless LZW.
  3. Conserva una copia su un supporto distinto e verifica periodicamente l'integrità del backup.
  4. La conservazione nel tempo dipende anche da supporti, copie e controlli d'integrità, non soltanto dal formato.

🔵 P: Posso elaborare più record contemporaneamente (in parallelo)?

R: I record di un batch vengono elaborati in sequenza. All'interno del singolo record, pagine e tile possono essere elaborati in parallelo secondo il portale e il profilo risorse.

  1. Prepara un file di input con tutti i record supportati, uno dopo l'altro.
  2. Selezionalo da File input → Apri input.
  3. Avvia una sola volta Output → Elabora.
  4. ATK-Pro prosegue automaticamente con i record successivi.

Esempio: Se input contiene 5 record, ATK-Pro processa automaticamente:

  • Record 1 (download + ricostruzione)
  • Record 2 (download + ricostruzione)
  • ... fino a Record 5

I risultati vengono salvati nelle cartelle configurate; non è necessario riavviare manualmente l'elaborazione per ogni record.

🔵 P: File si salvano dove esattamente?

R: Percorso default:

  • Installazione standard: cartella ATK-Pro/output nei Documenti dell'utente.
  • Modalità portatile: cartella output accanto all'eseguibile.

Puoi cambiare destinazione da Impostazioni → Seleziona cartella output. Le cartelle predefinite vengono create automaticamente quando possibile.

🔵 P: Posso spostare file output dopo elaborazione?

R: Sì, i file finali possono essere spostati dopo l'elaborazione.

Dopo completamento:

  1. Sposta la cartella del record nella nuova destinazione.
  2. Il PDF finale è autonomo; conserva anche immagini e metadati se fanno parte del tuo archivio di lavoro.
  3. Se prevedi di rielaborare il record, conserva il manifest e gli altri file sorgente.

🔵 P: Crashes improvvisi - cosa fare?

R: Se il programma crasha:

  1. Controlla atkpro.log oppure, con diagnostica estesa attiva, atkpro_debug.log. La posizione dipende dal tipo di installazione: cerca accanto all'eseguibile o nella directory di lavoro dell'applicazione.
  2. Copia il messaggio di errore o acquisisci uno screenshot.
  3. Riavvia il programma e ripeti l'operazione.
  4. Se l'errore si ripete, prova un altro record IIIF per distinguere un problema generale da uno specifico del manifest.

⚠️ ERRORI COMUNI E SOLUZIONI

Errore Causa Soluzione
"Network timeout" Server IIIF lento/offline Riprova con URL diverso
"Invalid IIIF format" URL non è Manifest IIIF Verifica URL in browser
"Disk space full" Spazio disco insufficiente Libera spazio su unità
"Permission denied" Cartella protetta/Read-only Scegli una cartella appartenente al tuo utente e verifica che sia scrivibile; evita cartelle di sistema o protette.
"URL not found (404)" Manifest IIIF scaduto Controlla ID nel Portale
"Window not responding" Elaborazione lenta/pesante Aspetta o clicca Annulla

🔵 P: Il portale è riconosciuto ma il download viene rifiutato. Perché?

R: La compatibilità tecnica non elimina le condizioni di accesso. ATK-Pro rifiuta o limita risorse che richiedono login o accesso affiliato, non espongono un endpoint pubblico stabile, sono marcate nodownload oppure non presentano diritti compatibili con l'operazione richiesta. Apri la pagina pubblica dell'oggetto, controlla licenza e condizioni d'uso e prova solo con l'URL ufficiale supportato.

🔵 P: Posso recuperare un batch OCR interrotto?

R: Controlla nella cartella scelta per l'OCR il file *_trascrizione_parziale.txt e i relativi metadati. Contengono il lavoro salvato progressivamente, da verificare e completare prima di considerarlo definitivo.
