📌 Panoramica

Il modulo Esportazione GEDCOM della v3 è un ambiente di analisi genealogica assistita: prende testi, immagini o documenti selezionati, usa un provider IA configurato in ATK-Pro e genera un file .ged con due file CSV di supporto.

Si apre dal menu Servizi → Esportazione GEDCOM. Il nome pubblico resta legato al formato GEDCOM, ma il lavoro effettivo comprende anche estrazione genealogica, uso di note paleografiche, eventuale incremento di una base esistente e gestione delle chiavi IA.

Il risultato deve essere verificato prima di importarlo in un software genealogico: l'IA può aiutare a strutturare dati e relazioni, ma non sostituisce la lettura critica delle fonti.

🖥️ Interfaccia

1. Metodo e input universale

La prima sezione permette di scegliere un'indicazione di metodo e i file da analizzare. Le opzioni Auto-Discovery, Vision IA e Refinery LLM sono memorizzate come preferenza, ma nella versione corrente non attivano tre pipeline distinte: il trattamento effettivo dipende principalmente dal tipo di file.

  • TXT e DOCX: vengono letti attraverso la pipeline testuale dedicata e inseriti nel prompt come trascrizioni.
  • Altri input: vengono inoltrati al provider selezionato secondo il flusso di estrazione disponibile.
  • Formati selezionabili: .pdf, .docx, .jpg, .jpeg, .png, .webp, .tiff, .tif, .bmp, .txt, .json e .csv.

2. Incrementa base esistente

Il pulsante CARICA BASE consente di indicare una base genealogica già esistente in formato GEDCOM o CSV. Se non carichi nulla, il modulo crea un nuovo lavoro. Quando carichi una base, il risultato viene salvato automaticamente nella cartella che la contiene, anche se in precedenza avevi scelto un'altra destinazione.

3. Banca dati note paleografiche

Questa sezione collega il lavoro genealogico alle tipologie documentali e alle note operative. Puoi scegliere il tipo di atto, richiamare una nota salvata, crearne una nuova, modificarla o eliminarla.

Le note servono a spiegare al modello abbreviazioni, formule locali, lingua del documento, regole di parentela, dubbi di lettura o criteri di estrazione.

4. Destinazione output

Scegli la cartella in cui salvare il risultato. Se è stata caricata una base esistente, viene invece usata la cartella della base. Il modulo genera un file genealogia_*.ged in formato GEDCOM 5.5.1 e due file di supporto con lo stesso nome base: *_REVISIONE.csv e *_REGISTRO_ORIGINALE.csv.

5. Motore IA e caveau chiavi

  • Provider: scegli il servizio IA tra quelli configurati, ad esempio Claude, OpenAI, Gemini, Mistral, xAI, DeepSeek, Groq, HuggingFace o Ollama.
  • Override modello: campo opzionale per indicare un modello specifico supportato dal provider scelto; viene nascosto quando il provider è Gemini.
  • GESTISCI CAVEAU CHIAVI (CSV): apre direttamente il file CSV del caveau.
  • AVVIA ESTRAZIONE COMPLETA: avvia l'analisi e la generazione del GEDCOM.

Puoi creare e rimuovere tipologie documentali personalizzate. Per le tipologie integrate puoi modificare il prompt tramite override, ma non eliminare la tipologia.

📝 Flusso consigliato

  1. Prepara input leggibili: trascrizioni, immagini o file già organizzati per atto.
  2. Scegli l'indicazione di metodo più adatta al materiale, tenendo presente che nella versione corrente non seleziona una pipeline distinta.
  3. Se stai proseguendo un lavoro esistente, carica la base GEDCOM o CSV.
  4. Seleziona la tipologia di atto e aggiungi una nota paleografica concreta.
  5. Scegli cartella di output, provider e chiave.
  6. Avvia l'estrazione completa.
  7. Controlla il file .ged generato prima di importarlo in altri programmi.

⚠️ Avvertenze

  • Il GEDCOM prodotto è una base di lavoro, non una prova definitiva.
  • Relazioni familiari, date, luoghi e nomi devono essere verificati sulle fonti originali.
  • Gli errori di OCR, trascrizione o interpretazione possono propagarsi nel file genealogico.
  • Prima di importare il GEDCOM in software esterni, conserva una copia del file originale e controlla eventuali duplicati.
  • Non inviare a provider esterni documenti riservati o soggetti a restrizioni senza aver verificato condizioni d'uso, privacy e autorizzazioni.
