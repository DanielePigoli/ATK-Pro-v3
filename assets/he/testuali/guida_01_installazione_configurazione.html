1. התקנה ודרישות

────────────────────────────────────────────────────────────────────────────────

מערכת הפעלה

  • Windows: Windows 10 ואילך (64 סיביות) - Professional, Home, Server, Server
  • Linux: Ubuntu 20.04+ או התפלגות תואמת (חבילת deb או .tar.gz Archives)
  • macOS: macOS 11 Big Sur או מאוחר יותר - .dmg הפצה (חומרה אמיתית בהתקדמות)
  • 64 סיביות חובה על כל הפלטפורמות
  • לפחות 2 GB של RAM זמין (4 GB מומלץ לעיבוד אצווה)
  • 1 GB של שטח דיסק חופשי

ההתקנה

Windows

  1. הורד Download ATK-Pro-Setup-vx.x.x.exe דף השחרור הרשמי
  2. לחץ כפול על קובץ ההתקנה
  3. בחר "Execute with adminrights" אם נדרש
  4. עקבו אחרי The Wizard (Next)
  5. בחירת השפה (20 זמין) תתבקש במהלך ההתקנה
  6. בסוף, בדוק את "Start ATK-Pro" כדי להתחיל את התוכנית.
  7. קבלו התראות מ- Windows Firewall/Defender

Linux

  1. הורד Download ATK-Pro-vx.x.x.deb (Debian/Ubuntu) או .tar.gz דף השחרור
  2. חבילה: sudo dpkg -i ATK-Pro-vx.x.x.deb לחץ כפול ב Nautilus/Files
  3. ארכיון התגים: בחוץ ולהתחיל ./ATK-Pro מתוך תיקיה מופקת
  4. השפה נבחרת בהתחלה ונ הצילה בקובץ הגדרות המשתמש

macOS

  1. הורד Download ATK-Pro-vx.x.x.dmg דף השחרור
  2. פתח את קובץ .dmg וגרור ATK-Pro לתיקית היישומים
  3. בהתחלה: לחיצה נכונה על Open (נדרש עבור יישומים לא מובנים)
  4. השפה נבחרת בהתחלה ונ הצילה בקובץ הגדרות המשתמש

עמדות ברירת מחדל

Windows

  • תוכנית: C:\Program Files\ATK-Pro\
  • יצרן: C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • Input (אופציונלי): C:\Users\[TuoNome]\Documents\ATK-Pro\input\

Linux

  • תוכנית: /opt/ATK-Pro/ (deb) או תיקיה מופקת (.tar.gz)
  • יצרן: ~/Documents/ATK-Pro/output/
  • Input (אופציונלי): ~/Documents/ATK-Pro/input/

macOS

  • תוכנית: /Applications/ATK-Pro.app
  • יצרן: ~/Documents/ATK-Pro/output/
  • Input (אופציונלי): ~/Documents/ATK-Pro/input/

דרישות רשת

  • חיבור לאינטרנט (מבקש לגשת IIIF Manifests)
  • חומת האש: מאפשר חיבורי HTTPS מרוחקים (פורט 443)
  • החברה Proxy: ATK-Pro אין תפריט פנימי עבור אישורי Proxy. הגדר את הפרוקסי במערכת ההפעלה או בסביבת הרשת ולוודא עם המנהל כי חיבורי HTTPS פורטלים מותר.

תצורת תיקיות URAZIONE

כאשר אתה מפעיל לראשונה, התוכנית יוצרת באופן אוטומטי את התיקיות הבאות:

  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\doc\ (מסמכים מוגדרים)
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\reg\ (רישום הגנה)
  • Linux/macOS: דומה למטה ~/Documents/ATK-Pro/output/
  • Folder input\ אנלוגיה (אופציונלית, עבור קלט קובץ)

בעוד עיבוד תיקיות זמניות נוצרות עבור אריח מופחת (tiles_canvas_X/(ואם נדרש, PDF, קבצים זמניים לדור שלה.

כל התיקיות והקבצים זמניים נמחקים באופן אוטומטי בסוף העיבוד.

רק קבצים סופיים מעובדים נשארים (תמונות בפורמטים נבחרים, PDF, ביטויים ומטא-נתונים).

כדי לשנות את תיקיות הפלט להשתמש בהגדרות "Select פלט תיקיות". הבחירות מאוחסנות ושוחזרות באופן אוטומטי לפגישה הבאה.

פרופיל משאבים PROFILO

הפקודה פרופיל משאבים מווסת את המקבילה בשימוש במהלך הורדה, שחזור תמונות ודור של PDF:

  • משקל אור: הגבלות על תהליכים עכשוויים ועל שיאי זיכרון; הצביעו על מחשבים פחות חזקים או עיבוד ארוך מאוד.
  • איזון: פשרת ברירת מחדל בין מהירות ויציבות, מתאימה לרוב המקרים.
  • מהיר: השתמש יותר משאבים כדי להפחית את הזמן; לבחור אותו רק במחשבים מספיק טוב.

הפרופיל אינו משנה את האיכות, זכויות או כמות המסמכים שנרכשו. הגבולות המיוחדים של פורטל ממשיכים להיות precedence.

תפריט

בראש החלון, מתחת לראש:

[מקור] [Output] [שירותים] [סעיפים] [הגדרות]

כל תפריט מכיל כפתורים ספציפיים ואפשרויות (ראה סעיף הבא).

תפריט זמין

1 קובץ

נהל את הטעינה של רשומות IIIF:

├─ Esempio input
│  └─ Visualizza il file di esempio (mostra formato coppie: modalità D/R + URL)
├─ Apri input
│  └─ Seleziona un file .txt con i tuoi record IIIF
│     (Deve contenere coppie: modalità D/R su riga 1, URL su riga 2)
└─ Modifica input
   └─ Modifica il file input attualmente caricato
      (Aggiungi/rimuovi record, cambia URL, salva modifiche)

2 תפוקה

ניהול עיבוד ופלט:

├─ Elabora
│  └─ Avvia il download, la ricostruzione e il salvataggio delle immagini
│     (Mostra finestra di progresso in tempo reale)
├─ Apri cartella output
│  └─ Apre in Esplora Risorse la cartella con i file elaborati
└─ Visualizza elaborazioni precedenti
   └─ Lista dei record già elaborati

3.שירות

רשימת השירותים המשולבים:

├─ Ricerca assistita AI
│  └─ Suggerisce portali, piste di ricerca e query genealogiche da verificare
├─ Visualizzazione Immagini
│  └─ Viewer immagini scaricate e/o PDF generati
├─ Visualizzazione Metadati JSON
│  └─ JSON originali e metadati (genealogici, tecnici, EXIF)
├─ OCR Avanzato
│  └─ Testi manoscritti ottocenteschi, latino ecclesiastico, tardo-medievali
├─ Traduzione OCR
│  └─ Traduzione automatica testi estratti nelle lingue selezionate
└─ Esportazione GEDCOM
   └─ GEDCOM, Gramps, Family Tree Maker, Ancestry, MyHeritage, WikiTree, etc.

4 מסמכים

גישה למקורות ולתיעוד:

├─ Disclaimer - Clausole legali e termini d'uso
├─ Presentazione autore - Background dell'autore del progetto
├─ Presentazione progetto - Storia, motivazioni, roadmap di ATK-Pro
├─ Guida - Indice principale della guida modulare
└─ Informazioni - Versione, copyright, email di contatto

5 הגדרות

תצורה כללית של התוכנית:

├─ Cambia lingua
│  └─ Seleziona la lingua dell'interfaccia (richiede riavvio)
├─ Seleziona formati immagine
│  └─ Scegli tra PNG, JPG, TIFF e PDF (almeno 1 obbligatorio)
│     PDF può essere selezionato da solo o insieme ai formati immagine
│     La scelta viene memorizzata e pre-selezionata automaticamente alla sessione successiva
├─ Seleziona cartelle output
│  └─ Apre prima la scelta della modalità cartelle, poi le finestre di selezione:
│     • Cartella unica per tutti    → una sola cartella per documenti e registri
│     • Cartelle separate doc/reg   → una cartella per tutti i doc, una per tutti i reg
│     • Cartella per ogni record    → una cartella distinta per ciascun record
│     La modalità e le cartelle vengono memorizzate e ripristinate alla sessione successiva
├─ Esporta configurazione
│  └─ Salva le impostazioni attuali in un file
├─ Importa configurazione
│  └─ Carica un file di impostazioni precedentemente salvato (ripristina tutte le preferenze e percorsi)
├─ Verifica aggiornamenti
│  └─ Controlla la disponibilità di nuove versioni del programma
└─ Chiudi
    └─ Termina il programma (mostra banner di supporto PayPal.me)
