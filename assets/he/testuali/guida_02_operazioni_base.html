מבנה קלט ופורטלים נתמך

ATK-Pro מקבל קבצים קלט עם פורמט מבוסס COPPIE ספציפי: עבור רשומות OGNI כדי לעבד, לספק מצב + URL.

פורטלים תומכים: העתק ודבק הציבור URL של הדף, הצופה, פוסטר או תואם PDF. ATK-Pro מזהה את הפורטל ומיישם את מצבו הטכני והפילוסופי.

תמיכה מצביע על תאימות טכנית מאומתת, לא רשות חסרת הבחנה להוריד. המשאב חייב להיות נגיש לציבור והמשתמש חייב לכבד את הזכויות, הרישיונות, תנאי השימוש והמגבלות של הפורטל הבודד. ATK-Pro אינו עקף כניסה, גישה מזוהה, מחסני תשלום או סמנים nodownload.

שמור שיא

לאחר טעינת פוסטר, התוכנית חוסכת באופן אוטומטי IIIF metadata. בתיקייה הפלט שתבחר (ראה סעיף 2, PASSO 2) פעילות גופנית (לפני עיבוד):

[cartella_output]/
 ├─ manifest_[ID]_[nome].json         ← Manifest IIIF originale (livello principale)
 └─ [nome]/                            ← Sottocartella SOLO per metadati
    ├─ [nome]_genealogico.json        ← Metadati genealogici estratti
    └─ [nome]_tecnico.json            ← Metadati tecnici (canvas ID, numero pagine)

DOPO L'ELABORAZIONE (כאשר לחיצה על התפריט) Output ברמה העיקרית מוסיפים קבצים מעובדים:

[cartella_output]/
 ├─ manifest_[ID]_[nome].json         ← Manifest IIIF originale
 ├─ [nome]_canvas_1.jpg/.png/.tif     ← Immagini ricostruite dai tile IIIF (una per pagina)
 ├─ [nome]_canvas_2.jpg/.png/.tif       (formato dipende da quello selezionato)
 ├─ [nome]_canvas_N.jpg/.png/.tif       (N = numero totale di pagine/canvas)
 ├─ [nome].json                        ← Sidecar JSON per ogni immagine (metadati EXIF)
 └─ [nome].pdf                         ← PDF completo (vedi spiegazione sotto)

מטא-נתונים נשארים ב- subfolder (שם) / כפי שמורים לטעינה.

PDF - דור אוטומטי במהלך עיבוד

אם בחרת PDF בתבנית בחירת המסכה (PASSO 1), PDF מיוצר באופן אוטומטי בסוף ההורדה של כל רישום או מסמך, ללא כל חלון אישור נוסף.

התנהגות ייצוגית:

  • ✅ PDF נבחר במסכת הפורמט: PDF מיוצר באופן אוטומטי בסוף ההורדה; לא נדרשת אישור נוסף.
  • ❌ PDF לא נבחר: רק תמונות בפורמטים נבחרים, לא PDF

תכונות PDF נוצרו:

  • שם קובץ: [nome].pdfללא suffixes נוספים (למשל. Registro Matrimoni 1920.pdf)
  • נשמר בתיקיה הפלט שנבחרה, באותה רמה כמו התמונות
  • דפים בסדר מספרי גדל (canvas 1) בד 2
  • אם בד לא ניתן להוריד, דף מוכנס בעל מקום ממוקם עם קישור ישיר הבד המקורי על Antenati
  • לא נותרו קבצים זמניים בתיקיה הפלט בסוף הדור

מה לא לעשות במהלך עיבוד:

  • אל תסגור את התוכנית (קובץ חלקי)
  • אל תמחקו את הדיסק החיצוני (שגיאה מצילה)
  • אל תכבה את PC/laptop
  • אל תמחקו את האינטרנט (resta Download)

מה אתה יכול לעשות:

  • חכה לסיום (זה הליך רגיל)

PDF עבור רישומים ומסמכים

────────────────────────────────────────────────────────────────────────────────

כיצד להפעיל את הדור PDF

הדור של PDF מופעל על ידי בחירת הקופסה PDF בתבנית בחירת המסכה (Menu) הגדרות "Select Image Sizes").

אתה יכול לשלב PDF עם אחד או יותר פורמטי תמונה (למשל PDF + PNG), או לבחור רק PDF כדי להשיג רק את המסמך ללא קבצי תמונה נפרדים.

מאפיינים של PDF שנוצר

  • שם קובץ: PDF נקרא פשוט [nome].pdfללא נפיחות נוספת - למשל Registro Matrimoni 1920.pdf
  • מיקום: שמור בתיקיה הפלט שנבחרה, באותה רמה כמו התמונות: [cartella_scelta]\[nome].pdf
  • סדר דף: דפים הם תמיד בסדר מספרי גדל (canvas 1) בד N, ללא קשר לסדר שבו האריחים הורדים
  • בעל אתר: אם בד אינו זמין (שגיאה או משאב לא זמין באופן זמני), דף מוכנס אוטומטית במקומו. בעל מקום ממוקם בשפה שנבחרה. דף בעל המקום מכיל:
    • טקסט אזהרה מקומי (למשל "תמונה לא זמינה"
    • הקישור הישיר אל הבד המקורי על אננטי (Antenati)https://antenati.cultura.gov.it/ark:/…אז אתה יכול בקלות להתייעץ עם המקור
    בדרך זו, PDF תמיד נוצר, עם כל המידע הדרוש כדי להשלים את זה במקרה של תמונות מוגזמות.
  • ניקוי אוטומטי: קבצים זמניים המשמשים לדור של PDF נמחקים באופן אוטומטי בסוף התהליך. בתיקיה הפלט נותרו רק התמונות בפורמטים שנבחרו, ה- PDF הסופי, פוסטרים ומטא-נתונים

אם PDF לא נבחר:

  • רק תמונות הורידו בפורמטים נבחרים
  • No PDF

מבנה הפלט

כאשר אתה מעבד שיא IIIF, ATK-Pro חוסכת את הקבצים בתיקיה שבחרת ב- PASSO 2 (Select פלט התיקיה).

מבנה מאורגן לתיעוד:

[cartella_output]/
├─ manifest_[ID]_[nome].json         ← Manifest IIIF originale
├─ [nome]_canvas_1.jpg/.png/.tif     ← Immagini ricostruite (una per pagina)
├─ [nome]_canvas_2.jpg/.png/.tif
├─ [nome]_canvas_N.jpg/.png/.tif     ← (N = numero totale pagine/canvas)
├─ [nome].json                       ← Sidecar JSON per ogni immagine (EXIF)
├─ [nome].pdf                        ← PDF completo (solo se richiesto)
└─ [nome]/                           ← Sottocartella SOLO per metadati
   ├─ [nome]_genealogico.json        ← Metadati genealogici
   └─ [nome]_tecnico.json            ← Metadati tecnici
