1. INSTALLATION UND ANFORDERUNGEN

────────────────────────────────────────────────────────────────────────────────

BETRIEBSSYSTEM

  • Windows: Windows 10 oder höher (64-Bit) — Professional, Home, Server
  • Linux: Ubuntu 20.04+ oder kompatible Distributionen (.deb-Paket oder .tar.gz-Archiv)
  • macOS: macOS 11 Big Sur oder höher — .dmg-Distribution (Tests auf realer Hardware laufen)
  • 64-Bit ist auf allen Plattformen erforderlich
  • Mindestens 2 GB verfügbarer RAM (4 GB für die Stapelverarbeitung empfohlen)
  • 1 GB freier Speicherplatz

INSTALLATION

🪟 Windows

  1. Laden Sie ATK-Pro-Setup-vx.x.x.exe von der offiziellen Release-Seite herunter
  2. Doppelklicken Sie auf die Installer-Datei
  3. Wählen Sie bei Aufforderung „Als Administrator ausführen“
  4. Folgen Sie dem Installationsassistenten (Next → Next → Install)
  5. Während der Installation werden Sie zur Auswahl der Sprache aufgefordert (20 verfügbar)
  6. Aktivieren Sie nach Abschluss „ATK-Pro starten“, um das Programm zu starten
  7. Bestätigen Sie gegebenenfalls Warnmeldungen von Windows Firewall/Defender

🐧 Linux

  1. Laden Sie ATK-Pro-vx.x.x.deb (Debian/Ubuntu) oder .tar.gz von der Release-Seite herunter
  2. .deb-Paket: sudo dpkg -i ATK-Pro-vx.x.x.deb oder doppelklicken Sie in Nautilus/Files
  3. .tar.gz-Archiv: entpacken Sie es und starten Sie ./ATK-Pro aus dem entpackten Ordner
  4. Die Sprache wird beim ersten Start ausgewählt und in der Benutzerkonfigurationsdatei gespeichert

🍎 macOS

  1. Laden Sie ATK-Pro-vx.x.x.dmg von der Release-Seite herunter
  2. Öffnen Sie die .dmg-Datei und ziehen Sie ATK-Pro in den Ordner Programme
  3. Beim ersten Start: Rechtsklick → Öffnen (für nicht notarisierte Anwendungen erforderlich)
  4. Die Sprache wird beim ersten Start ausgewählt und in der Benutzerkonfigurationsdatei gespeichert

STANDARDPFADE

🪟 Windows

  • Programm: C:\Program Files\ATK-Pro\
  • Benutzerausgabe: C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • Eingabe (optional): C:\Users\[TuoNome]\Documents\ATK-Pro\input\

🐧 Linux

  • Programm: /opt/ATK-Pro/ (.deb) oder entpackter Ordner (.tar.gz)
  • Benutzerausgabe: ~/Documents/ATK-Pro/output/
  • Eingabe (optional): ~/Documents/ATK-Pro/input/

🍎 macOS

  • Programm: /Applications/ATK-Pro.app
  • Benutzerausgabe: ~/Documents/ATK-Pro/output/
  • Eingabe (optional): ~/Documents/ATK-Pro/input/

NETZWERKANFORDERUNGEN

  • Stabile Internetverbindung (für den Zugriff auf IIIF Manifests erforderlich)
  • Firewall: Ausgehende HTTPS-Verbindungen zulassen (Port 443)
  • Unternehmensproxy: ATK-Pro verfügt über kein internes Menü für Proxy-Anmeldedaten. Konfigurieren Sie den Proxy im Betriebssystem oder in der Netzwerkumgebung und vergewissern Sie sich beim Administrator, dass HTTPS-Verbindungen zu den Portalen zulässig sind.

📂 ORDNERKONFIGURATION

Beim ersten Start erstellt das Programm automatisch die folgenden Ordner:

  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\doc\ (Standard-Dokumentordner)
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\reg\ (Standard-Protokollordner)
  • Linux/macOS: entsprechende Ordner unter ~/Documents/ATK-Pro/output/
  • Ordner input\ entsprechender Ordner (optional, für Eingabedateien)

Während der Verarbeitung werden temporäre Ordner für die heruntergeladenen Tiles erstellt (tiles_canvas_X/) und, wenn ein PDF angefordert wurde, temporäre Dateien für dessen Erstellung.

Alle temporären Ordner und Dateien werden nach Abschluss der Verarbeitung automatisch gelöscht.

Es verbleiben nur die endgültig verarbeiteten Dateien (Bilder in den ausgewählten Formaten, PDF, Manifest und Metadaten).

Um die Ausgabeordner zu ändern, verwenden Sie Menü → Einstellungen → „Ausgabeordner auswählen“. Die Auswahl wird gespeichert und bei der nächsten Sitzung automatisch wiederhergestellt.

⚙️ RESSOURCENPROFIL

Der Befehl Einstellungen → Ressourcenprofil steuert die Parallelverarbeitung beim Download, bei der Bildrekonstruktion und bei der PDF-Erstellung:

  • Leicht: begrenzt die Anzahl gleichzeitiger Prozesse und Speicherspitzen; geeignet für weniger leistungsfähige Computer oder sehr lange Verarbeitungsvorgänge.
  • Ausgewogen: standardmäßiger Kompromiss zwischen Geschwindigkeit und Stabilität, für die meisten Fälle geeignet.
  • Schnell: nutzt mehr Ressourcen, um die Verarbeitungszeit zu verkürzen; wählen Sie dieses Profil nur auf ausreichend leistungsfähigen Computern.

Das Profil verändert weder Qualität noch Rechte noch die Anzahl der erfassten Dokumente. Portalspezifische vorsorgliche Beschränkungen haben weiterhin Vorrang.

MENÜLEISTE

[Eingabedatei] [Ausgabe] [Dienste] [Dokumente] [Einstellungen]

Jedes Menü enthält spezifische Schaltflächen und Optionen (siehe nächsten Abschnitt).

VERFÜGBARE MENÜS

1. EINGABEDATEI

Verwaltet das Laden der IIIF-Datensätze:

├─ Eingabebeispiel
│  └─ Zeigt die Beispieldatei an (Format der Paare: Modus D/R + URL)
├─ Eingabe öffnen
│  └─ Wählt eine .txt-Datei mit Ihren IIIF-Datensätzen aus
│     (Sie muss Paare enthalten: Modus D/R in Zeile 1, URL in Zeile 2)
└─ Eingabe bearbeiten
   └─ Bearbeitet die aktuell geladene Eingabedatei
      (Datensätze hinzufügen/entfernen, URL ändern, Änderungen speichern)

2. AUSGABE

Verwaltet Verarbeitung und Ausgabe:

├─ Verarbeiten
│  └─ Startet Download, Rekonstruktion und Speicherung der Bilder
│     (Zeigt ein Fortschrittsfenster in Echtzeit an)
├─ Ausgabeordner öffnen
│  └─ Öffnet den Ordner mit den verarbeiteten Dateien im Datei-Explorer
└─ Frühere Verarbeitungen anzeigen
   └─ Liste der bereits verarbeiteten Datensätze

3. DIENSTE

Liste der integrierten Dienste:

├─ KI-gestützte Suche
│  └─ Schlägt zu überprüfende Portale, Rechercheansätze und genealogische Suchanfragen vor
├─ Bildanzeige
│  └─ Viewer für heruntergeladene Bilder und/oder erzeugte PDFs
├─ JSON-Metadatenanzeige
│  └─ Original-JSONs und Metadaten (genealogisch, technisch, EXIF)
├─ Erweiterte OCR
│  └─ Handschriftliche Texte des 19. Jahrhunderts, Kirchenlatein, spätmittelalterliche Texte
├─ OCR-Übersetzung
│  └─ Automatische Übersetzung extrahierter Texte in die ausgewählten Sprachen
└─ GEDCOM-Export
   └─ GEDCOM, Gramps, Family Tree Maker, Ancestry, MyHeritage, WikiTree, etc.

4. DOKUMENTE

Zugriff auf Ressourcen und Dokumentation:

├─ Haftungsausschluss - Rechtliche Klauseln und Nutzungsbedingungen

├─ Projektvorstellung - Geschichte, Beweggründe und Roadmap von ATK-Pro

5. EINSTELLUNGEN

Allgemeine Programmkonfiguration:

├─ Sprache ändern
│  └─ Wählt die Sprache der Benutzeroberfläche aus (Neustart erforderlich)
├─ Bildformate auswählen
│  └─ Wählen Sie zwischen PNG, JPG, TIFF und PDF (mindestens 1 erforderlich)
│     PDF kann allein oder zusammen mit den Bildformaten ausgewählt werden
│     Die Auswahl wird gespeichert und bei der nächsten Sitzung automatisch vorausgewählt
├─ Ausgabeordner auswählen
│  └─ Öffnet zunächst die Auswahl des Ordnermodus und anschließend die Auswahlfenster:
│     • Ein Ordner für alle         → ein einziger Ordner für Dokumente und Register
│     • Separate Ordner Dok./Reg.   → ein Ordner für alle Dok., einer für alle Reg.
│     • Ordner für jeden Datensatz  → ein eigener Ordner für jeden Datensatz
│     Modus und Ordner werden gespeichert und bei der nächsten Sitzung wiederhergestellt
├─ Konfiguration exportieren
│  └─ Speichert die aktuellen Einstellungen in einer Datei
├─ Konfiguration importieren
│  └─ Lädt eine zuvor gespeicherte Einstellungsdatei (stellt alle Einstellungen und Pfade wieder her)
├─ Nach Updates suchen
│  └─ Prüft, ob neue Programmversionen verfügbar sind
└─ Schließen
    └─ Beendet das Programm (zeigt das Unterstützungsbanner PayPal.me an)

LOKALISIERTE TEXTE

Beim Wechsel der Sprache werden folgende Elemente übersetzt:

  • Menüs und Schaltflächen
  • Fortschrittsmeldungen
  • Fehler-/Warndialoge

HINWEIS ZU SCHRIFTARTEN UND LAYOUT

  • RTL-Sprachen (Arabisch, Hebräisch) ändern das Layout (Menüs/Steuerelemente rechtsbündig ausgerichtet)
  • Eine mehrsprachige UTF-8-Schriftart gewährleistet die korrekte Darstellung
  • Wenn unter Windows fehlerhafte Zeichen angezeigt werden, aktualisieren Sie auf Windows 10+ (seltenes Problem)
