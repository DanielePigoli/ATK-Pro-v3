3. Troubleshooting und FAQ

────────────────────────────────────────────────────────────────────────────────

❓ HÄUFIG GESTELLTE FRAGEN

🔵 F: Bleibt das Programm beim Laden des Manifests hängen?

A: Meist handelt es sich um ein Netzwerk-Timeout. Prüfen Sie:

  1. Prüfen Sie, ob die Internetverbindung funktioniert, indem Sie im Browser eine zuverlässige Webseite öffnen.
  2. Öffnen Sie die IIIF-URL im Browser und kopieren Sie sie erneut aus der Adressleiste.
  3. Prüfen Sie, ob Firewall oder Sicherheitssoftware die Verbindungen von ATK-Pro zulassen.
  4. Wenn Sie ein Netzwerk mit Proxy verwenden, prüfen Sie die Netzwerkkonfiguration des Betriebssystems.

Wenn das Problem weiterhin besteht, versuchen Sie eine andere URL, um die IIIF-Verbindung zu testen

🔵 F: "Datei nicht gefunden (404)" - was bedeutet das?

A: Die URL des Manifests ist nicht erreichbar. Mögliche Ursachen:

  • URL abgelaufen (Repository nicht aktualisiert)
  • Repository offline
  • Falsche URL-Parameter (falsche Manifest-ID)

Lösung: Prüfen Sie die URL im Browser, bevor Sie sie in ATK-Pro einfügen

🔵 F: Ist der Download sehr langsam oder wird er unterbrochen?

A: Versuchen Sie Folgendes:

  1. Prüfen Sie die Stabilität des WLAN-Netzwerks oder verwenden Sie, falls verfügbar, eine kabelgebundene Verbindung.
  2. Testen Sie eine andere öffentliche IIIF-URL, um festzustellen, ob die Verlangsamung vom Server verursacht wird.
  3. Reduzieren Sie die Belastung mit dem Ressourcenprofil Leicht.
  4. Wenn das Problem nur ein Portal betrifft, warten Sie und versuchen Sie es später erneut: Der entfernte Dienst könnte überlastet oder vorübergehend nicht verfügbar sein.

🔵 F: Die Bildrekonstruktion ist langsam - wie kann sie beschleunigt werden?

A: Die Geschwindigkeit hängt hauptsächlich von der Antwortzeit des IIIF-Servers, der Größe der Bilder, der Verbindung und den auf dem Computer verfügbaren Ressourcen ab.

  • Verwenden Sie das Profil Leicht, um den Ressourcenverbrauch zu reduzieren, oder Schnell nur auf entsprechend leistungsfähigen Systemen.
  • Verarbeiten Sie Register mit weniger Seiten auf einmal, wenn Arbeitsspeicher oder Netzwerk stark belastet sind.
  • Beachten Sie, dass einige Portale unabhängig vom ausgewählten Profil einen sequenziellen Zugriff erzwingen.

🔵 F: Ist die PDF-Ausgabe beschädigt oder lässt sie sich nicht öffnen?

A: Versuchen Sie Folgendes:

  1. Bewahren Sie eine für die Diagnose geeignete Kopie auf und entfernen oder benennen Sie anschließend die unvollständige PDF-Datei um.
  2. Laden Sie den Datensatz erneut über Eingabedatei → Eingabe öffnen und erzeugen Sie die PDF-Datei erneut.
  3. Prüfen Sie, ob das Ziel beschreibbar ist und ausreichend Speicherplatz für die Verarbeitung zur Verfügung steht.
  4. Prüfen Sie die einzelnen erzeugten Bilder, um festzustellen, ob das Problem nur die PDF-Datei betrifft.

🔵 F: Wie verwende ich TIFF-Dateien für die Archivierung?

A: TIFF ist ein verlustfreies Format und ideal für die Archivierung:

  1. Wählen Sie TIFF unter den Bildformaten aus.
  2. ATK-Pro speichert TIFF-Dateien mit verlustfreier LZW-Komprimierung.
  3. Bewahren Sie eine Kopie auf einem separaten Speichermedium auf und prüfen Sie regelmäßig die Integrität des Backups.
  4. Die langfristige Erhaltung hängt auch von Speichermedien, Kopien und Integritätsprüfungen ab, nicht nur vom Format.

🔵 F: Kann ich mehrere Datensätze gleichzeitig (parallel) verarbeiten?

A: Die Datensätze eines Batchs werden nacheinander verarbeitet. Innerhalb eines einzelnen Datensatzes können Seiten und Tiles je nach Portal und Ressourcenprofil parallel verarbeitet werden.

  1. Erstellen Sie eine Eingabedatei mit allen unterstützten Datensätzen nacheinander.
  2. Wählen Sie sie über Eingabedatei → Eingabe öffnen.
  3. Starten Sie nur einmal Ausgabe → Verarbeiten.
  4. ATK-Pro fährt automatisch mit den folgenden Datensätzen fort.

Beispiel: Wenn die Eingabe 5 Datensätze enthält, verarbeitet ATK-Pro automatisch:

  • Datensatz 1 (Download + Rekonstruktion)
  • Datensatz 2 (Download + Rekonstruktion)
  • ... bis Datensatz 5

Die Ergebnisse werden in den konfigurierten Ordnern gespeichert; die Verarbeitung muss nicht für jeden Datensatz manuell neu gestartet werden.

🔵 F: Wo genau werden die Dateien gespeichert?

A: Standardpfad:

  • Standardinstallation: Ordner ATK-Pro/output in den Dokumenten des Benutzers.
  • Portabler Modus: Ordner output neben der ausführbaren Datei.

Sie können das Ziel ändern über Einstellungen → Ausgabeordner auswählen. Die Standardordner werden nach Möglichkeit automatisch erstellt.

🔵 F: Warum meldet oder blockiert ATK-Pro einen Ausgabepfad?

A: Bevor Dateien erstellt werden, prüft ATK-Pro den längsten für den Datensatz erwarteten Pfad. Die abschließende Zusammenfassung unterscheidet zwei Situationen:

  • Blockierender Fehler: Der Name enthält unzulässige Zeichen, verwendet einen reservierten Windows-Namen, endet mit einem Leerzeichen oder Punkt oder ein Pfadsegment überschreitet die unterstützte Grenze. Nur der betroffene Datensatz wird angehalten und der zugehörige Arbeitsordner wird nicht erstellt.
  • Kompatibilitätswarnung: Der Pfad liegt nahe an einem vorsorglichen Grenzwert oder kann bei älteren Windows-Anwendungen Schwierigkeiten verursachen. Die Verarbeitung kann fortgesetzt werden, es empfiehlt sich jedoch, ein kürzeres Ziel zu wählen.

Das Profil OneDrive/SharePoint wird nur angewendet, wenn sich der ausgewählte Ordner tatsächlich unter einem Stammverzeichnis OneDrive oder OneDrive - Organizzazionebefindet. Kürzen Sie bei einem Fehler den Namen des Datensatzes oder wählen Sie einen Zielordner näher am Stammverzeichnis des Laufwerks; Dateien, die bereits bei anderen Verarbeitungen erzeugt wurden, müssen weder umbenannt noch verschoben werden.

🔵 F: Kann ich Ausgabedateien nach der Verarbeitung verschieben?

A: Ja, die endgültigen Dateien können nach der Verarbeitung verschoben werden.

Nach Abschluss:

  1. Verschieben Sie den Ordner des Datensatzes an das neue Ziel.
  2. Die endgültige PDF-Datei ist eigenständig; bewahren Sie auch Bilder und Metadaten auf, wenn sie zu Ihrem Arbeitsarchiv gehören.
  3. Wenn Sie den Datensatz später erneut verarbeiten möchten, bewahren Sie das Manifest und die übrigen Quelldateien auf.

🔵 F: Plötzliche Abstürze - was tun?

A: Wenn das Programm abstürzt:

  1. Prüfen Sie atkpro.log oder, wenn die erweiterte Diagnose aktiviert ist, atkpro_debug.log. Der Speicherort hängt von der Installationsart ab: Suchen Sie neben der ausführbaren Datei oder im Arbeitsverzeichnis der Anwendung.
  2. Kopieren Sie die Fehlermeldung oder erstellen Sie einen Screenshot.
  3. Starten Sie das Programm neu und wiederholen Sie den Vorgang.
  4. Wenn der Fehler erneut auftritt, testen Sie einen anderen IIIF-Datensatz, um ein allgemeines Problem von einem manifestspezifischen Problem zu unterscheiden.

🔵 F: Das Portal wird erkannt, aber der Download wird abgelehnt. Warum?

A: Technische Kompatibilität hebt die Zugangsbedingungen nicht auf. ATK-Pro lehnt Ressourcen ab oder schränkt sie ein, wenn sie eine Anmeldung oder einen institutionellen Zugang erfordern, keinen stabilen öffentlichen Endpunkt bereitstellen, als nodownload gekennzeichnet sind oder keine mit dem gewünschten Vorgang kompatiblen Rechte aufweisen. Öffnen Sie die öffentliche Seite des Objekts, prüfen Sie Lizenz und Nutzungsbedingungen und versuchen Sie es nur mit der unterstützten offiziellen URL.

🔵 F: Kann ich einen unterbrochenen OCR-Batch wiederherstellen?

A: Prüfen Sie im für OCR ausgewählten Ordner die Datei *_trascrizione_parziale.txt und die zugehörigen Metadaten. Sie enthalten den schrittweise gespeicherten Arbeitsstand, der geprüft und vervollständigt werden muss, bevor er als endgültig angesehen werden kann.
