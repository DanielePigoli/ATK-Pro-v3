📌 Vue d’ensemble

Le module OCR avancé (transcription diplomatique) extrait le texte d’images et de documents PDF au moyen de modèles multimodaux, de modèles OCR spécialisés et de services HTR. Il est conçu spécifiquement pour les documents historiques : manuscrits, actes notariés, registres paroissiaux, lettres d’archives en italien du XIXe siècle, en latin ou en dialecte.

Contrairement aux moteurs OCR traditionnels (Tesseract, etc.), le module peut interpréter l’écriture dans le contexte du document et reconnaître les abréviations et les formules récurrentes. La sortie TEI-P5 représente les lignes transcrites et, lorsqu’ils sont reconnus, les sauts de page, les développements d’abréviations et les passages illisibles ; elle ne reproduit pas intégralement la mise en page graphique d’origine.

Il s’ouvre depuis le menu Services → OCR avancé de l’application principale.

🖥️ Interface — guide pas à pas

📂 Étape 1 — Sélection des fichiers

Cliquez sur “Sélectionner les fichiers (images/PDF)” pour ouvrir le sélecteur. Vous pouvez sélectionner plusieurs fichiers simultanément en maintenant la touche Ctrl ou Shift.

Formats acceptés :

  • Images : .jpg, .jpeg, .png, .tiff, .tif
  • PDF : tout document PDF (numérisé ou natif)

Le nombre de fichiers sélectionnés est affiché à côté de l’étiquette. Chaque fichier est traité séparément et génère ses propres fichiers de sortie.

Le champ “Remplacement du modèle (facultatif)” permet de remplacer le modèle par défaut. Utilisez-le uniquement si vous connaissez l’identifiant exact et la compatibilité visuelle du modèle. Pour Gemini, ce champ n’est pas affiché.

Vous pouvez saisir la clé d’API dans le champ prévu à cet effet ou ouvrir le Coffre-fort. Les clés d’IA sont conservées localement dans le coffre CSV api_keys.csv : il ne s’agit pas du trousseau protégé du système d’exploitation. La protection du profil utilisateur, les sauvegardes et la révocation des clés restent sous la responsabilité de l’utilisateur.

📄 Étape 3 — Formats de sortie

Sélectionnez un ou plusieurs formats de sortie (les trois sont sélectionnés par défaut) :

  • Texte brut (.txt) : transcription brute, compatibilité maximale. Idéale pour les traitements ultérieurs (traduction, indexation).
  • Document Word (.docx) : texte mis en forme, modifiable avec Microsoft Word ou LibreOffice.
  • XML TEI (.xml) : format TEI-P5 pour représenter la transcription, avec un en-tête descriptif, des lignes et des marqueurs reconnus pour les pages, les développements d’abréviations et le texte illisible.

Les fichiers sont enregistrés dans le dossier de destination que vous choisirez au moment du lancement de l’OCR.

📝 Étape 4 — Instructions supplémentaires (facultatif mais recommandé)

Le champ “Instructions supplémentaires pour l’IA” permet de personnaliser le comportement du modèle pour chaque session de travail :

  • Indiquer le dialecte ou la variante linguistique du texte
  • Signaler les abréviations récurrentes et leur signification
  • Préciser s’il faut ignorer les cachets, les annotations marginales ou les timbres-poste
  • Demander la conservation de formules spécifiques

Exemples pratiques :

  • “Les noms des mois sont en dialecte sicilien du XIXe siècle. Ne pas corriger.”
  • “Ignorer les cachets en marge et les annotations au crayon rouge.”
  • “L’abréviation 'f.' peut signifier 'fils/fille de' ; 'fu' et 'q.' indiquent que la personne citée était déjà décédée.”

Bibliothèque d’instructions : les instructions utilisées le plus fréquemment peuvent être enregistrées à l’aide du bouton “+” et rappelées depuis le menu déroulant “Instructions enregistrées” lors des sessions suivantes.

Les instructions enregistrées peuvent être ajoutées, renommées ou supprimées. Le type de document détermine le prompt de base : en plus des types inclus, vous pouvez créer, modifier ou supprimer des profils documentaires personnalisés.

🎯 Calibration assistée et diagnostic (facultatifs)

La calibration assistée traite la partie supérieure du premier fichier sélectionné, affiche le résultat pour correction et utilise le texte approuvé comme référence pour le traitement complet. Elle est utile pour vérifier le fournisseur, le modèle, le type de document et les instructions avant de lancer un lot important.

L’option de diagnostic enregistre des informations techniques supplémentaires sur le traitement. Activez-la lorsque vous devez analyser une erreur ou fournir des éléments au support ; vérifiez le contenu avant de le partager, car il peut inclure des données relatives au document ou à la requête.

🎓 Étape 5 — Transcription de référence (few-shot, facultatif)

Le champ “Transcription de référence” fournit au modèle un exemple contextuel de transcription correcte à utiliser dans la requête. Il n’entraîne, ne modifie ni ne met à jour le modèle.

Comment l’utiliser :

  1. Transcrivez manuellement et avec précision la première page (ou les premières lignes) du registre
  2. Collez le texte transcrit dans le champ “Transcription de référence”
  3. Lancez l’OCR : le modèle utilisera cette transcription comme guide pour tout le reste du document

Résultat : peut améliorer la précision, notamment pour les écritures cursives difficiles, les abréviations inhabituelles ou les dialectalismes locaux ; l’effet dépend du fournisseur, du modèle et de la qualité du document.
Le champ “Effacer le texte” (✖) vide la transcription et rétablit le mode standard.

🔍 Étape 6 — Révision interactive (facultatif)

Cocher “Activer la fenêtre de révision interactive” active un mode interactif qui s’ouvre après chaque traitement :

  • Panneau gauche : image originale avec zoom (molette de la souris) et déplacement panoramique
  • Panneau droit : texte OCR extrait, librement modifiable
  • Bouton “Approuver et générer les fichiers” : enregistre le texte révisé dans les formats choisis
  • Bouton “Ignorer la page” : abandonne le traitement en cours et passe à la page suivante

Utile pour vérifier en temps réel la qualité de l’OCR et corriger les erreurs avant l’enregistrement définitif. Pour les lots de grande taille, il est préférable de désactiver la révision interactive et de corriger le texte a posteriori.

▶️ Étape 7 — Lancement de l’OCR

Cliquez sur “Lancer l’OCR”. Le dossier de destination des fichiers de sortie vous sera demandé.

La barre de progression indique l’avancement (fichier en cours / nombre total de fichiers). Le traitement s’effectue dans un thread séparé : l’interface reste réactive pendant le traitement.

Pendant les lots, ATK-Pro met à jour une transcription progressive *_trascrizione_parziale.txt avec les métadonnées correspondantes. Si le traitement est interrompu, conservez ces fichiers afin de récupérer ce qui a déjà été transcrit ; ne les considérez pas comme une sortie définitive tant que le lot n’est pas terminé et révisé.

À la fin, une boîte de dialogue confirmera l’achèvement ou signalera d’éventuelles erreurs.

🔑 Comment obtenir les clés API

Compte, clés, modèles et coûts

Obtenez les identifiants exclusivement depuis la console officielle du fournisseur choisi et ne les partagez pas dans les fichiers d’entrée, les transcriptions ou les demandes d’assistance. Les interfaces, modèles, quotas, disponibilités géographiques et tarifs peuvent changer sans mise à jour d’ATK-Pro.

Avant un traitement important, consultez toujours la documentation et le tableau de bord de facturation de votre compte. ATK-Pro ne garantit ni offre gratuite, ni quota minimal, ni maintien d’un modèle particulier.

💡 Conseils pour des résultats optimaux

  • Qualité des images : des images nettes à 300 DPI ou plus produisent des résultats nettement meilleurs. Évitez les JPEG fortement compressés (artefacts).
  • Utilisez toujours les instructions supplémentaires : quelques lignes de contexte suffisent à améliorer sensiblement la précision pour les documents dialectaux ou présentant une écriture inhabituelle.
  • Première page comme référence : transcrivez manuellement la première page et utilisez le champ “Transcription de référence” ; l’amélioration sur les pages suivantes est souvent notable.
  • Lot de test : pour les grands lots (100+ images), effectuez d’abord un test sur 5 à 10 fichiers avec la révision interactive activée avant de traiter le lot complet.
  • TEI XML : sélectionnez le format XML TEI si vous prévoyez de déposer la transcription dans des archives numériques universitaires ou de la partager avec d’autres chercheurs.
  • Enregistrez les instructions : chaque série d’archives possède ses propres caractéristiques. Enregistrez un ensemble d’instructions spécifique pour chaque registre ou fonds traité.
