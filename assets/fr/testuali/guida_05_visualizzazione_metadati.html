📚 Module 05 : Visualisation des métadonnées JSON

⬅️ Mod.04 — Visualisation des images 🏠 Index principal Mod.06 — Fonctions avancées OCR ➡️

📌 Vue d’ensemble

La Visionneuse de métadonnées JSON d’ATK-Pro est dédiée à l’affichage des fichiers JSON générés lors du traitement des documents. Elle s’ouvre depuis le menu Services → Visualisation des métadonnées JSON de l’application.

La visionneuse ouvre les fichiers JSON valides structurés sous forme d’objet, y compris les fichiers sidecar générés par ATK-Pro. Elle recherche automatiquement une image portant le même nom dans le même dossier (extensions : .jpg, .jpeg, .png, .tif, .tiff) et, si elle en trouve une, l’affiche dans le panneau de droite.

Si le fichier ne contient pas de JSON valide ou ne peut pas être lu, le message suivant s’affiche : “Impossible de lire le fichier JSON”.

🌳️ Interface

La fenêtre est divisée en deux panneaux côte à côte :

Panneau de gauche — tableau des métadonnées

Les données du fichier JSON sont affichées sous forme de tableau à deux colonnes :

  • Champ : le nom de la clé JSON
  • Valeur : la valeur correspondante

Seuls les champs de premier niveau du JSON sont affichés. Les champs dont le nom commence par _ (underscore) sont omis, car ils sont réservés à un usage interne. Les structures imbriquées, telles que les objets ou les tableaux, apparaissent sous forme de texte dans la colonne Valeur et non comme des niveaux dépliables.

Panneau de droite — aperçu de l’image

Si une image correspondante est trouvée, elle est chargée avec les mêmes fonctionnalités que la Visionneuse d’images (zoom à la molette, boutons +/−, Ajuster à la fenêtre, 1:1, déplacement par glissement).

Si aucune image correspondante n’est trouvée, le panneau affiche “Aucune image correspondante trouvée”.

Afficher et masquer le panneau

  • Bouton “◄ Masquer les métadonnées” : masque le panneau de gauche contenant les métadonnées
  • Bouton “► Afficher les métadonnées” : rétablit le panneau des métadonnées
