📌 Vue d’ensemble

Le module Exportation GEDCOM de la v3 est un environnement d’analyse généalogique assistée : il traite des textes, images ou documents sélectionnés, utilise un fournisseur d’IA configuré dans ATK-Pro et génère un fichier .ged accompagné de deux fichiers CSV de support.

Il s’ouvre depuis le menu Services → Exportation GEDCOM. Le nom public reste lié au format GEDCOM, mais le traitement effectif comprend également l’extraction généalogique, l’utilisation de notes paléographiques, l’enrichissement éventuel d’une base existante et la gestion des clés d’IA.

Le résultat doit être vérifié avant d’être importé dans un logiciel de généalogie : l’IA peut aider à structurer les données et les relations, mais elle ne remplace pas la lecture critique des sources.

🖥️ Interface

1. Méthode et entrée universelle

La première section permet de choisir une indication de méthode ainsi que les fichiers à analyser. Les options Auto-Discovery, Vision IA et Refinery LLM sont enregistrées comme préférences, mais dans la version actuelle elles n’activent pas trois pipelines distincts : le traitement effectif dépend principalement du type de fichier.

  • TXT et DOCX : ils sont lus au moyen du pipeline textuel dédié et intégrés au prompt sous forme de transcriptions.
  • Autres entrées : elles sont transmises au fournisseur sélectionné selon le flux d’extraction disponible.
  • Formats sélectionnables : .pdf, .docx, .jpg, .jpeg, .png, .webp, .tiff, .tif, .bmp, .txt, .json et .csv.

2. Enrichir une base existante

Le bouton CHARGER LA BASE permet d’indiquer une base généalogique déjà existante au format GEDCOM ou CSV. Si vous ne chargez rien, le module crée un nouveau travail. Lorsque vous chargez une base, le résultat est automatiquement enregistré dans le dossier qui la contient, même si vous aviez précédemment choisi une autre destination.

3. Base de données des notes paléographiques

Cette section relie le travail généalogique aux typologies documentaires et aux notes opérationnelles. Vous pouvez choisir le type d’acte, rappeler une note enregistrée, en créer une nouvelle, la modifier ou la supprimer.

Les notes servent à expliquer au modèle les abréviations, les formules locales, la langue du document, les règles de parenté, les incertitudes de lecture ou les critères d’extraction.

4. Destination de sortie

Choisissez le dossier dans lequel enregistrer le résultat. Si une base existante a été chargée, le dossier de cette base est utilisé à la place. Le module génère un fichier genealogia_*.ged au format GEDCOM 5.5.1 et deux fichiers de support portant le même nom de base : *_REVISIONE.csv et *_REGISTRO_ORIGINALE.csv.

5. Moteur d’IA et coffre-fort des clés

  • Fournisseur : choisissez le service d’IA parmi ceux configurés, par exemple Claude, OpenAI, Gemini, Mistral, xAI, DeepSeek, Groq, HuggingFace ou Ollama.
  • Override du modèle : champ facultatif permettant d’indiquer un modèle spécifique pris en charge par le fournisseur choisi ; il est masqué lorsque le fournisseur est Gemini.
  • GÉRER LE COFFRE-FORT DES CLÉS (CSV) : ouvre directement le fichier CSV du coffre-fort.
  • LANCER L’EXTRACTION COMPLÈTE : lance l’analyse et la génération du GEDCOM.

Vous pouvez créer et supprimer des typologies documentaires personnalisées. Pour les typologies intégrées, vous pouvez modifier le prompt au moyen d’un override, mais vous ne pouvez pas supprimer la typologie.

📝 Procédure recommandée

  1. Préparez des entrées lisibles : transcriptions, images ou fichiers déjà organisés par acte.
  2. Choisissez l’indication de méthode la plus adaptée au contenu, en gardant à l’esprit que, dans la version actuelle, elle ne sélectionne pas un pipeline distinct.
  3. Si vous poursuivez un travail existant, chargez la base GEDCOM ou CSV.
  4. Sélectionnez la typologie d’acte et ajoutez une note paléographique concrète.
  5. Choisissez le dossier de sortie, le fournisseur et la clé.
  6. Lancez l’extraction complète.
  7. Vérifiez le fichier .ged généré avant de l’importer dans d’autres programmes.

⚠️ Avertissements

  • Le GEDCOM produit constitue une base de travail, et non une preuve définitive.
  • Les relations familiales, les dates, les lieux et les noms doivent être vérifiés à partir des sources originales.
  • Les erreurs d’OCR, de transcription ou d’interprétation peuvent se propager dans le fichier généalogique.
  • Avant d’importer le GEDCOM dans des logiciels externes, conservez une copie du fichier original et vérifiez la présence d’éventuels doublons.
  • N’envoyez pas à des fournisseurs externes des documents confidentiels ou soumis à des restrictions sans avoir vérifié les conditions d’utilisation, les règles de confidentialité et les autorisations.
