3. Dépannage et FAQ

────────────────────────────────────────────────────────────────────────────────

❓ QUESTIONS FRÉQUENTES

🔵 Q : Le programme se bloque lors du chargement du manifeste ?

R : Il s’agit généralement d’un délai d’attente réseau dépassé. Vérifiez les points suivants :

  1. Vérifiez que la connexion Internet fonctionne en ouvrant une page fiable dans le navigateur.
  2. Ouvrez l’URL IIIF dans le navigateur et copiez-la à nouveau depuis la barre d’adresses.
  3. Vérifiez que le pare-feu ou les logiciels de sécurité autorisent les connexions d’ATK-Pro.
  4. Si vous utilisez un réseau avec proxy, vérifiez la configuration réseau du système d’exploitation.

Si le problème persiste, essayez une autre URL afin de tester la connexion IIIF

🔵 Q : "Fichier introuvable (404)" — qu’est-ce que cela signifie ?

R : L’URL du manifeste n’est pas accessible. Causes possibles :

  • URL expirée (dépôt non mis à jour)
  • Dépôt hors ligne
  • Paramètres d’URL incorrects (ID de manifeste erroné)

Solution : vérifiez l’URL dans le navigateur avant de la coller dans ATK-Pro

🔵 Q : Le téléchargement est très lent ou s’interrompt ?

R : Essayez les solutions suivantes :

  1. Vérifiez la stabilité du réseau Wi-Fi ou utilisez une connexion filaire, si elle est disponible.
  2. Essayez une autre URL IIIF publique afin de déterminer si le ralentissement provient du serveur.
  3. Réduisez la charge en choisissant le profil de ressources Léger.
  4. Si le problème concerne un seul portail, attendez puis réessayez : le service distant peut être saturé ou temporairement indisponible.

🔵 Q : La reconstruction des images est lente — comment l’accélérer ?

R : La vitesse dépend principalement de la réponse du serveur IIIF, de la taille des images, de la connexion et des ressources disponibles sur l’ordinateur.

  • Utilisez le profil Léger pour réduire la consommation de ressources ou Rapide uniquement sur des systèmes adaptés.
  • Traitez des registres comportant moins de pages à la fois si la mémoire ou le réseau sont fortement sollicités.
  • N’oubliez pas que certains portails imposent un accès séquentiel indépendamment du profil choisi.

🔵 Q : Le PDF de sortie est corrompu ou ne s’ouvre pas ?

R : Essayez les solutions suivantes :

  1. Conservez une copie utile au diagnostic, puis supprimez ou renommez le PDF incomplet.
  2. Rechargez l’enregistrement depuis File input → Apri input et générez à nouveau le PDF.
  3. Vérifiez que l’emplacement de destination est accessible en écriture et dispose d’un espace suffisant pour le traitement.
  4. Vérifiez les différentes images générées afin de déterminer si le problème concerne uniquement le PDF.

🔵 Q : Comment utiliser les fichiers TIFF pour l’archivage ?

R : TIFF est un format sans perte, parfaitement adapté à la conservation :

  1. Sélectionnez TIFF parmi les formats d’image.
  2. ATK-Pro enregistre les fichiers TIFF avec une compression LZW sans perte.
  3. Conservez une copie sur un support distinct et vérifiez périodiquement l’intégrité de la sauvegarde.
  4. La conservation à long terme dépend également des supports, des copies et des contrôles d’intégrité, et pas uniquement du format.

🔵 Q : Puis-je traiter plusieurs enregistrements simultanément (en parallèle) ?

R : Les enregistrements d’un lot sont traités séquentiellement. Au sein d’un même enregistrement, les pages et les tuiles peuvent être traitées en parallèle selon le portail et le profil de ressources.

  1. Préparez un fichier d’entrée contenant tous les enregistrements pris en charge, les uns à la suite des autres.
  2. Sélectionnez-le depuis File input → Apri input.
  3. Lancez une seule fois Output → Elabora.
  4. ATK-Pro poursuit automatiquement avec les enregistrements suivants.

Exemple : si le fichier d’entrée contient 5 enregistrements, ATK-Pro traite automatiquement :

  • Enregistrement 1 (téléchargement + reconstruction)
  • Enregistrement 2 (téléchargement + reconstruction)
  • ... jusqu’à l’enregistrement 5

Les résultats sont enregistrés dans les dossiers configurés ; il n’est pas nécessaire de relancer manuellement le traitement pour chaque enregistrement.

🔵 Q : Où les fichiers sont-ils exactement enregistrés ?

R : Chemin par défaut :

  • Installation standard : dossier ATK-Pro/output dans les Documents de l’utilisateur.
  • Mode portable : dossier output à côté de l’exécutable.

Vous pouvez modifier la destination depuis Paramètres → Sélectionner le dossier de sortie. Les dossiers par défaut sont créés automatiquement lorsque cela est possible.

🔵 Q : Pourquoi ATK-Pro signale-t-il ou bloque-t-il un chemin de sortie ?

R : Avant de créer des fichiers, ATK-Pro vérifie le chemin le plus long prévu pour l’enregistrement. Le récapitulatif final distingue deux situations :

  • Erreur bloquante : le nom contient des caractères non autorisés, utilise un nom réservé par Windows, se termine par un espace ou un point, ou bien un segment dépasse la limite prise en charge. Seul l’enregistrement concerné est interrompu et son dossier de travail n’est pas créé.
  • Avertissement de compatibilité : le chemin est proche d’un seuil de précaution ou peut poser des difficultés avec des applications Windows plus anciennes. Le traitement peut se poursuivre, mais il est préférable de choisir une destination au chemin plus court.

Le profil OneDrive/SharePoint n’est appliqué que lorsque le dossier sélectionné se trouve réellement sous une racine OneDrive ou OneDrive - Organizzazione. En cas d’erreur, raccourcissez le nom de l’enregistrement ou choisissez un dossier de destination plus proche de la racine du lecteur ; il n’est pas nécessaire de renommer ou de déplacer les fichiers déjà produits lors d’autres traitements.

🔵 Q : Puis-je déplacer les fichiers de sortie après le traitement ?

R : Oui, les fichiers finaux peuvent être déplacés après le traitement.

Une fois le traitement terminé :

  1. Déplacez le dossier de l’enregistrement vers la nouvelle destination.
  2. Le PDF final est autonome ; conservez également les images et les métadonnées si elles font partie de vos archives de travail.
  3. Si vous prévoyez de retraiter l’enregistrement, conservez le manifeste et les autres fichiers sources.

🔵 Q : Plantages soudains — que faire ?

R : Si le programme plante :

  1. Vérifiez atkpro.log ou, si le diagnostic étendu est activé, atkpro_debug.log. L’emplacement dépend du type d’installation : recherchez à côté de l’exécutable ou dans le répertoire de travail de l’application.
  2. Copiez le message d’erreur ou réalisez une capture d’écran.
  3. Redémarrez le programme et répétez l’opération.
  4. Si l’erreur se reproduit, essayez un autre enregistrement IIIF afin de distinguer un problème général d’un problème propre au manifeste.

⚠️ ERREURS COURANTES ET SOLUTIONS

Erreur Cause Solution
"Network timeout" Serveur IIIF lent/hors ligne Réessayez avec une autre URL
"Invalid IIIF format" L’URL n’est pas un manifeste IIIF Vérifiez l’URL dans le navigateur
"Disk space full" Espace disque insuffisant Libérez de l’espace sur le lecteur
"Permission denied" Dossier protégé/en lecture seule Choisissez un dossier appartenant à votre compte utilisateur et vérifiez qu’il est accessible en écriture ; évitez les dossiers système ou protégés.
"URL not found (404)" Manifeste IIIF expiré Vérifiez l’ID dans le portail
"Window not responding" Traitement lent/lourd Attendez ou cliquez sur Annuler

🔵 Q : Le portail est reconnu, mais le téléchargement est refusé. Pourquoi ?

R : La compatibilité technique ne supprime pas les conditions d’accès. ATK-Pro refuse ou limite les ressources qui nécessitent une connexion ou un accès affilié, n’exposent pas de point de terminaison public stable, sont marquées nodownload ou ne présentent pas de droits compatibles avec l’opération demandée. Ouvrez la page publique de l’objet, vérifiez la licence et les conditions d’utilisation, puis essayez uniquement avec l’URL officielle prise en charge.

🔵 Q : Puis-je récupérer un lot OCR interrompu ?

R : Dans le dossier choisi pour l’OCR, vérifiez le fichier *_trascrizione_parziale.txt et les métadonnées associées. Ils contiennent le travail enregistré progressivement, qui doit être vérifié et complété avant d’être considéré comme définitif.
