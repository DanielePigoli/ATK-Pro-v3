1. INSTALLATION ET PRÉREQUIS

────────────────────────────────────────────────────────────────────────────────

SYSTÈME D'EXPLOITATION

  • Windows : Windows 10 ou version ultérieure (64 bits) — Professional, Home, Server
  • Linux : Ubuntu 20.04 ou version ultérieure, ou distributions compatibles (paquet .deb ou archive .tar.gz)
  • macOS : macOS 11 Big Sur ou version ultérieure — distribution .dmg (tests sur du matériel réel en cours)
  • Architecture 64 bits obligatoire sur toutes les plateformes
  • Au moins 2 Go de RAM disponibles (4 Go recommandés pour le traitement par lots)
  • 1 Go d'espace disque libre

INSTALLATION

🪟 Windows

  1. Téléchargez ATK-Pro-Setup-vx.x.x.exe depuis la page officielle des versions
  2. Double-cliquez sur le fichier d'installation
  3. Sélectionnez « Exécuter avec des privilèges d'administrateur », si cela vous est demandé
  4. Suivez l'assistant d'installation (Suivant → Suivant → Installer)
  5. Lors de l'installation, vous devrez sélectionner la langue (20 langues disponibles)
  6. À la fin, cochez « Lancer ATK-Pro » pour démarrer le programme
  7. Acceptez les éventuels avertissements du pare-feu Windows/Defender

🐧 Linux

  1. Téléchargez ATK-Pro-vx.x.x.deb (Debian/Ubuntu) ou .tar.gz depuis la page des versions
  2. Paquet .deb : sudo dpkg -i ATK-Pro-vx.x.x.deb ou double-cliquez dans Nautilus/Files
  3. Archive .tar.gz : extrayez-la et lancez ./ATK-Pro depuis le dossier extrait
  4. La langue est sélectionnée au premier lancement et enregistrée dans le fichier de configuration de l'utilisateur

🍎 macOS

  1. Téléchargez ATK-Pro-vx.x.x.dmg depuis la page des versions
  2. Ouvrez le fichier .dmg et faites glisser ATK-Pro dans le dossier Applications
  3. Au premier lancement : clic droit → Ouvrir (nécessaire pour les applications non notariées)
  4. La langue est sélectionnée au premier lancement et enregistrée dans le fichier de configuration de l'utilisateur

EMPLACEMENTS PAR DÉFAUT

🪟 Windows

  • Programme : C:\Program Files\ATK-Pro\
  • Sortie utilisateur : C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • Entrée (facultative) : C:\Users\[TuoNome]\Documents\ATK-Pro\input\

🐧 Linux

  • Programme : /opt/ATK-Pro/ (deb) ou dossier extrait (.tar.gz)
  • Sortie utilisateur : ~/Documents/ATK-Pro/output/
  • Entrée (facultative) : ~/Documents/ATK-Pro/input/

🍎 macOS

  • Programme : /Applications/ATK-Pro.app
  • Sortie utilisateur : ~/Documents/ATK-Pro/output/
  • Entrée (facultative) : ~/Documents/ATK-Pro/input/

EXIGENCES RÉSEAU

  • Connexion Internet stable (obligatoire pour accéder aux Manifestes IIIF)
  • Pare-feu : Autorisez les connexions HTTPS sortantes (port 443)
  • Proxy d’entreprise : ATK-Pro ne dispose pas d’un menu interne permettant de saisir les identifiants du proxy. Configurez le proxy dans le système d’exploitation ou l’environnement réseau et vérifiez auprès de l’administrateur que les connexions HTTPS vers les portails sont autorisées.

📂 CONFIGURATION DES DOSSIERS

Lors de la première exécution, le programme crée automatiquement les dossiers suivants :

  • Windows : C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • Windows : C:\Users\[TuoNome]\Documents\ATK-Pro\output\doc\ (documents par défaut)
  • Windows : C:\Users\[TuoNome]\Documents\ATK-Pro\output\reg\ (registres par défaut)
  • Linux/macOS : analogues sous ~/Documents/ATK-Pro/output/
  • Dossier input\ analogue (facultatif, pour les fichiers d’entrée)

Pendant le traitement, des dossiers temporaires sont créés pour les tuiles téléchargées (tiles_canvas_X/) et, si le PDF est demandé, des fichiers temporaires sont créés pour sa génération.

Tous les dossiers et fichiers temporaires sont automatiquement supprimés à la fin du traitement.

Seuls les fichiers finaux traités sont conservés (images dans les formats choisis, PDF, manifestes et métadonnées).

Pour modifier les dossiers de sortie, utilisez Menu → Paramètres → « Sélectionner les dossiers de sortie ». Les choix sont enregistrés et restaurés automatiquement lors de la session suivante.

⚙️ PROFIL DE RESSOURCES

La commande Paramètres → Profil de ressources règle le parallélisme utilisé pendant le téléchargement, la reconstruction des images et la génération des PDF :

  • Léger : limite le nombre de processus simultanés et les pics d’utilisation de la mémoire ; recommandé pour les ordinateurs moins puissants ou les traitements très longs.
  • Équilibré : compromis par défaut entre vitesse et stabilité, adapté à la plupart des cas.
  • Rapide : utilise davantage de ressources pour réduire les délais ; choisissez-le uniquement sur des ordinateurs suffisamment performants.

Le profil ne modifie ni la qualité, ni les droits, ni la quantité des documents acquis. Les limites de précaution propres à un portail restent prioritaires.

3. INTERFACE PRINCIPALE

────────────────────────────────────────────────────────────────────────────────

DISPOSITION DE LA FENÊTRE

La fenêtre principale d’Antenati Toolkit Pro présente une structure simple et intuitive.

📝 LÉGENDE DE L’EN-TÊTE :

  • [🔲] Icône du programme (logo Antenati Toolkit Pro)
  • "ATK-Pro" Titre de la fenêtre
  • [_] Réduire (minimiser la fenêtre)
  • [□] Agrandir/Restaurer (maximiser ou restaurer la fenêtre)
  • [✕] Fermer (quitte le programme en affichant une bannière de soutien)

En bas figure la devise latine « Qui ante nos venerunt, in memoria nostra vivunt », qui rappelle l’importance des racines et de la mémoire collective.

BARRE DES MENUS

Dans la partie supérieure de la fenêtre, sous l’en-tête :

[Fichier d’entrée] [Sortie] [Services] [Documents] [Paramètres]

Chaque menu contient des boutons et des options spécifiques (voir la section suivante).

MENUS DISPONIBLES

1. FICHIER D’ENTRÉE

Gère le chargement des enregistrements IIIF :

├─ Exemple d’entrée
│  └─ Affiche le fichier d’exemple (présente le format des paires : mode D/R + URL)
├─ Ouvrir l’entrée
│  └─ Sélectionne un fichier .txt contenant vos enregistrements IIIF
│     (Il doit contenir des paires : mode D/R à la ligne 1, URL à la ligne 2)
└─ Modifier l’entrée
   └─ Modifie le fichier d’entrée actuellement chargé
      (Ajoutez/supprimez des enregistrements, modifiez les URL, enregistrez les modifications)

2. SORTIE

Gère le traitement et la sortie :

├─ Traiter
│  └─ Lance le téléchargement, la reconstitution et l’enregistrement des images
│     (Affiche une fenêtre de progression en temps réel)
├─ Ouvrir le dossier de sortie
│  └─ Ouvre dans l’Explorateur de fichiers le dossier contenant les fichiers traités
└─ Afficher les traitements précédents
   └─ Liste des enregistrements déjà traités

3. SERVICES

Liste des services intégrés :

├─ Recherche assistée par l’IA
│  └─ Suggère des portails, des pistes de recherche et des requêtes généalogiques à vérifier
├─ Affichage des images
│  └─ Visionneuse des images téléchargées et/ou des PDF générés
├─ Affichage des métadonnées JSON
│  └─ JSON d’origine et métadonnées (généalogiques, techniques, EXIF)
├─ OCR avancé
│  └─ Textes manuscrits du XIXe siècle, en latin ecclésiastique et de la fin du Moyen Âge
├─ Traduction OCR
│  └─ Traduction automatique des textes extraits dans les langues sélectionnées
└─ Exportation GEDCOM
   └─ GEDCOM, Gramps, Family Tree Maker, Ancestry, MyHeritage, WikiTree, etc.

4. DOCUMENTS

Accès aux ressources et à la documentation :

├─ Clause de non-responsabilité - Clauses juridiques et conditions d’utilisation
├─ Présentation de l’auteur - Parcours de l’auteur du projet
├─ Présentation du projet - Histoire, motivations et feuille de route d’ATK-Pro
├─ Guide - Index principal du guide modulaire
└─ Informations - Version, droits d’auteur et adresse e-mail de contact

5. PARAMÈTRES

Configuration générale du programme :

├─ Changer de langue
│  └─ Sélectionne la langue de l’interface (redémarrage requis)
├─ Sélectionner les formats d’image
│  └─ Choisissez parmi PNG, JPG, TIFF et PDF (au moins 1 obligatoire)
│     PDF peut être sélectionné seul ou avec les formats d’image
│     Le choix est mémorisé et présélectionné automatiquement lors de la session suivante
├─ Sélectionner les dossiers de sortie
│  └─ Ouvre d’abord le choix du mode de gestion des dossiers, puis les fenêtres de sélection :
│     • Dossier unique pour tous      → un seul dossier pour les documents et les registres
│     • Dossiers séparés doc/reg      → un dossier pour tous les documents, un autre pour tous les registres
│     • Un dossier par enregistrement → un dossier distinct pour chaque enregistrement
│     Le mode et les dossiers sont mémorisés et restaurés lors de la session suivante
├─ Exporter la configuration
│  └─ Enregistre les paramètres actuels dans un fichier
├─ Importer la configuration
│  └─ Charge un fichier de paramètres précédemment enregistré (restaure toutes les préférences et tous les chemins)
├─ Rechercher les mises à jour
│  └─ Vérifie si de nouvelles versions du programme sont disponibles
└─ Fermer
    └─ Quitte le programme (affiche une bannière de soutien PayPal.me)

CHANGEMENT DE LANGUE

La langue peut être changée à tout moment via Menu → Paramètres → Changer de langue.

Le programme nécessite un redémarrage pour appliquer la nouvelle langue.

Au redémarrage, le programme charge automatiquement la nouvelle langue sélectionnée.

TEXTES LOCALISÉS

Lors du changement de langue, les éléments suivants sont traduits :

  • Menus et boutons
  • Messages de progression
  • Boîtes de dialogue d'erreur et d'avertissement
  • Documents du menu Documents

REMARQUE SUR LES POLICES ET LA MISE EN PAGE

  • Les langues RTL (arabe, hébreu) modifient la mise en page (menus et contrôles alignés à droite)
  • Une police UTF-8 multilingue garantit un affichage correct
  • Si des caractères corrompus s'affichent sous Windows, mettez à jour vers Windows 10+ (problème rare)
