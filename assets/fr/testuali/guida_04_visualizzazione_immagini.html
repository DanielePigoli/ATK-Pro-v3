📌 Vue d’ensemble

Le Visualiseur d’images d’ATK-Pro est un outil intégré pour l'analyse de documents généalogiques numérisés. Il s'ouvre depuis le menu Services → Visualisation des images de l'application principale. Il prend en charge les formats JPEG, PNG et TIFF (y compris les fichiers multipages).

📂 Formats pris en charge

FormatExtensionRemarques
JPEG.jpg, .jpegPrise en charge complète
PNG.pngPrise en charge complète
TIFF.tif, .tiffPrise en charge multipage avec navigation dédiée

🖥️ Interface et commandes

🔍 Zoom

  • Molette de la souris : zoom progressif par pas de 15 %
  • Bouton “ + ” : agrandissement de 15 %
  • Bouton “ − ” : réduction de 15 %
  • Bouton “Adapter à la fenêtre” : redimensionne l'image pour occuper la zone disponible (proportionnellement)
  • Bouton “1:1” : affichage à la résolution native (un pixel de l'image = un pixel de l'écran)

Le niveau de zoom actuel est toujours visible dans l'indicateur de pourcentage situé entre les boutons + et −. La plage s'étend de 5 % à 800 %.

✋️ Panoramique (déplacement)

Clic et glissement : maintenez le bouton gauche de la souris enfoncé et faites glisser pour déplacer l'image. Le curseur prend la forme d'une main fermée pendant le déplacement et d'une main ouverte lorsqu'il survole la zone de l'image.

📅 TIFF multipage

Pour les fichiers TIFF contenant plusieurs images, une barre de navigation supplémentaire apparaît dans la barre d'outils :

  • Champ numérique (spinbox) : saisissez le numéro de la page souhaitée ; le visualiseur charge immédiatement l'image correspondante
  • Indicateur “/ N” : affiche le nombre total de pages à côté du champ numérique

Remarque : chaque image du fichier TIFF est gérée comme une page distincte.

📋 Panneau de métadonnées sidecar (panneau droit)

Si un fichier JSON portant le même nom de base se trouve dans le même dossier que l'image (par ex. documento.jpg → recherche documento.json), le panneau droit affiche les métadonnées sous forme de tableau.

  • Bouton “◄ Masquer les métadonnées” : masque le panneau droit afin d'agrandir la zone d'affichage de l'image
  • Bouton “► Afficher les métadonnées” : rétablit le panneau des métadonnées

Si aucun sidecar JSON n'est trouvé, le panneau droit affiche “Aucun sidecar JSON trouvé”. Si le fichier existe mais ne peut pas être lu, le panneau signale une erreur de lecture des métadonnées.
