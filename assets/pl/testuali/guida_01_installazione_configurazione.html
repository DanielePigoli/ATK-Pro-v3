1. INSTALACJA I WYMAGANIA

──────────────────── ──────────────────── ──────────────────── ────────────────────

SYSTEM OPERACYJNY

  • Windows: Windows 10 lub nowszy (64-bitowy) — Profesjonalny, Domowy, Serwer
  • Linux: Ubuntu 20.04+ lub kompatybilne dystrybucje (pakiet .deb lub archiwum .tar.gz)
  • macOS: macOS 11 Big Sur lub nowszy — dystrybucja .dmg (trwa testowanie na prawdziwym sprzęcie)
  • Na wszystkich platformach wymagany jest system 64-bitowy
  • Co najmniej 2 GB dostępnej pamięci RAM (zalecane 4 GB do przetwarzania wsadowego)
  • 1 GB wolnego miejsca na dysku

INSTALACJA

🪟Windows

  1. Pobierz ATK-Pro-Setup-vx.x.x.exe z oficjalnej strony wydania
  2. Kliknij dwukrotnie plik instalacyjny
  3. Jeśli pojawi się monit, wybierz opcję „Uruchom z uprawnieniami administratora”.
  4. Postępuj zgodnie z instrukcjami kreatora (Dalej → Dalej → Zainstaluj)
  5. Podczas instalacji zostaniesz poproszony o wybranie języka (20 dostępnych)
  6. Po zakończeniu zaznacz opcję „Uruchom ATK-Pro”, aby uruchomić program
  7. Zaakceptuj wszelkie ostrzeżenia z zapory sieciowej Windows/Defender

🐧 Linux

  1. Pobierz ATK-Pro-vx.x.x.deb (Debian/Ubuntu) lub .tar.gz na stronie Wydanie
  2. pakiet .deb: sudo dpkg -i ATK-Pro-vx.x.x.deb lub kliknij dwukrotnie Nautilus/Files
  3. Archiwum .tar.gz: wypakuj i uruchom ./ATK-Pro z wyodrębnionego folderu
  4. Język jest wybierany przy pierwszym uruchomieniu i zapisywany w pliku konfiguracyjnym użytkownika

🍎macOS

  1. Pobierz ATK-Pro-vx.x.x.dmg na stronie Wydanie
  2. Otwórz plik .dmg i przeciągnij ATK-Pro do folderu Aplikacje
  3. Przy pierwszym uruchomieniu: kliknij prawym przyciskiem myszy → Otwórz (konieczne w przypadku aplikacji nienotarialnych)
  4. Język jest wybierany przy pierwszym uruchomieniu i zapisywany w pliku konfiguracyjnym użytkownika

POZYCJE DOMYŚLNE

🪟Windows

  • Program: C:\Program Files\ATK-Pro\
  • Dane wyjściowe użytkownika: C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • Wejścia (opcjonalnie): C:\Users\[TuoNome]\Documents\ATK-Pro\input\

🐧 Linux

  • Program: /opt/ATK-Pro/ (deb) lub wyodrębniony folder (.tar.gz)
  • Dane wyjściowe użytkownika: ~/Documents/ATK-Pro/output/
  • Wejścia (opcjonalnie): ~/Documents/ATK-Pro/input/

🍎macOS

  • Program: /Applications/ATK-Pro.app
  • Dane wyjściowe użytkownika: ~/Documents/ATK-Pro/output/
  • Wejścia (opcjonalnie): ~/Documents/ATK-Pro/input/

WYMAGANIA SIECIOWE

  • Stabilne połączenie internetowe (wymagane do uzyskania dostępu do manifestów IIIF)
  • Zapora sieciowa: Zezwalaj na wychodzące połączenia HTTPS (port 443)
  • Enterprise Proxy: ATK-Pro nie ma wewnętrznego menu dla poświadczeń proxy. Skonfiguruj serwer proxy w swoim systemie operacyjnym lub środowisku sieciowym i sprawdź u administratora, czy dozwolone są połączenia HTTPS z portalami.

📂 KONFIGURACJA FOLDERÓW

Przy pierwszym uruchomieniu program automatycznie tworzy następujące foldery:

  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\doc\ (dokumenty domyślne)
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\reg\ (rejestry domyślne)
  • Linux/macOS: podobne poniżej ~/Documents/ATK-Pro/output/
  • Folder input\ analogicznie (opcjonalnie, dla pliku wejściowego)

Podczas przetwarzania dla pobranych kafelków tworzone są foldery tymczasowe (tiles_canvas_X/) oraz, jeśli wymagane jest PDF, pliki tymczasowe do jego wygenerowania.

Wszystkie foldery i pliki tymczasowe są automatycznie usuwane po zakończeniu przetwarzania.

Pozostają tylko finalnie przetworzone pliki (obrazy w wybranych formatach, PDF, manifest i metadane).

Aby zmienić foldery wyjściowe, użyj Menu → Ustawienia → „Wybierz foldery wyjściowe”. Twoje wybory zostaną zapisane i automatycznie przywrócone do następnej sesji.

⚙️PROFIL ZASOBÓW

Polecenie Ustawienia → Profil zasobów dostosowuje równoległość używaną podczas pobierania, rekonstrukcji obrazu i generowania PDF:

  • Lekki: ogranicza współbieżne procesy i skoki pamięci; nadaje się do mniej wydajnych komputerów lub bardzo długich procesów.
  • Zrównoważony: predefiniowany kompromis pomiędzy szybkością i stabilnością, odpowiedni w większości przypadków.
  • Szybko: wykorzystywać więcej zasobów, aby skrócić czas; wybieraj go tylko na komputerach o wystarczająco dużej wydajności.

Profil nie zmienia jakości, praw ani ilości pozyskiwanych dokumentów. Limity ostrożnościowe specyficzne dla portalu nadal mają pierwszeństwo.

UKŁAD OKNA

Główne okno Antenati Toolkit Pro ma prostą i intuicyjną strukturę.

📝TESTOWANA LEGENDA:

  • [🔲] Ikona programu (logo Ancestors Toolkit Pro)
  • Tytuł okna „ATK-Pro”.
  • [_] Minimalizuj (minimalizuj okno)
  • [□] Rozwiń/Collassa (maksymalizuj lub przywróć okno)
  • [✕] Zamknij (zakończ program z banerem wsparcia)

Na dole widnieje łacińskie motto „Qui ante nos veneunt, in memoria nostra vivunt”, upamiętniające znaczenie korzeni i pamięci zbiorowej.

PASEK MENU

W górnej części okna, pod nagłówkiem:

[Pliki wejściowe] [Wyjście] [Usługi] [Dokumenty] [Ustawienia]

Każde menu zawiera określone przyciski i opcje (patrz następna sekcja).

DOSTĘPNE MENU

1. PLIK WEJŚCIOWY

Zarządza ładowaniem rekordów IIIF:

├─ Esempio input
│  └─ Visualizza il file di esempio (mostra formato coppie: modalità D/R + URL)
├─ Apri input
│  └─ Seleziona un file .txt con i tuoi record IIIF
│     (Deve contenere coppie: modalità D/R su riga 1, URL su riga 2)
└─ Modifica input
   └─ Modifica il file input attualmente caricato
      (Aggiungi/rimuovi record, cambia URL, salva modifiche)

2. WYJŚCIE

Zarządza przetwarzaniem i wynikami:

├─ Elabora
│  └─ Avvia il download, la ricostruzione e il salvataggio delle immagini
│     (Mostra finestra di progresso in tempo reale)
├─ Apri cartella output
│  └─ Apre in Esplora Risorse la cartella con i file elaborati
└─ Visualizza elaborazioni precedenti
   └─ Lista dei record già elaborati

3. USŁUGI

Lista zintegrowanych usług:

├─ Ricerca assistita AI
│  └─ Suggerisce portali, piste di ricerca e query genealogiche da verificare
├─ Visualizzazione Immagini
│  └─ Viewer immagini scaricate e/o PDF generati
├─ Visualizzazione Metadati JSON

├─ Traduzione OCR
│  └─ Traduzione automatica testi estratti nelle lingue selezionate
└─ Esportazione GEDCOM
   └─ GEDCOM, Gramps, Family Tree Maker, Ancestry, MyHeritage, WikiTree, etc.

4. DOKUMENTY

Dostęp do zasobów i dokumentacji:

├─ Disclaimer - Clausole legali e termini d'uso

├─ Presentazione progetto - Storia, motivazioni, roadmap di ATK-Pro

5. USTAWIENIA

Ogólna konfiguracja programu:

├─ Cambia lingua
│  └─ Seleziona la lingua dell'interfaccia (richiede riavvio)
├─ Seleziona formati immagine
│  └─ Scegli tra PNG, JPG, TIFF e PDF (almeno 1 obbligatorio)
│     PDF può essere selezionato da solo o insieme ai formati immagine
│     La scelta viene memorizzata e pre-selezionata automaticamente alla sessione successiva
├─ Seleziona cartelle output
│  └─ Apre prima la scelta della modalità cartelle, poi le finestre di selezione:
│     • Cartella unica per tutti    → una sola cartella per documenti e registri
│     • Cartelle separate doc/reg   → una cartella per tutti i doc, una per tutti i reg
│     • Cartella per ogni record    → una cartella distinta per ciascun record
│     La modalità e le cartelle vengono memorizzate e ripristinate alla sessione successiva
├─ Esporta configurazione
│  └─ Salva le impostazioni attuali in un file
├─ Importa configurazione
│  └─ Carica un file di impostazioni precedentemente salvato (ripristina tutte le preferenze e percorsi)
├─ Verifica aggiornamenti
│  └─ Controlla la disponibilità di nuove versioni del programma
└─ Chiudi
    └─ Termina il programma (mostra banner di supporto PayPal.me)
