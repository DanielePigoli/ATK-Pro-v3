1. ΦΟΡΤΩΣΗ ΕΓΓΡΑΦΩΝ - ΜΟΡΦΕΣ ΕΙΣΟΔΟΥ

──────────────────── ──────────────────── ──────────────────── ────────────────────

📥 ΔΟΜΗ ΕΙΣΟΔΟΥ ΚΑΙ ΥΠΟΣΤΗΡΙΖΟΜΕΝΕΣ ΠΥΛΕΣ

Το ATK-Pro δέχεται αρχεία εισόδου με συγκεκριμένη μορφή με βάση τα ΖΕΥΓΑ: Για ΚΑΘΕ εγγραφή προς επεξεργασία, δώστε Mode + URL.

Υποστηριζόμενες πύλες: αντιγράψτε και επικολλήστε το δημόσιο URL της σελίδας, του προγράμματος προβολής, του μανιφέστου ή του συμβατού PDF. Το ATK-Pro αναγνωρίζει την πύλη και εφαρμόζει τη σχετική τεχνική και προληπτική μέθοδο.

Υποστηρίζεται υποδεικνύει επαληθευμένη τεχνική συμβατότητα, όχι αδιάκριτη εξουσιοδότηση λήψης. Ο πόρος πρέπει να είναι δημόσια προσβάσιμος και ο χρήστης πρέπει να σέβεται τα δικαιώματα, τις άδειες, τους όρους χρήσης και τα όρια της μεμονωμένης πύλης. Το ATK-Pro δεν παρακάμπτει τις συνδέσεις, τις συνδέσεις θυγατρικών, τα paywalls ή τους δείκτες nodownload.

1. ΣΕΙΡΑ 1: Λειτουργία + Όνομα (προαιρετικό)

  • D = Μεμονωμένο έγγραφο (μια μεμονωμένη εικόνα/pagina)
  • R = Μητρώο (πλήρης συλλογή σελίδων/documenti)

2. ΣΕΙΡΑ 2: Δημόσιο URL της εγγραφής ή του πόρου

Παράδειγμα σωστού αρχείου input.txt:

# Commenti iniziano con #

RECORD 1 (coppia di righe):
D - Lettera Importante
https://biblioteca.example.org/iiif/doc123/manifest.json

RECORD 2 (coppia di righe):
R - Registro Amministrativo 1920-1925
https://archives.example.org/iiif/reg456/manifest.json

RECORD 3 (coppia di righe):
D - Fotografia Singola
https://collections.example.org/iiif/foto789/manifest.json

📝 ΚΑΝΟΝΕΣ ΜΟΡΦΗΣ ΕΙΣΑΓΩΓΗΣ:

  • Κενές γραμμές: αγνοήθηκαν (μπορείτε να τις χρησιμοποιήσετε για αναγνωσιμότητα)
  • Γραμμές με #: Αγνοήθηκαν ως σχόλια
  • Οι λειτουργίες D/d ή R/r: είναι υποχρεωτικές. κεφαλαία και πεζά είναι ισοδύναμα
  • Όνομα αρχείου: προαιρετική μετά τη λειτουργία (π.χ. "D - Όνομα" ή απλώς "D")
  • URL: Πρέπει να ξεκινήσει με http:// ή https://
  • Ζεύγη: η λειτουργία + URL πρέπει να είναι σε διαδοχικές γραμμές

⚙️ ΠΩΣ ΝΑ ΦΟΡΤΩΣΕΤΕ ΤΗΝ ΕΙΣΟΔΟ - 3 ΕΠΙΛΟΓΕΣ ΑΠΟ ΤΟ ΜΕΝΟΥ:

ΕΠΙΛΟΓΗ 1: Προβολή παραδείγματος εισαγωγής ──────────────────

1. Κάντε κλικ στο Μενού → "Αρχείο εισαγωγής" → "Παράδειγμα εισαγωγής"

2. Ανοίγει ένα παράθυρο που δείχνει το τοπικό δείγμα αρχείου

3. Μπορείτε να αντιγράψετε το περιεχόμενο ως πρότυπο για το αρχείο εισόδου σας

4. Παράδειγμα αρχείου: assets/[lingua]/testuali/input_link_base.txt

Σημείωση για το όνομα αρχείου: καλείται το κατανεμημένο αρχείο input_link_base.txt. Το όνομα έχει κανονικοποιηθεί στο v3 για να αποφευχθούν οι αναφορές σε προηγούμενες εκδόσεις. η μορφή παραμένει αυτή που είναι συμβατή με τη φόρτωση εγγραφών IIIF.

ΕΠΙΛΟΓΗ 2: Ανοίξτε το αρχείο έτοιμου εισόδου ──────────────────

1. Κάντε κλικ στο Μενού → "Αρχείο Εισόδου" → "Άνοιγμα Εισόδου"

2. Ανοίγει ένα παράθυρο διαλόγου επιλογής αρχείου

3. Επιλέξτε το αρχείο σας input.txt (πρέπει να τηρεί τη μορφή των ζευγών)

4. Το ATK-Pro φορτώνει αυτόματα και διαβάζει όλες τις εγγραφές

5. Δείτε τον αριθμό των εγγραφών που έχουν φορτωθεί και είναι έτοιμες για επεξεργασία

ΕΠΙΛΟΓΗ 3: Επεξεργασία εισαγωγής έχει ήδη φορτωθεί ───────────────────── ─────────────────────

1. Μετά τη φόρτωση ενός αρχείου εισόδου (ΕΠΙΛΟΓΗ 2)

2. Κάντε κλικ στο Menu → "Input File" → "Edit Input"

3. Ανοίγει ένα πρόγραμμα επεξεργασίας κειμένου με το τρέχον φορτωμένο αρχείο

4. Επεξεργασία ζευγαριών (προσθήκη, αφαίρεση, αλλαγή URL)

5. Κάντε κλικ στο "Αποθήκευση" για να ενημερώσετε τις εγγραφές που υποβάλλονται σε επεξεργασία

6. Το πρόγραμμα επανερμηνεύει το ενημερωμένο αρχείο

📌 ΔΙΑΦΟΡΑ ΜΕΤΑΞΥ D ΚΑΙ R:

  • D (Έγγραφο): Διαχειρίζεται μια μεμονωμένη εικόνα/pagina
  • → Έξοδος: Ένα αρχείο για το έγγραφο
  • R (Μητρώο): Διαχειρίζεται συλλογές πολλών σελίδων
  • → Έξοδος: φάκελος με οργανωμένες σελίδες + PDF (εάν ζητηθεί από τον χρήστη)

✅ ΕΠΙΚΥΡΩΣΗ ΡΕΚΟΡ

Μετά τη φόρτωση, το πρόγραμμα ελέγχει:

  • ✓ URL προσβάσιμο και προσβάσιμο
  • ✓ Συμβατός πόρος: manifest IIIF v2/v3, υποστηριζόμενη σελίδα, εικόνα ή απευθείας PDF σύμφωνα με την πύλη
  • ✓ Αριθμός διαθέσιμων εικόνων και καμβάδων
  • ✓ Μεταδεδομένα (τίτλος, συγγραφέας, ημερομηνία)

❌ ΣΥΝΗΘΗ ΛΑΘΗ

  • "URL μη έγκυρο": Ελέγξτε το copy/incolla URL
  • "Το μανιφέστο δεν βρέθηκε (404)": Το URL έχει λήξει ή είναι λάθος
  • "Η μορφή IIIF δεν υποστηρίζεται": Ο διακομιστής δεν χρησιμοποιεί τυπικό IIIF
  • "Λήξη χρόνου σύνδεσης": Αργή σύνδεση στο Διαδίκτυο/assente

💾 ΑΠΟΘΗΚΕΥΣΗ ΕΓΓΡΑΦΩΝ

Μετά τη φόρτωση της δήλωσης, το πρόγραμμα αποθηκεύει αυτόματα τα μεταδεδομένα IIIF. ΠΟΥ: Στο φάκελο εξόδου που επιλέγετε (δείτε Ενότητα 2, ΒΗΜΑ 2) ΔΟΜΗ ΦΑΚΕΛΟΥ ΜΕΤΑ ΤΗ ΦΟΡΤΩΣΗ (πριν από την επεξεργασία):

[cartella_output]/
 ├─ manifest_[ID]_[nome].json         ← Manifest IIIF originale (livello principale)
 └─ [nome]/                            ← Sottocartella SOLO per metadati
    ├─ [nome]_genealogico.json        ← Metadati genealogici estratti
    └─ [nome]_tecnico.json            ← Metadati tecnici (canvas ID, numero pagine)

ΜΕΤΑ ΤΗΝ ΕΠΕΞΕΡΓΑΣΙΑ (όταν κάνετε κλικ στο Μενού → Έξοδος → Διεργασία): Τα επεξεργασμένα αρχεία προστίθενται στο κύριο επίπεδο:

[cartella_output]/
 ├─ manifest_[ID]_[nome].json         ← Manifest IIIF originale
 ├─ [nome]_canvas_1.jpg/.png/.tif     ← Immagini ricostruite dai tile IIIF (una per pagina)
 ├─ [nome]_canvas_2.jpg/.png/.tif       (formato dipende da quello selezionato)
 ├─ [nome]_canvas_N.jpg/.png/.tif       (N = numero totale di pagine/canvas)
 ├─ [nome].json                        ← Sidecar JSON per ogni immagine (metadati EXIF)
 └─ [nome].pdf                         ← PDF completo (vedi spiegazione sotto)

Τα μεταδεδομένα παραμένουν στον [όνομα]/ υποφάκελο όπως αποθηκεύτηκαν κατά τη μεταφόρτωση.

ΣΗΜΑΝΤΙΚΗ ΣΗΜΕΙΩΣΗ: Οργάνωση αρχείων

  • Manifest IIIF: επίπεδο ρίζας του φακέλου εξόδου
  • Εικόνες (καμβάς), PDF, Sidecar JSON: επίπεδο ρίζας του φακέλου εξόδου
  • ΜΟΝΟ τεχνικά και γενεαλογικά μεταδεδομένα: αποθηκεύονται στον υποφάκελο [όνομα]/
  • Οι προσωρινοί φάκελοι (tiles_canvas_X/) διαγράφονται αυτόματα όταν τελειώσουν
  • Αυτή η δομή σάς επιτρέπει να διαχειρίζεστε πολλές εγγραφές στον ίδιο φάκελο χωρίς σύγχυση

Παράδειγμα: Εάν επεξεργαστείτε το "Register1", θα βρείτε:

  • manifest_[ID1]_Registro1.json (ανώτατο επίπεδο)
  • Registro1_canvas_1.jpg, Registro1_canvas_2.jpg, ... (κύριο επίπεδο)
  • Registro1.pdf (κύριο επίπεδο)
  • Registro1/ (υποφάκελος ΜΟΝΟ με γενεαλογικά και τεχνικά μεταδεδομένα)

2. ΕΠΕΞΕΡΓΑΣΙΑ ΚΑΙ ΛΗΨΗ ΕΙΚΟΝΩΝ

──────────────────── ──────────────────── ──────────────────── ────────────────────

🎯 ΡΟΗ ΕΠΕΞΕΡΓΑΣΙΑΣ

Η ροή εργασιών επεξεργασίας περιλαμβάνει 3 βήματα:

ΒΗΜΑ 1: ΕΠΙΛΟΓΗ ΜΟΡΦΩΝ ΕΙΚΟΝΑΣ

──────────────────

1. Φόρτωση αρχείου εισόδου (Αρχείο εισόδου → Άνοιγμα εισόδου): το παράθυρο μορφών ανοίγει αυτόματα

2. Εναλλακτικά: Κάντε κλικ στο Μενού → "Ρυθμίσεις" → "Επιλογή μορφών εικόνας"

3. Ανοίγει ένα παράθυρο διαλόγου με 3 επιλογές:

☐ PNG → Μορφή χωρίς απώλειες, καλύτερη ποιότητα, μεγαλύτερα αρχεία

☐ JPG → Συμπιεσμένη μορφή (απώλεια), καλής ποιότητας συμβιβασμός/dimensione

☐ TIFF → Μορφή αρχειοθέτησης, υψηλότερης ποιότητας, πολύ μεγάλα αρχεία

Έγγραφο PDF

☐ PDF → Δημιουργήστε ένα πλήρες PDF με όλες τις σελίδες του αρχείου καταγραφής ή του εγγράφου, επιπλέον των επιλεγμένων μορφών εικόνας (ή ως η μόνη έξοδος εάν δεν έχει επιλεγεί μορφή εικόνας)

4. Επιλέξτε τουλάχιστον μία μορφή εικόνας ή PDF (μπορείτε να επιλέξετε περισσότερες από μία)

5. Κάντε κλικ στο "Επιβεβαίωση"

✅ Οι επιλεγμένες μορφές αποθηκεύονται και προεπιλέγεται αυτόματα την επόμενη φορά που θα ανοίξετε το πρόγραμμα.

📝 ΣΥΜΒΟΥΛΕΣ:

  • Για προεπισκόπηση/consultazione: JPG (γρήγορο άνοιγμα, λιγότερος χώρος)
  • Για συντηρητικό αρχείο: PNG (χωρίς απώλειες, συμβιβασμός χώρου) ή TIFF (μέγιστη ποιότητα)
  • Και για τα δύο: επιλέξτε PNG και TIFF
  • Για PDF: Επιλέξτε PDF μαζί με μία ή περισσότερες μορφές εικόνας ή επιλέξτε PDF μόνο για να δημιουργήσετε μόνο το έγγραφο PDF χωρίς ξεχωριστά αρχεία εικόνας

ΒΗΜΑ 2: ΕΠΙΛΟΓΗ ΦΑΚΕΛΩΝ ΕΞΟΔΟΥ

──────────────────

1. Το παράθυρο φακέλου ανοίγει αυτόματα αφού επιλέξετε μορφές (όταν φορτώνετε ένα αρχείο εισόδου)

2. Εναλλακτικά: Κάντε κλικ στο Μενού → "Ρυθμίσεις" → "Επιλογή φακέλων εξόδου"

3. Επιλέξτε τη λειτουργία οργάνωσης φακέλων:

⬤ Ενιαίος φάκελος για όλους → ένας μόνο φάκελος για όλες τις εγγραφές (έγγραφο και μητρώα)

⬤ Ξεχωριστοί φάκελοι doc/reg → ένας φάκελος για όλα τα έγγραφα, ένας για όλα τα μητρώα

⬤ Φάκελος για κάθε εγγραφή → έναν ξεχωριστό φάκελο για κάθε εγγραφή στο αρχείο εισόδου

4. Αφού επιλέξετε τη λειτουργία, επιλέξτε τους απαιτούμενους φακέλους (1, 2 ή N παράθυρα διαλόγου)

5. Στο τέλος εμφανίζει τη σύνοψη των επιλεγμένων φακέλων

✅ Οι λειτουργίες και οι φάκελοι αποθηκεύονται. Την επόμενη φορά που ανοίγει ένα αρχείο εισόδου, αποκαθίσταται αυτόματα εάν είναι συμβατό με τον αριθμό των εγγραφών.

⚠️ Εάν το νέο αρχείο εισαγωγής έχει διαφορετικό αριθμό Documents/Registri από τους αποθηκευμένους φακέλους, εμφανίζεται μια προειδοποίηση και η επιλογή επαναφέρεται για να ζητηθούν νέοι φάκελοι.

🛡️ Προληπτικός έλεγχος διαδρομών: Πριν δημιουργήσετε φακέλους ή αρχεία, το ATK-Pro ελέγχει τα αναμενόμενα ονόματα και διαδρομές. Τα ονόματα που δεν είναι συμβατά με το Windows και τα υπερβολικά μεγάλα τμήματα αποκλείουν μόνο την επηρεαζόμενη εγγραφή. Οι προειδοποιήσεις συμβατότητας εμφανίζονται στην τελική περίληψη.

☁️ Το OneDrive/SharePoint δεν θεωρείται ως ο προεπιλεγμένος προορισμός. Τα όριά του εφαρμόζονται μόνο όταν ο επιλεγμένος φάκελος βρίσκεται στην πραγματικότητα κάτω από μια ρίζα OneDrive. Στις υπόλοιπες διαδρομές, το ιστορικό όριο Windows των 260 χαρακτήρων αντιμετωπίζεται ως προληπτική προειδοποίηση και όχι ως αυτόματο μπλοκ.

📌 ΣΥΝΟΨΗ ΛΕΙΤΟΥΡΓΙΑΣ:

  • Ενιαίος φάκελος: Απλά, όλα σε ένα μέρος. Κατάλληλο για γρήγορη επεξεργασία ή δοκιμή
  • Ξεχωριστό doc/reg: Οργάνωση ανά τύπο. Προεπιλογές: output/doc/ ε output/reg/
  • Για κάθε εγγραφή: Μέγιστη ευελιξία. Μπορείτε να χρησιμοποιήσετε διαφορετικές μονάδες δίσκου, NAS, προσαρμοσμένους φακέλους

ΒΗΜΑ 3: ΞΕΚΙΝΗΣΤΕ ΤΗΝ ΕΠΕΞΕΡΓΑΣΙΑ

───────────────────────

1. Κάντε κλικ στο Μενού → "Έξοδος" → "Διαδικασία"

2. Ελέγξτε ότι:

✓ Επιλέχθηκε τουλάχιστον 1 μορφή εικόνας

✓ Μεταφορτώθηκε τουλάχιστον 1 εγγραφή

Εάν λείπουν αυτές οι απαιτήσεις, εμφανίζεται ένα μήνυμα σφάλματος:

❌ "Δεν έχει επιλεγεί μορφή" → Μεταβείτε στο ΒΗΜΑ 1

❌ "Δεν έχουν φορτωθεί εγγραφές" → Μεταβείτε στη Φόρτωση εισόδου (Ενότητα 1)

📺 ΠΑΡΑΘΥΡΟ ΕΠΕΞΕΡΓΑΣΙΑΣ

Μόλις κάνετε κλικ στο "Επεξεργασία", ανοίγει ένα παράθυρο με τα εξής:

📊 ΟΡΑΤΑ ΣΤΟΙΧΕΙΑ:

1️⃣ ΤΙΤΛΟΣ ΠΑΡΑΘΥΡΟΥ: "Επεξεργασία"

  • Παραμένει στο προσκήνιο μέχρι να ολοκληρωθεί η επεξεργασία
  • Δεν μπορείτε να αλληλεπιδράσετε με το υπόλοιπο GUI

2️⃣ ΕΤΙΚΕΤΑ ΠΡΟΟΔΟΥ: "Επεξεργασία εγγραφών: 2/5 — Όνομα αρχείου"

  • Εμφάνιση: τρέχουσα επεξεργασμένη εγγραφή (2) από το σύνολο (5)
  • Εμφανίζει επίσης το όνομα του αρχείου /registro που υποβάλλεται σε επεξεργασία
  • Ενημερώνεται σε πραγματικό χρόνο καθώς επεξεργάζεται εγγραφές
  • Π.χ.: "Επεξεργασία αρχείων: 1/3 — Μητρώο γάμου 1850"

3️⃣ BAR PROGRESS: Οπτική πρόοδος

  • Μορφή αριθμού: "2/5" (τρέχων / συνολικός αριθμός)
  • Η χρωματική γραμμή προχωρά από αριστερά προς τα δεξιά
  • Φτάνει στο 100% (μέγιστο πλάτος) όταν είναι γεμάτο
  • ΔΕΝ δείχνει ποσοστό, μόνο αριθμό

4️⃣ ΚΟΥΜΠΙ [ΑΚΥΡΩΣΗ]

  • Δυνατότητα κλικ κατά την επεξεργασία
  • Σας ζητά να ακυρωθεί ολόκληρη η παρτίδα και κλείνει το παράθυρο προόδου
  • Ο τερματισμός είναι συνεργάσιμος: μπορεί να περιμένει την ολοκλήρωση του μεμονωμένου αιτήματος δικτύου που βρίσκεται ήδη σε εξέλιξη
  • Κανένα αποτέλεσμα από την ακυρωμένη συνεδρία δεν δημοσιεύεται στον επιλεγμένο φάκελο. τα προϋπάρχοντα αρχεία παραμένουν αμετάβλητα

🔄 ΚΑΤΑ ΤΗΝ ΕΠΕΞΕΡΓΑΣΙΑ

Το πρόγραμμα παρασκηνίου:

├─ Scarica immagini dai server IIIF
├─ Legge manifest per canvas ID
├─ Ricostruisce tile in immagini complete
├─ Converte nei formati selezionati (PNG, JPG, TIFF)
└─ Salva nelle cartelle scelte

Το GUI δείχνει την πρόοδο σε πραγματικό χρόνο:

  • Κάθε 2-3 δευτερόλεπτα ενημερώνεται ο αριθμός ρεκόρ
  • Χωρίς παγώσεις: η διεπαφή παραμένει αποκριτική
  • Μπορείτε να ακυρώσετε ανά πάσα στιγμή

⚠️ ΣΥΜΠΕΡΙΦΟΡΑ ΑΝ ΚΑΝΕΤΕ ΚΛΙΚ ΑΚΥΡΩΣΗ:

1. Ζητείται συνεργατική διακοπή λειτουργίας ολόκληρης της παρτίδας

2. Όλη η προσωρινή παραγωγή που παράγεται από την ακυρωμένη παρτίδα διαγράφεται

3. Τα αρχεία που υπάρχουν ήδη στους φακέλους εξόδου πριν από την εκκίνηση παραμένουν αμετάβλητα

4. Μπορείτε να ξεκινήσετε ξανά από το Μενού → Έξοδος → Διαδικασία

📋 PDF — ΑΥΤΟΜΑΤΗ ΠΑΡΑΓΩΓΗ ΚΑΤΑ ΤΗΝ ΕΠΕΞΕΡΓΑΣΙΑ

Εάν έχετε επιλέξει PDF στη μάσκα επιλογής μορφής (ΒΗΜΑ 1), το PDF δημιουργείται αυτόματα στο τέλος της λήψης κάθε μητρώου ή εγγράφου, χωρίς πρόσθετο παράθυρο επιβεβαίωσης.

📌 ΣΥΜΠΕΡΙΦΟΡΑ:

  • ✅ PDF επιλεγμένο στη μάσκα μορφής: το PDF δημιουργείται αυτόματα στο τέλος της λήψης. δεν ζητείται πρόσθετη επιβεβαίωση
  • ❌ PDF δεν έχει επιλεγεί: μόνο εικόνες στις επιλεγμένες μορφές, όχι PDF

Χαρακτηριστικά του παραγόμενου PDF:

  • Όνομα αρχείου: [nome].pdf, χωρίς πρόσθετα επιθήματα (π.χ. Registro Matrimoni 1920.pdf)
  • Αποθηκεύεται στον επιλεγμένο φάκελο εξόδου, στο ίδιο επίπεδο με τις εικόνες
  • Σελίδες σε αύξουσα αριθμητική σειρά (καμβάς 1 → καμβάς 2 → … → καμβάς N)
  • Εάν δεν υπάρχει δυνατότητα λήψης ενός καμβά, εισάγεται μια σελίδα κράτησης θέσης εντοπισμένο με απευθείας σύνδεσμο στον αρχικό καμβά στο Ancestors
  • Δεν παραμένουν προσωρινά αρχεία στο φάκελο εξόδου μετά την ολοκλήρωση της δημιουργίας

⚠️ ΤΙ ΝΑ ΜΗΝ ΚΑΝΕΤΕ ΚΑΤΑ ΤΗΝ ΕΠΕΞΕΡΓΑΣΙΑ:

  • ❌ Μην κλείσετε το πρόγραμμα (χάνει μερικά αρχεία)
  • ❌ Μην αφαιρείτε τον εξωτερικό δίσκο (σφάλμα αποθήκευσης)
  • ❌ Μην απενεργοποιείτε το PC/laptop
  • ❌ Μην αποσυνδέετε το διαδίκτυο (διακοπή λήψης)

✅ ΤΙ ΜΠΟΡΕΙΤΕ ΝΑ ΚΑΝΕΤΕ:

  • ✓ Περιμένετε να τελειώσει (αυτή είναι κανονική διαδικασία)
  • ✓ Κάντε κλικ στην Ακύρωση εάν είναι επείγον
  • ✓ Χρησιμοποιήστε τον υπολογιστή για άλλα πράγματα κανονικά (απλώς ελαχιστοποιήστε το παράθυρο)

🎉 ΤΕΛΟΣ ΕΠΕΞΕΡΓΑΣΙΑΣ

Όταν έχουν υποβληθεί σε επεξεργασία όλες οι εγγραφές:

1. Το παράθυρο προόδου κλείνει αυτόματα

2. Εμφανίζεται ένα μήνυμα: "Η λειτουργία ολοκληρώθηκε"

3. Κάντε κλικ στο OK για να κλείσετε το μήνυμα

4. Το παράθυρο προόδου εξαφανίζεται εντελώς

Μετά από:

  • Προβάλετε τα αρχεία εξόδου στους φακέλους που επιλέξατε στο ΒΗΜΑ 2
  • Κάθε έγγραφο/registro έχει τον δικό του υποφάκελο μέσα στο φάκελο που επιλέξατε
  • Οι εικόνες είναι έτοιμες για χρήση (προβολή, εκτύπωση, αρχειοθέτηση, PDF)

✅ ΠΑΡΑΓΩΓΗ ΕΞΟΔΟΣ:

Για κάθε επεξεργασμένη εγγραφή θα βρείτε:

  • Εικόνες σε επιλεγμένες μορφές (PNG, JPG, TIFF)
  • manifest_[ID]_[όνομα].json → Πρωτότυπο Manifest IIIF με δομημένα μεταδεδομένα
  • [όνομα]_genealogico.json → Γενεαλογικά μεταδεδομένα (ημερομηνίες, τόποι, ονόματα, δήμοι, επαρχίες)
  • [όνομα]_tecnico.json → Τεχνικά μεταδεδομένα (αριθμός καμβά, λίστα αναγνωριστικών καμβά, δικαιώματα, αρχεία που δημιουργούνται)
  • [όνομα].json → Sidecar JSON για κάθε εικόνα (ενσωματωμένα μεταδεδομένα EXIF)

📝 ΣΗΜΕΙΩΣΗ ΓΙΑ ΤΑ ΟΝΟΜΑΤΑ ΑΡΧΕΙΩΝ:

  • Η βάση [όνομα] λαμβάνεται απευθείας από το αρχείο input.txt (γραμμή χρήστη)
  • Εάν γράψετε στο αρχείο εισόδου "Marriage Registry 1920", τα αρχεία θα είναι:
    • Ληξιαρχείο Γάμων 1920_canvas_1.jpg
    • Ληξιαρχείο Γάμων 1920_genealogico.json
    • Ληξιαρχείο Γάμων 1920_tecnico.json
  • Τα επιθήματα JSON παραμένουν στο EN (_genealogical, _technical) για συμβατότητα
  • Μπορείτε να χρησιμοποιήσετε ονόματα σε οποιαδήποτε γλώσσα στο αρχείο εισόδου (IT, EN, μικτή)

3. PDF ΓΙΑ ΑΡΧΕΙΑ ΚΑΙ ΕΓΓΡΑΦΑ

──────────────────── ──────────────────── ──────────────────── ────────────────────

ΠΩΣ ΝΑ ΕΝΕΡΓΟΠΟΙΗΣΕΤΕ ΤΗ ΓΕΝΙΑ PDF

Η δημιουργία του PDF ενεργοποιείται επιλέγοντας το πλαίσιο PDF στη μάσκα επιλογής μορφής (Μενού → Ρυθμίσεις → "Επιλογή μορφών εικόνας").

Μπορείτε να συνδυάσετε το PDF με μία ή περισσότερες μορφές εικόνας (π.χ. PDF + PNG) ή να επιλέξετε μόνο PDF για να αποκτήσετε αποκλειστικά το έγγραφο χωρίς ξεχωριστά αρχεία εικόνας.

📄 ΧΑΡΑΚΤΗΡΙΣΤΙΚΑ ΤΟΥ ΔΗΜΙΟΥΡΓΗΜΕΝΟΥ PDF

  • Όνομα αρχείου: το PDF ονομάζεται απλά [nome].pdf, χωρίς πρόσθετα επιθήματα — π.χ Registro Matrimoni 1920.pdf
  • Τοποθεσία: αποθηκεύεται στον επιλεγμένο φάκελο εξόδου, στο ίδιο επίπεδο με τις εικόνες: [cartella_scelta]\[nome].pdf
  • Σειρά σελίδας: οι σελίδες είναι πάντα σε αύξουσα αριθμητική σειρά (καμβάς 1 → καμβάς 2 → … → καμβάς N), ανεξάρτητα από τη σειρά λήψης των πλακιδίων
  • Σελίδες κράτησης θέσης: εάν ένας καμβάς δεν είναι διαθέσιμος (σφάλμα δικτύου ή πόρος προσωρινά μη προσβάσιμος), μια σελίδα εισάγεται αυτόματα στη θέση της κράτησης θέσης εντοπισμένο στην επιλεγμένη γλώσσα. Η σελίδα κράτησης θέσης περιέχει:
    • Ένα τοπικό κείμενο προειδοποίησης (π.χ. "Η εικόνα δεν είναι διαθέσιμη")
    • Ο άμεσος σύνδεσμος στον αρχικό καμβά στους Προγόνους (https://antenati.cultura.gov.it/ark:/…), ώστε να μπορείτε να συμβουλευτείτε την πηγή εύκολα
    Με αυτόν τον τρόπο δημιουργείται πάντα το PDF, με όλες τις απαραίτητες πληροφορίες για την ολοκλήρωσή του σε περίπτωση μη λήψης εικόνων.
  • Αυτόματος καθαρισμός: τα προσωρινά αρχεία που χρησιμοποιούνται για τη δημιουργία του PDF διαγράφονται αυτόματα στο τέλος της διαδικασίας. Μόνο οι εικόνες στις επιλεγμένες μορφές, το τελικό PDF, οι δηλώσεις και τα μεταδεδομένα παραμένουν στο φάκελο εξόδου

🚫 Εάν δεν έχει επιλεγεί το PDF:

  • Γίνεται λήψη μόνο εικόνων στις επιλεγμένες μορφές
  • Δεν δημιουργήθηκε PDF

4. 📌 ΔΙΑΘΕΣΙΜΕΣ ΧΑΡΑΚΤΗΡΙΣΤΙΚΕΣ

Το μενού "Υπηρεσίες" περιέχει τις λειτουργικές λειτουργίες του v3: αναζήτηση με τη βοήθεια AI, προβολή εικόνων, προβολή μεταδεδομένων JSON, OCR Advanced, Μετάφραση OCR και Εξαγωγή GEDCOM.

1️⃣ ΑΝΑΖΗΤΗΣΗ ΜΕ ΒΟΗΘΗΣΗ AI ✅

Βοηθός για τον καθορισμό στρατηγικών γενεαλογικής έρευνας:

  • Μετατρέψτε τα επώνυμα, τους τόπους, τις περιόδους και τους στόχους σε ερευνητικούς δυνητικούς πελάτες
  • Προτείνει πύλες, φίλτρα και παραδείγματα ερωτημάτων για μη αυτόματο έλεγχο
  • Υποστηρίζει ιταλικά, ιταλόφωνα, μεταναστευτικά και διεθνή σενάρια
  • Επιτρέπει προσωπικές σημειώσεις, σύγκριση πολλών παρόχων και αποθήκευση αποτελεσμάτων

Κατάσταση: ✅ Διαθέσιμο - Ανατρέξτε στον Οδηγό αναζήτησης με τη βοήθεια AI

2️⃣ ΠΡΟΒΟΛΗ ΕΙΚΟΝΑΣ ✅

Ενσωματωμένο πρόγραμμα προβολής εικόνων γενεαλογίας:

  • Υποστηριζόμενες μορφές: JPG, PNG, TIFF (συμπεριλαμβανομένης πολυσέλιδης πλοήγησης TIFF προς τα εμπρός /indietro)
  • Ζουμ με τον τροχό του ποντικιού και τα ειδικά κουμπιά
  • Μετακίνηση με σύρσιμο του ποντικιού
  • Λειτουργίες "Fit to window" και "1:1 pixel".
  • Sidecar JSON δίπλα δίπλα με εικόνα (EXIF και τεχνικά μεταδεδομένα)

Κατάσταση: ✅ Διαθέσιμο - Δείτε τον Οδηγό προβολής εικόνων

3️⃣ ΠΡΟΒΟΛΗ ΜΕΤΑΔΕΔΟΜΕΝΩΝ JSON ✅

Πρόγραμμα προβολής δέντρου για δομημένα μεταδεδομένα:

  • Άμεσο άνοιγμα αρχείων _genealogico.json ε _tecnico.json
  • Επεκτάσιμη προβολή δέντρου
  • Ενότητες: γενεαλογικά δεδομένα, τεχνικά μεταδεδομένα, EXIF από εικόνες
  • Αντιστοιχισμένη προεπισκόπηση εικόνας δίπλα-δίπλα στον πίνακα μεταδεδομένων

Κατάσταση: ✅ Διαθέσιμο - Δείτε τον Οδηγό προβολής μεταδεδομένων JSON

4️⃣ OCR ADVANCED ✅

Προηγμένη θεραπεία OCR μέσω LLM Vision:

  • Εξαγωγή κειμένου από αρχαία έγγραφα (συμπεριλαμβανομένων χειρογράφων στα ιταλικά και στα λατινικά του 19ου αιώνα)
  • Διατήρηση της δομής της διάταξης και των αναφορών (TEI XML)
  • Αυτόματη αναγνώριση και καθαρισμός δομημένων δεδομένων (π.χ. πίνακες, ρόλοι)
  • Εξαγωγή οντοτήτων (ονόματα, ημερομηνίες, σχέσεις) σε πλοηγήσιμη μορφή JSON

Κατάσταση: ✅ Διαθέσιμο - Δείτε τον Οδηγό για προχωρημένους OCR

5️⃣ ΜΕΤΑΦΡΑΣΗ OCR ✅

Μετάφραση με βάση τα συμφραζόμενα εξαγόμενων ή μεταγραφόμενων κειμένων:

  • Μετάφραση κειμένων OCR, μη αυτόματες μεταγραφές και αρχεία TXT
  • Χρήση τύπων εγγράφων, γλωσσαρίου και περιβάλλοντος
  • Ρυθμιζόμενος πάροχος AI, προαιρετικό πρότυπο και Key Vault
  • Επεξεργάσιμη έξοδος TXT ή DOCX

Κατάσταση: ✅ Διαθέσιμο - Δείτε τον Οδηγό μετάφρασης OCR

6️⃣ ΕΞΑΓΩΓΗ GEDCOM ✅

Υποβοηθούμενη γενεαλογική ανάλυση και εξαγωγή GEDCOM:

  • Καθολική είσοδος με τη μέθοδο Auto-Discovery, Vision AI ή Refinery LLM
  • Δυνατότητα αύξησης μιας υπάρχουσας βάσης GEDCOM ή CSV
  • Παλαιογραφικές σημειώσεις και τυπολογίες τεκμηρίωσης για την καθοδήγηση της εξαγωγής
  • Δημιουργία αρχείου genealogia_*.ged να ελεγχθεί πριν από τη χρήση

Κατάσταση: ✅ Διαθέσιμο - Δείτε τον Οδηγό GEDCOM

5. ΦΑΚΕΛΟΙ ΚΑΙ ΑΡΧΕΙΑ ΕΞΟΔΟΥ

──────────────────── ──────────────────── ──────────────────── ────────────────────

📂 ΔΟΜΗ ΕΞΟΔΟΥ

Όταν επεξεργάζεστε μια εγγραφή IIIF, το ATK-Pro αποθηκεύει τα αρχεία στο φάκελο που επιλέξατε στο ΒΗΜΑ 2 (Επιλογή φακέλου εξόδου).

ΔΟΜΗ ΟΡΓΑΝΩΜΕΝΗ ΑΠΟ ΚΑΤΑΓΡΑΦΗ:

[cartella_output]/
├─ manifest_[ID]_[nome].json         ← Manifest IIIF originale
├─ [nome]_canvas_1.jpg/.png/.tif     ← Immagini ricostruite (una per pagina)
├─ [nome]_canvas_2.jpg/.png/.tif
├─ [nome]_canvas_N.jpg/.png/.tif     ← (N = numero totale pagine/canvas)
├─ [nome].json                       ← Sidecar JSON per ogni immagine (EXIF)
├─ [nome].pdf                        ← PDF completo (solo se richiesto)
└─ [nome]/                           ← Sottocartella SOLO per metadati
   ├─ [nome]_genealogico.json        ← Metadati genealogici
   └─ [nome]_tecnico.json            ← Metadati tecnici

ΠΟΛΥ ΕΓΓΡΑΦΗ ΣΤΟΝ ΙΔΙΟ ΦΑΚΕΛΟ:

Εάν επεξεργαστείτε 3 εγγραφές στον ίδιο φάκελο, η δομή γίνεται:

[cartella_output]/
├─ manifest_[ID1]_Registro1.json
├─ Registro1_canvas_1.jpg
├─ Registro1_canvas_2.jpg
├─ Registro1.json (sidecar)
├─ Registro1.pdf
├─ Registro1/
│  ├─ Registro1_genealogico.json
│  └─ Registro1_tecnico.json
├─ manifest_[ID2]_Documento2.json
├─ Documento2_canvas_1.jpg
├─ Documento2.json (sidecar)
├─ Documento2.pdf
├─ Documento2/
│  ├─ Documento2_genealogico.json
│  └─ Documento2_tecnico.json
├─ manifest_[ID3]_Registro3.json
├─ Registro3_canvas_1.jpg
├─ Registro3_canvas_2.jpg
├─ Registro3.json (sidecar)
├─ Registro3.pdf
└─ Registro3/
    ├─ Registro3_genealogico.json
    └─ Registro3_tecnico.json

📌 ΣΗΜΕΙΩΣΕΙΣ ΓΙΑ ΤΗ ΔΟΜΗ:

  • Manifest IIIF, Εικόνες, PDF, Sidecar JSON: στο κύριο επίπεδο
  • ΜΟΝΟ τεχνικά και γενεαλογικά μεταδεδομένα: σε [όνομα]/ υποφακέλους (ένας ανά εγγραφή)
  • Προσωρινοί φάκελοι (tiles_canvas_X/) και τα προσωρινά αρχεία που χρησιμοποιούνται για τη δημιουργία του PDF διαγράφονται αυτόματα στο τέλος της επεξεργασίας: κανένα ενδιάμεσο αρχείο εργασίας δεν παραμένει στο φάκελο εξόδου
  • Αυτή η οργάνωση σάς επιτρέπει να διαχειρίζεστε πολλές εγγραφές στον ίδιο φάκελο χωρίς σύγχυση αρχείων

📋 ΣΥΜΒΑΣΗ ΟΝΟΜΑΣΙΑΣ:

  • Μανιφέστο: manifest_[ID]_[όνομα].json
  • Εικόνες: [name]_canvas_1, [name]_canvas_2, ... [name]_canvas_N
  • JSON μεταδεδομένα: [όνομα]_genealogico.json, [όνομα]_tecnico.json
  • Εικόνες JSON: [όνομα].json (για κάθε καμβά)
  • PDF: [όνομα].pdf
