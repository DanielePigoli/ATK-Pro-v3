1. ΕΓΚΑΤΑΣΤΑΣΗ ΚΑΙ ΑΠΑΙΤΗΣΕΙΣ

──────────────────── ──────────────────── ──────────────────── ────────────────────

ΛΕΙΤΟΥΡΓΙΚΟ ΣΥΣΤΗΜΑ

  • Windows: Windows 10 ή μεταγενέστερο (64-bit) — Επαγγελματικό, Οικιακό, Διακομιστής
  • Linux: Ubuntu 20.04+ ή συμβατές διανομές (πακέτο .deb ή αρχείο .tar.gz)
  • macOS: macOS 11 Big Sur ή μεταγενέστερο — διανομή .dmg (δοκιμή σε πραγματικό υλικό σε εξέλιξη)
  • Απαιτείται 64-bit σε όλες τις πλατφόρμες
  • Τουλάχιστον 2 GB διαθέσιμης μνήμης RAM (4 GB συνιστώνται για μαζική επεξεργασία)
  • 1 GB ελεύθερου χώρου στο δίσκο

ΕΓΚΑΤΑΣΤΑΣΗ

🪟 Windows

  1. Λήψη ATK-Pro-Setup-vx.x.x.exe από την επίσημη σελίδα έκδοσης
  2. Κάντε διπλό κλικ στο αρχείο εγκατάστασης
  3. Επιλέξτε "Εκτέλεση με δικαιώματα διαχειριστή" εάν σας ζητηθεί
  4. Ακολουθήστε τον οδηγό (Επόμενο → Επόμενο → Εγκατάσταση)
  5. Κατά την εγκατάσταση θα σας ζητηθεί να επιλέξετε τη γλώσσα (20 διαθέσιμα)
  6. Όταν τελειώσετε, επιλέξτε "Εκκίνηση ATK-Pro" για να ξεκινήσει το πρόγραμμα
  7. Αποδεχτείτε τυχόν προειδοποιήσεις από το Windows Firewall/Defender

🐧 Linux

  1. Λήψη ATK-Pro-vx.x.x.deb (Debian/Ubuntu) ή .tar.gz από τη σελίδα Έκδοση
  2. Πακέτο .deb: sudo dpkg -i ATK-Pro-vx.x.x.deb ή κάντε διπλό κλικ στο Nautilus/Files
  3. Αρχείο .tar.gz: εξάγετε και τρέξτε ./ATK-Pro από τον εξαγόμενο φάκελο
  4. Η γλώσσα επιλέγεται κατά την πρώτη εκκίνηση και αποθηκεύεται στο αρχείο ρυθμίσεων χρήστη

🍎 macOS

  1. Λήψη ATK-Pro-vx.x.x.dmg από τη σελίδα Έκδοση
  2. Ανοίξτε το αρχείο .dmg και σύρετε το ATK-Pro στο φάκελο Εφαρμογές σας
  3. Κατά την πρώτη εκκίνηση: δεξί κλικ → Άνοιγμα (απαραίτητο για μη συμβολαιογραφικές εφαρμογές)
  4. Η γλώσσα επιλέγεται κατά την πρώτη εκκίνηση και αποθηκεύεται στο αρχείο ρυθμίσεων χρήστη

ΠΡΟΕΠΙΛΟΓΗ ΘΕΣΕΙΣ

🪟 Windows

  • Πρόγραμμα: C:\Program Files\ATK-Pro\
  • Έξοδος χρήστη: C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • Είσοδοι (προαιρετικά): C:\Users\[TuoNome]\Documents\ATK-Pro\input\

🐧 Linux

  • Πρόγραμμα: /opt/ATK-Pro/ (deb) ή φάκελος εξαγωγής (.tar.gz)
  • Έξοδος χρήστη: ~/Documents/ATK-Pro/output/
  • Είσοδοι (προαιρετικά): ~/Documents/ATK-Pro/input/

🍎 macOS

  • Πρόγραμμα: /Applications/ATK-Pro.app
  • Έξοδος χρήστη: ~/Documents/ATK-Pro/output/
  • Είσοδοι (προαιρετικά): ~/Documents/ATK-Pro/input/

ΑΠΑΙΤΗΣΕΙΣ ΔΙΚΤΥΟΥ

  • Σταθερή σύνδεση στο Διαδίκτυο (απαιτείται για πρόσβαση σε IIIF Manifests)
  • Τείχος προστασίας: Επιτρέπονται οι εξερχόμενες συνδέσεις HTTPS (θύρα 443)
  • Enterprise Proxy: Το ATK-Pro δεν διαθέτει εσωτερικό μενού για διαπιστευτήρια διακομιστή μεσολάβησης. Διαμορφώστε τον διακομιστή μεσολάβησης στο λειτουργικό σας σύστημα ή στο περιβάλλον δικτύου και ελέγξτε με τον διαχειριστή σας ότι επιτρέπονται οι συνδέσεις HTTPS σε πύλες.

2. ΠΡΩΤΗ ΕΚΚΙΝΗΣΗ ΚΑΙ ΔΙΑΜΟΡΦΩΣΗ

ΕΠΙΛΟΓΗ ΓΛΩΣΣΑΣ

Οι διαθέσιμες γλώσσες είναι:

  • ITΙταλικά (Ιταλικά): Απαραίτητο για κατοίκους και νέους ομογενείς.
  • ENΑγγλικά (Αγγλικά): Γλώσσα γεφυρών για τις ΗΠΑ, τον Καναδά, την Αυστραλία και το Ηνωμένο Βασίλειο.
  • ESEspañol (Ισπανικά): Καλύπτει όλες τις ισπανόφωνες χώρες της Αμερικής, τις Φιλιππίνες και την Ισπανία (προτιμώμενος προορισμός για νέους Ιταλούς το 2024-2025).
  • FRFrançais (Γαλλικά): Για τις ιστορικές και τεράστιες κοινότητες στη Γαλλία και το Βέλγιο.
  • DEDeutsch (Γερμανικά): Για τη Γερμανία (σχεδόν 900.000 Ιταλοί κάτοικοι) και την Ελβετία.
  • PTPortuguês (Πορτογαλικά): Απαραίτητο για τη Βραζιλία (λεκάνη άνω των 30 εκατομμυρίων απογόνων).
  • RUРусский (Ρωσικά): Για να καλύψει κοινότητες και απογόνους σε πρώην σοβιετικές δημοκρατίες και στα Βαλκάνια.
  • AR العربية (Αραβικά, RTL): Για κοινότητες στη Βόρεια Αφρική (Αίγυπτος, Τυνησία, Μαρόκο) και για απογόνους στις χώρες του Κόλπου.
  • NLNederlands (Ολλανδικά): Fundamental για την Ολλανδία, ένας ταχέως αναπτυσσόμενος κόμβος για Ιταλούς αποφοίτους το 2025.
  • ΑΥΤΟΣ עברית (Εβραϊκά, RTL): Για τη σημαντική και δραστήρια κοινότητα των Ιταλών στο Ισραήλ.
  • JA日本語 (Ιαπωνικά): Για την κοινότητα των επαγγελματιών και των Ιταλών που κατοικούν στην Ιαπωνία.
  • SVSvenska (Σουηδικά): Η Σουηδία είναι ο κορυφαίος Σκανδιναβικός προορισμός για τους Ιταλούς το 2025.
  • ZH中文 (Κινέζικα): Για κατοίκους και επιχειρηματίες στην Κίνα.
  • RORomână (Ρουμανικά): Για τη μεγάλη κοινότητα Ιταλών επιχειρηματιών και κατοίκων στη Ρουμανία.
  • ΕΛΕλληνικά (Ελληνικά): Για ιστορικούς δεσμούς και μόνιμους κατοίκους ελληνικών νησιών και πόλεων.
  • PLPolski (Πολωνικά): Για Ιταλούς που διαμένουν στην Πολωνία (υλικοτεχνικός και βιομηχανικός κόμβος).
  • DADansk (Δανικά): Για Ιταλούς ερευνητές και δημιουργικούς στη Δανία.
  • ΟΧΙNorsk (Νορβηγικά): Για την κοινότητα πετρελαίου & φυσικού αερίου και τεχνολογίας.
  • TRTürkçe (τουρκικά): Για την ιστορική «λεβαντίνικη» κοινότητα και τους κατοίκους της Κωνσταντινούπολης.
  • VITiếng Việt (Βιετναμέζικα): Για την αναπτυσσόμενη επιχειρηματική κοινότητα στη Νοτιοανατολική Ασία.

με το οποίο, με βάση τα διαθέσιμα στοιχεία στο τέλος του 2025, υπολογίζεται ότι μπορούμε να καλύψουμε περίπου το 98% των απογόνων Ιταλών και ιταλόφωνων ή ιταλόφωνων κοινοτήτων διάσπαρτων σε όλο τον κόσμο.

  • Ελάτε Windows: η γλώσσα επιλέγεται κατά την εγκατάσταση και αποθηκεύεται στο μητρώο Windows
  • Ελάτε Linux/macOS: Η γλώσσα επιλέγεται κατά την πρώτη εκκίνηση και αποθηκεύεται στο αρχείο διαμόρφωσης χρήστη
  • Και στις δύο περιπτώσεις, φορτώνεται αυτόματα σε κάθε εκκίνηση
  • Μπορεί να αλλάξει ανά πάσα στιγμή μέσω Μενού → Ρυθμίσεις → Αλλαγή γλώσσας
  • Το πρόγραμμα απαιτεί επανεκκίνηση για να εφαρμόσει τη νέα επιλεγμένη γλώσσα

📂 ΔΙΑΜΟΡΦΩΣΗ ΦΑΚΕΛΟΥ

Κατά την πρώτη εκτέλεση, το πρόγραμμα δημιουργεί αυτόματα τους ακόλουθους φακέλους:

  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\doc\ (προεπιλεγμένα έγγραφα)
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\reg\ (προεπιλεγμένα μητρώα)
  • Linux/macOS: παρόμοια παρακάτω ~/Documents/ATK-Pro/output/
  • Φάκελος input\ ανάλογο (προαιρετικό, για αρχείο εισόδου)

Δημιουργούνται προσωρινοί φάκελοι για τα ληφθέντα πλακίδια κατά την επεξεργασία (tiles_canvas_X/) και, εάν ζητηθεί PDF, προσωρινά αρχεία για τη δημιουργία του.

Όλοι οι φάκελοι και τα προσωρινά αρχεία διαγράφονται αυτόματα μετά την ολοκλήρωση της επεξεργασίας.

Απομένουν μόνο τα τελικά επεξεργασμένα αρχεία (εικόνες στις επιλεγμένες μορφές, PDF, δήλωση και μεταδεδομένα).

Για να αλλάξετε τους φακέλους εξόδου, χρησιμοποιήστε το Μενού → Ρυθμίσεις → "Επιλογή φακέλων εξόδου". Οι επιλογές σας αποθηκεύονται και επαναφέρονται αυτόματα στην επόμενη συνεδρία.

⚙️ ΠΡΟΦΙΛ ΠΟΡΟΥ

Η εντολή Ρυθμίσεις → Προφίλ πόρων προσαρμόζει τον παραλληλισμό που χρησιμοποιείται κατά τη λήψη, την ανακατασκευή εικόνας και τη δημιουργία PDF:

  • Ελαφρύ: περιορίζει τις ταυτόχρονες διεργασίες και τις αιχμές της μνήμης. κατάλληλο για λιγότερο ισχυρούς υπολογιστές ή πολύ μεγάλες διαδικασίες.
  • Ισορροπημένο: προκαθορισμένος συμβιβασμός μεταξύ ταχύτητας και σταθερότητας, κατάλληλος για τις περισσότερες περιπτώσεις.
  • Γρήγορα: Χρησιμοποιήστε περισσότερους πόρους για να μειώσετε τους χρόνους. επιλέξτε το μόνο σε υπολογιστές αρκετά υψηλής απόδοσης.

Το προφίλ δεν αλλάζει την ποιότητα, τα δικαιώματα ή την ποσότητα των εγγράφων που αποκτήθηκαν. Τα όρια προληπτικής εποπτείας ειδικά για την πύλη εξακολουθούν να έχουν προτεραιότητα.
