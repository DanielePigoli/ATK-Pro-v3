1. 安装和要求

────────────────────────────────────────────────────────────────────────────────

操作系统

  • Windows: Windows 10或以后(64位)——专业,家,服务器
  • Linux: Ubuntu 20.04 + 或兼容分布(.deb package 或.tar.gz 存档)
  • macOS: macOS 11 Big Sur 或后期——dmg 发行(真正的硬件正在进行中)
  • 所有平台的64位强制值
  • 至少有2GB的内存可用(4GB建议批次处理)
  • 1GB 自由磁盘空间

安装

🪟 Windows

  1. 下载 ATK-Pro-Setup-vx.x.x.exe 从官方发布页面
  2. 双击安装者文件
  3. 如果需要, 请选择“ 有管理员权限的执行 ”
  4. 跟随向导( 下一位 ) —— 下一位 —— 安装)
  5. 安装时将要求选择语言( 20种可用语言)
  6. 结尾处请检查"Start ATK-Pro"启动程序
  7. 接受 Windows 防火墙/防御器提示

🐧 Linux

  1. 下载 ATK-Pro-vx.x.x.deb (德比安/乌邦图)或 .tar.gz 从发行页面
  2. .deb 软件包 : sudo dpkg -i ATK-Pro-vx.x.x.deb 或双击 Nautilus/ Files
  3. 存档 .tar.gz: 外部开始 ./ATK-Pro 从已提取文件夹中
  4. 语言在第一次启动时选中并保存在用户配置文件中

🍎 macOS

  1. 下载 ATK-Pro-vx.x.x.dmg 从发行页面
  2. 打开 .dmg 文件并将 ATK-Pro 拖到“应用程序”文件夹
  3. 初开始: 右键点击 → 打开( 未公证的应用程序需要)
  4. 语言在第一次启动时选中并保存在用户配置文件中

默认位置

🪟 Windows

  • 程序 : C:\Program Files\ATK-Pro\
  • 用户输出 : C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • 输入( 可选) : C:\Users\[TuoNome]\Documents\ATK-Pro\input\

🐧 Linux

  • 程序 : /opt/ATK-Pro/ (deb)或提取文件夹(.tar.gz)
  • 用户输出 : ~/Documents/ATK-Pro/output/
  • 输入( 可选) : ~/Documents/ATK-Pro/input/

🍎 macOS

  • 程序 : /Applications/ATK-Pro.app
  • 用户输出 : ~/Documents/ATK-Pro/output/
  • 输入( 可选) : ~/Documents/ATK-Pro/input/

网络要求

  • 稳定的互联网连接（访问 IIIF 清单所必需）
  • 防火墙:允许输出HTTPS连接(第443端口)
  • 公司代理:ATK-Pro没有代理证书的内部菜单. 在操作系统或网络环境中配置代理,并与管理员核实允许HTTPS连接门户.

第一个开始

  • HE (希伯来语,RTL): 为在以色列的意大利人的重要而活跃的社区.

  • SV斯文斯卡 (瑞典语):瑞典是2025年意大利人的主要斯堪的纳维亚目的地.

根据2025年底的现有数据,估计它能够覆盖世界各地意大利人和意大利人或意大利人后裔的98%。

  • 上来 Windows: 语言在安装器中选择,并存储在 Windows 注册中
  • 上来 Linux/macOS: 语言在第一次启动时被选中并保存在用户配置文件中
  • 在两种情况下,每次启动时自动加载
  • 可随时通过菜单 设置 更改语言
  • 程序需要重启以应用所选新语言

配置文件夹

当您第一次运行时, 程序会自动创建以下文件夹 :

  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\doc\ (违约文件)
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\reg\ (违约登记册)
  • Linux/macOS: 与下文类似 ~/Documents/ATK-Pro/output/
  • 文件夹 input\ 模拟( 可选, 文件输入)

处理临时文件夹时,可下载瓷砖(tiles_canvas_X/),如果需要的话,PDF,为其生成的临时文件.

所有临时文件夹和文件都会在处理结束时自动删除.

仅保留已处理的最后文件(以选定格式、PDF、海报和元数据为图像)。

要更改输出文件夹,请使用菜单 → 设置 → “ 选择输出文件夹 ” 。 选择被存储并自动恢复到下一个会话.

⚙️ 资源配置

命令 设置 ~ 资源配置 规范下载、图像重建和 PDF 生成过程中使用的并行性 :

  • 轻量级 : 限制当代进程和内存峰值; 显示为不太强大的计算机或很长的处理。
  • 余额: 在速度和稳定性之间默认妥协,适合大多数情况。
  • 快速 : 使用更多的资源来减少时间; 只在计算机上选择足够好。

简介不改变所取得文件的质量、权利或数量。 门户网站的具体审慎限制仍然具有优先地位。

3. 主要接口

────────────────────────────────────────────────────────────────────────────────

窗口布局

Antenati Toolkit Pro的主窗口结构简单直观.

: 测试的传说 :

  • [🔲] 程序图标（Antenati Toolkit Pro 标志）
  • "ATK-Pro" 窗口标题
  • [ ] 减少到图标( 最小化窗口)
  • D] 扩展/ Collassa(最大或恢复窗口)
  • [✕] 关闭（通过支持横幅退出程序）

拉丁格言“Qui ante nos venerunt,以纪念我们的活力”,回顾了根基和集体记忆的重要性。

菜单栏

在窗顶,头下面:

[文件输入] [产出] [服务] [文件] [定

每个菜单都包含特定的按钮和选项(见下一节).

可选菜单

1. 文件输入

管理 IIIF 记录的加载 :

├─ Esempio input
│  └─ Visualizza il file di esempio (mostra formato coppie: modalità D/R + URL)
├─ Apri input
│  └─ Seleziona un file .txt con i tuoi record IIIF
│     (Deve contenere coppie: modalità D/R su riga 1, URL su riga 2)
└─ Modifica input
   └─ Modifica il file input attualmente caricato
      (Aggiungi/rimuovi record, cambia URL, salva modifiche)

2. 产出

管理处理和输出 :

├─ Elabora
│  └─ Avvia il download, la ricostruzione e il salvataggio delle immagini
│     (Mostra finestra di progresso in tempo reale)
├─ Apri cartella output
│  └─ Apre in Esplora Risorse la cartella con i file elaborati
└─ Visualizza elaborazioni precedenti
   └─ Lista dei record già elaborati

3. 服务

综合服务清单:

├─ Ricerca assistita AI
│  └─ Suggerisce portali, piste di ricerca e query genealogiche da verificare
├─ Visualizzazione Immagini
│  └─ Viewer immagini scaricate e/o PDF generati
├─ Visualizzazione Metadati JSON
│  └─ JSON originali e metadati (genealogici, tecnici, EXIF)
├─ OCR Avanzato
│  └─ Testi manoscritti ottocenteschi, latino ecclesiastico, tardo-medievali
├─ Traduzione OCR
│  └─ Traduzione automatica testi estratti nelle lingue selezionate
└─ Esportazione GEDCOM
   └─ GEDCOM, Gramps, Family Tree Maker, Ancestry, MyHeritage, WikiTree, etc.

4. 文件

获取资源和文件:

├─ Disclaimer - Clausole legali e termini d'uso
├─ Presentazione autore - Background dell'autore del progetto
├─ Presentazione progetto - Storia, motivazioni, roadmap di ATK-Pro
├─ Guida - Indice principale della guida modulare
└─ Informazioni - Versione, copyright, email di contatto

5. 设置

程序的一般配置 :

├─ Cambia lingua
│  └─ Seleziona la lingua dell'interfaccia (richiede riavvio)
├─ Seleziona formati immagine
│  └─ Scegli tra PNG, JPG, TIFF e PDF (almeno 1 obbligatorio)
│     PDF può essere selezionato da solo o insieme ai formati immagine
│     La scelta viene memorizzata e pre-selezionata automaticamente alla sessione successiva
├─ Seleziona cartelle output
│  └─ Apre prima la scelta della modalità cartelle, poi le finestre di selezione:
│     • Cartella unica per tutti    → una sola cartella per documenti e registri
│     • Cartelle separate doc/reg   → una cartella per tutti i doc, una per tutti i reg
│     • Cartella per ogni record    → una cartella distinta per ciascun record
│     La modalità e le cartelle vengono memorizzate e ripristinate alla sessione successiva
├─ Esporta configurazione
│  └─ Salva le impostazioni attuali in un file
├─ Importa configurazione
│  └─ Carica un file di impostazioni precedentemente salvato (ripristina tutte le preferenze e percorsi)
├─ Verifica aggiornamenti
│  └─ Controlla la disponibilità di nuove versioni del programma
└─ Chiudi
    └─ Termina il programma (mostra banner di supporto PayPal.me)
