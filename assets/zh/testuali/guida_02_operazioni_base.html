* 输入结构和支助门户

ATK-Pro 接受采用成对格式的输入文件：对于每条待处理记录，请提供“模式 + URL”。

支持的门户 : 复制并粘贴该页面的公众URL,查看器,海报或兼容PDF. ATK-Pro承认该门户并应用其技术和谨慎模式.

支助 表示经核实的技术兼容性,而不是任意允许下载。 资源必须向公众开放,用户必须尊重个人门户的权利、许可证、使用条件和限制。 ATK-Pro不绕过登录器,附属访问器,付费墙或标记 nodownload.

处理完成后（点击“菜单 → 输出 → 处理”时）：已处理的文件会添加到顶层目录：

 ├─ [nome]_canvas_1.jpg/.png/.tif     ← Immagini ricostruite dai tile IIIF (una per pagina)
 ├─ [nome]_canvas_2.jpg/.png/.tif       (formato dipende da quello selezionato)
 ├─ [nome]_canvas_N.jpg/.png/.tif       (N = numero totale di pagine/canvas)

 └─ [nome].pdf                         ← PDF completo (vedi spiegazione sotto)

  • Express IIIF: 输出文件夹的主要级别

2. 图像的处理和下载

────────────────────────────────────────────────────────────────────────────────

🎯 处理流程

处理工作流程包括三个步骤:

步骤1:选择图像格式

─────────────────────────────────────

1. 上传输入文件(文件输入 打开输入):格式窗口自动打开

2. 或者:单击菜单 → "设置" → "选择图像格式"

3. 打开包含3个选项的对话框:

PNG 时间轴 − 无损失格式(无损失),质量更好,文件更大

JPG 时间轴 ——压缩格式(损耗),良好折中质量/差价

TIFF 时间轴 — 存档格式,最高质量,非常大的文件

PDF文档

PDF 时间轴 − 生成一个完整的PDF,除了选定的图像格式(或者在没有选择图像格式的情况下作为单一的输出)之外,还有登记册或文档的所有页面。

4. 选择至少一个图像或PDF格式(您可以选择多个)

5. 点击“确认”

✅ 所选格式被存储 ,并在下一个程序打开时自动选择。

: 小费 :

  • 用于预览/协商:JPG(快速打开,空间较少)
  • 保守档案:PNG(无损失,空间妥协)或TIFF(最大质量)
  • 两者:既选择PNG,又选择PNG.
  • 对于 PDF : 选择 PDF 和一个或多个图像格式, 或者只选择 PDF 创建单独的 PDF 文档, 没有图像文件 。

步骤2: 选择输出文件夹

──────────────────────────────────────

1. 文件夹窗口在选择格式后自动打开(当你上传输入文件时)

4. 在选择模式后, 选择所需的文件夹 (1、2 或 N 对话框)

5. 结尾处显示选定文件夹的摘要

如果新输入文件的文档/登记文件数量与保存的文件夹不同,则会显示一个提醒,并重设选择以请求新文件夹.

🛡️ 预防性路线控制 : 在创建文件夹或文件之前, ATK-Pro 验证预期名称和路径。 Windows不兼容的名称和过长的片段屏蔽了唯一受影响的记录;兼容性提示在最后摘要中显示.

共性行为 :

  • ✅ 在格式掩码中选择的 PDF : PDF在下载结束时自动生成;不需要额外确认
  • ❌ 未选择 PDF : 只有选定格式的图像,没有 PDF

PDF的特性产生:

  • 文件名 : [nome].pdf,不添加后缀(如: Registro Matrimoni 1920.pdf)
  • 保存在选中的输出文件夹中, 级别与图像相同

  • ❌ 不要断开互联网连接（否则下载会停止）

3. 登记和证件的PDF

────────────────────────────────────────────────────────────────────────────────

如何激活生成 PDF

PDF的生成通过选择框激活 PDF 在格式选择掩码(Menu = 设置 = 选择图像大小)中。

您可以将 PDF 与一个或多个图像格式(如 PDF + PNG)合并,或者只选择 PDF ,只获取文档而无需单独的图像文件.

📄 生成的 PDF 特性

  • 文件名 : PDF 被简单地称为 [nome].pdf,不添加后缀——例如: Registro Matrimoni 1920.pdf
  • 地点 : 保存在选中的输出文件夹中, 级别与图像相同 : [cartella_scelta]\[nome].pdf
  • 页面顺序 : 页面总是在数字顺序上不断增长(canvas 1 → 画布 2 → 画布 N),无论瓷砖的下载顺序如何
  • 页面占位符 : 如果一个画布无法使用(网络错误或暂时没有资源),则自动插入一个页面的位置 占位符 位于选定的语言中。 占位符页面包含:
    • 一个本地化的警告文本( 例如“ 图像不可用 ” )
    • 直接链接到Antenati上的原始画布(https://antenati.cultura.gov.it/ark:/…),这样你就可以轻松地查阅来源
    以这种方式,PDF总是生成的,在被卸载的图像中,有完成它所需的所有信息.
  • 自动清理 : 用于 pdf 生成的临时文件在进程结束时自动删除。 输出文件夹中仅保留所选格式、PDF、海报和元数据中的图像

如果未选中 PDF :

  • 只以选定格式下载图像
  • 没有生成 PDF

  • 用可航行的JSON格式提取实体(名称、日期、报告)

状态 : * 备有 查看高级 OCR 指南

5. 文件夹和输出文件

产出结构

处理 IIIF 记录时，ATK-Pro 会将文件保存到步骤 2 所选的文件夹（选择输出文件夹）。

记录结构:

[cartella_output]/
├─ manifest_[ID]_[nome].json         ← Manifest IIIF originale
├─ [nome]_canvas_1.jpg/.png/.tif     ← Immagini ricostruite (una per pagina)
├─ [nome]_canvas_2.jpg/.png/.tif
├─ [nome]_canvas_N.jpg/.png/.tif     ← (N = numero totale pagine/canvas)
├─ [nome].json                       ← Sidecar JSON per ogni immagine (EXIF)
├─ [nome].pdf                        ← PDF completo (solo se richiesto)
└─ [nome]/                           ← Sottocartella SOLO per metadati
   ├─ [nome]_genealogico.json        ← Metadati genealogici
   └─ [nome]_tecnico.json            ← Metadati tecnici

在同一文件夹中的多记录 :

如果您在同一文件夹中处理3个记录,则结构变为:

[cartella_output]/
├─ manifest_[ID1]_Registro1.json
├─ Registro1_canvas_1.jpg
├─ Registro1_canvas_2.jpg
├─ Registro1.json (sidecar)
├─ Registro1.pdf
├─ Registro1/
│  ├─ Registro1_genealogico.json
│  └─ Registro1_tecnico.json
├─ manifest_[ID2]_Documento2.json
├─ Documento2_canvas_1.jpg
├─ Documento2.json (sidecar)
├─ Documento2.pdf
├─ Documento2/
│  ├─ Documento2_genealogico.json
│  └─ Documento2_tecnico.json
├─ manifest_[ID3]_Registro3.json
├─ Registro3_canvas_1.jpg
├─ Registro3_canvas_2.jpg
├─ Registro3.json (sidecar)
├─ Registro3.pdf
└─ Registro3/
    ├─ Registro3_genealogico.json
    └─ Registro3_tecnico.json

: 结构注释:

  • IIIF 清单、图像、PDF、Sidecar JSON：位于顶层目录
  • 仅技术和分族元数据:分文件夹[名称]/(每个记录一个)
  • 临时文件夹( E)tiles_canvas_X/)和用于 PDF 生成的临时文件在处理结束时自动删除:输出文件夹中没有保留中间工作文件
  • 此组织允许您在同一文件夹中管理多个记录而不混淆文件

  • 清单：manifest_[ID]_[nome].json
  • 图像: [名称]画布 1, [名称]画布 2,. [名称]画布 N
  • JSON元数据:_tecnico.json,_tecnico.json
  • JSON影像:[名]. json(每张帆布)
  • PDF：[nome].pdf
