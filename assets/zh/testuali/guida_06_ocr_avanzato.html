全景概览

模块 高级OCR（外交转录） 通过多模式模式,专用的PDF模式和HTR服务,从图像和文档PDF中提取文本. 它专门为历史文献设计:手稿,公证行为,教区记录,十九世纪意大利语,拉丁语或方言的档案信件.

与传统的OCR引擎(Tesseract等)不同,模块可以在文档上下文中解释拼写,并识别反复出现的缩写和公式. TEI-P5输出代表了转录的行,并在识别时分页,扩展和不可读步骤;它不完全复制原始的图形布局.

从菜单打开 服务 OCR 高级 主要应用程序。

界面-分步骤指南

dei 步骤 1 — 文件选择

单击 “选择文件(图像/ PDF) 打开选择器。 在持有时可以同时选择多个文件 Ctrl 或 Shift.

接受格式:

  • 图像: .jpg, .jpeg, .png, .tiff, .tif
  • PDF: PDF 任何文件(带或原生)

所选文件的数目在标签旁边显示。 每个文件分别处理,生成其输出文件.

🤖 步骤 2 — 选择 AI 提供商和 API 密钥

在下拉菜单中选择提供者 “选择IA提供者”:

提供商服务类型全权证书操作说明
双子座,OpenAI,克劳德远程服务API 提供者密钥模式和可用性取决于供应商的账户和当前条件。
米斯特拉尔、格罗克、xAI兼容远程终点API 提供者密钥选择一个可以处理图像的模板;并非所有文本模型都支持视觉OCR.
深层搜索当前配置中仅远程端点文本API 提供者密钥在配置一个端点和图像兼容模型之前,它不适合视觉OCR.
拥抱脸远程 API 推论托肯·胡金发兼容性和结果取决于所配置的模式.
转写远程 HTR 服务email:password 或 扣号符需要账户和至少一个收藏。
Ollama当地服务无远程 API 密钥需要活动 Ollama 和当地安装兼容的视觉模型.

营地 “重叠模式(可选)” 允许替换默认模式。 只有在知道模型的精确标识和视觉兼容性时才使用. 对于双子座这个字段没有显示 。

您可以在指定字段插入证书或打开 保险箱。IA 密钥在当地存储在 CSV 库中 api_keys.csv: 这不是操作系统的受保护密钥链. 用户配置保护、安全副本和密钥撤销仍然是你的责任。

di Step 3 — 输出格式

选择一种或多种输出格式( 默认选择的三种格式):

  • 纯文本 (.txt):平面抄写,最大兼容性. 以后处理的理想(翻译,索引编制).
  • Word文档 (.docx):文本格式化,可使用微软Word或LibreOffice编辑.
  • XML TEI (. xml) (英语).: TEI-P5格式,以表示抄写,有描述性标题,行和标记为页面识别,扩展和不可读文本.

文件保存在您启动 OCR 时将选择的目标文件夹中 。

📝 步骤 4 — 补充说明（可选但建议）

营地 “Add IA文书” 允许您自定义每个工作会话的模型行为 :

  • 表示文字的方言或语言变体
  • 重复报告的缩略语及其含义
  • 指定是否忽略邮票、边注或邮票
  • 需要具体公式保护

实例:

  • “这些月的名字出现在19世纪的西西里方言中。 别修. "
  • “不记名的差价邮票和红色铅笔笔笔记。
  • “缩写“f.”可以指儿子;“fu”和“q.”表示所提到的人已经死亡。”

指令存档 : 最常用的指令可以用按钮保存 “+” 并在以后的会议中从下拉菜单“拯救指令”中回顾。

保存的指令可以添加,重新命名或删除. 那个 文档类型 确定基本提示:除了包含的类型外,您还可以创建、编辑或删除自定义文档配置文件。

辅助校准和诊断(可选)

协助校准处理第一批选定文件的上部,显示校正结果,并使用核准的文本作为全面处理的参考. 在开始扩大批次之前核实提供者、型号、文件类型和指示是有用的。

诊断选项可节省处理方面的额外技术信息. 当您需要分析错误或提供支持元素时激活它;在共享之前检查内容,因为它可能包括文档数据或请求.

di 步骤5——参考抄录(few-shot,可选)

营地 “参考资料” 给模型一个正确的转录背景实例,用于请求中。 不添加、编辑或更新模型。

如何使用它:

  1. 手动准确地转录登记簿的第一页(或第一行)
  2. 粘贴“参考文献的翻译”栏目中转录的文字
  3. 启动 OCR:该型号将使用该笔录作为文档其余部分的指南

结果: 能够提高准确性,特别是在困难的车道,不寻常的捷径或局部方言;效果取决于提供者,模型和文件质量.
“清除文本”字段（✖）会清空转录并恢复标准模式。

🔍 步骤 6 — 交互式复核（可选）

退出 “可启用的互动审查窗口” 激活每次处理后打开的互动模式 :

  • 左侧面板: 带有缩放的原始图像( Mouse wheel) 和 pan
  • 右侧面板: 文本 OCR 摘录,可自由编辑
  • “证明和生成文件”按钮: 以所选格式保存订正文本
  • “Salta Page”按钮: 丢弃当前处理并移动到下一页

用于实时验证OCR的质量,并在确定救援前纠正错误. 对于大批次,最好是禁用交互式修订,并更正背面文本。

▶️ 步骤 7 — 启动 OCR

单击 “开始OCR”。需要输出文件的目的地文件夹。

进度栏显示进度( 当前/ 总计文件) 。 处理过程在一个单独的线程中进行: 界面在处理过程中仍然响应.

在批次期间,ATK-Pro更新了递进的抄录. *_trascrizione_parziale.txt 及其元数据。 如果处理中断,请保留这些文件,以便按照已经转录的方式恢复;在完成和修改批次之前,不考虑其最终输出.

最后,对话框将确认完成或显示任何错误。

如何获得 API 密钥

账户、钥匙、模型和费用

完全从被选中的提供者的官方控制台获得证书,并且不要在输入文件,笔录或服务请求中分享. 界面,模型,机率,地域可用性和价格可以不更新ATK-Pro而改变.

在广泛处理之前,请查看您的账户的文档和账单面板。 ATK-Pro不保证自由计划,最小概率或特定模型的持久性.

每个提示以获得最佳结果

  • 质量图像:300+IMPs的清晰图像能产生明显更好的效果. 高压缩避免JPEG(artefatti).
  • 总是使用附加指令:甚至很少有上下文行显著提高方言文档或异常拼写的准确性.
  • 作为参考的第1页:手动转录第一页,并使用“参考文献的翻译”字段;下一页的改进往往引人注目。
  • 测试批次:对于大批量(100+图像),在进行整批之前,先用Active Interactive Review对5-10文件进行测试.
  • TEI XML 时: 选择TEI XML格式,如果计划将抄本存入学术数字档案或与其他研究者分享.
  • 保存指令:每个档案系列都有自己的特色. 为所处理的每个日志或基金保存一套特定的指令。
