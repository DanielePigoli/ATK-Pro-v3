全景概览

模块 GEDCOM 导出 v3 是一个辅助的基因分析环境: 它需要选中的文本、 图像或文档, 使用配置在 ATK-Pro 的 IA 提供者并生成一个文件 .ged 带有两个支持的 CSV 文件。

从菜单打开 服务-出口GEDCOM. 公共名称仍然与GEDCOM格式相关联,但实际工作还包括分族提取,使用苍白笔记,可能增加现有基数和管理IA键.

在将结果导入一个属谱软件之前必须核实:AI可以帮助构建数据和关系,但并不能取代对源的批判读取.

🖥️ 界面

1. 方法和普遍投入

第一节允许您选择一个方法指示和要分析的文件. 选项 自动发现, 愿景IA 和 炼油 LLM 存储为首选,但在当前版本中不激活三个独立的管道: 实际处理主要取决于文件类型.

  • TXT 和 DOCX 数据:它们通过专用文本管道读取,并作为记录誊本插入提示。
  • 其他投入:它们根据可用的提取流量被传送到选定的提供者。
  • 可选择的格式: .pdf, .docx, .jpg, .jpeg, .png, .webp, .tiff, .tif, .bmp, .txt, .json 和 .csv.

2. 现有基本增长

按钮 加载基础 表示 GEDCOM 或 CSV 格式中已经存在的家族学基础 。 如果不加载任何东西,模块会创造新的工作. 当您加载一个碱基时,结果会自动保存到包含它的文件夹中,即使您先前选择了另一个目的地.

3. 古文字笔记数据库

本节将家族工作与文件类型和业务说明联系起来。 您可以选择行为类型,回忆保存的注释,创建新的注释,编辑或删除.

注释用于向模型缩写,本地公式,文档语言,亲缘关系规则,阅读疑点或提取标准解释.

4. 目标产出

选择要保存结果的文件夹 。 如果装入了已有碱基,则使用碱基文件夹. 模块生成文件 genealogia_*.ged 在GEDCOM 5.5.1 格式和两个基本名称相同的支持文件: *_REVISIONE.csv 和 *_REGISTRO_ORIGINALE.csv.

5. 汽车IA和金库钥匙

  • 提供商:在所配置的服务之间选择IA服务,如克劳德,OpenAI,双子座,米斯特拉尔,xAI,DeepSeek,Groq,HuggingFace或Ollama.
  • 覆盖模式:可选字段,以表示被选中的提供者支持的特定模型;当提供者是双子座时,它被隐藏.
  • 管理密钥库（CSV）:直接打开金库的CSV文件.
  • 开始完整提取:开始分析并生成GEDCOM.

您可以创建并删除自定义文档类型。 对于集成类型,您可以通过覆盖更改提示,但不删除该类型。

建议流量

  1. 准备可读输入:已按行为编排的抄录、图像或文件。
  2. 选择最适合材料的方法,同时铭记在当前版本中不选择单独的管道.
  3. 如果您在继续现有工作, 请加载 GEDCOM 或 CSV 基础 。
  4. 选择行为类型并添加混凝土苍白符号。
  5. 选择输出文件夹、 提供者和密钥 。
  6. 开始全面撤离
  7. 检查文件 .ged 在导入到其他程序之前生成。

ưμ㼯A

  • GEDCOM产品是一个工作基础,而不是一个明确的测试.
  • 家庭关系、日期、地点和姓名必须在原始来源上加以核实。
  • OCR错误、抄录或翻译可在家庭档案中传播。
  • 在将GEDCOM导入外部软件之前,保留一份原始文件的副本,并检查任何复制件.
  • 未经核实的使用条件,隐私和许可,不得向外部提供者发送机密文件或受到限制.
