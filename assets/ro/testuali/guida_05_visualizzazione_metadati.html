📚 Modulul 05: Vizualizare metadate JSON

⬅️ Mod.04 — Vizualizare imagini 🏠 Cuprins principal Mod.06 — OCR avansat ➡️

📌 Prezentare generală

Vizualizatorul de metadate JSON ATK-Pro este destinat afișării fișierelor JSON generate în timpul procesării documentelor. Se deschide din meniul Servicii → Vizualizare metadate JSON al aplicației.

Vizualizatorul deschide fișiere JSON valide, structurate ca obiecte, inclusiv fișiere sidecar generate de ATK-Pro. Caută automat o imagine cu același nume în același dosar (extensii: .jpg, .jpeg, .png, .tif, .tiff) și, dacă o găsește, o afișează în panoul din dreapta.

Dacă fișierul nu conține JSON valid sau nu poate fi citit, este afișat mesajul „Fișierul JSON nu poate fi citit”.

🌳️ Interfață

Fereastra este împărțită în două panouri unul lângă altul:

Panoul din stânga — tabel de metadate

Datele fișierului JSON sunt afișate sub forma unui tabel cu două coloane:

  • Câmp: numele cheii JSON
  • Valoare: valoarea corespunzătoare

Sunt afișate doar câmpurile de prim nivel din JSON. Câmpurile al căror nume începe cu _ (caracter de subliniere) sunt omise deoarece sunt rezervate pentru uz intern. Structurile imbricate, cum ar fi obiectele sau array-urile, apar ca text în coloana Valoare, nu ca niveluri extensibile.

Panoul din dreapta — previzualizare imagine

Dacă este găsită o imagine asociată, aceasta este încărcată cu aceleași funcții ca Vizualizatorul de imagini: zoom cu rotița mouse-ului, butoane +/−, Adaptați la fereastră, 1:1 și pan prin tragere.

Dacă nu este găsită nicio imagine asociată, panoul afișează „Nicio imagine corespunzătoare găsită”.

Afișarea și ascunderea panoului

  • Butonul „◄ Ascundere metadate”: ascunde panoul din stânga care conține metadatele
  • Butonul „► Afișare metadate”: restabilește panoul de metadate
