3. Depanare și întrebări frecvente

──────────────────── ──────────────────── ──────────────────── ────────────────────

❓ ÎNTREBĂRI FRECVENTE

🔵 P: Se blochează programul la încărcarea manifestului?

A: De obicei, cauza este expirarea conexiunii de rețea. Verificați:

  1. Verificați dacă conexiunea dvs. la internet funcționează deschizând o pagină de încredere în browser.
  2. Deschideți adresa URL IIIF în browser și copiați-o din nou din bara de adrese.
  3. Verificați dacă firewall-ul sau software-ul de securitate permite conexiuni ATK-Pro.
  4. Dacă utilizați o rețea proxy, verificați configurația rețelei sistemului de operare.

Dacă problema persistă, încercați cu o adresă URL diferită pentru a testa conexiunea IIIF

🔵 P: „Fișierul nu a fost găsit (404)” - ce înseamnă asta?

A: Adresa URL a manifestului nu este accesibilă. Cauze:

  • Adresa URL a expirat (portalul a fost actualizat)
  • Arhiva este temporar indisponibilă
  • Parametri URL incorecți (ID de manifest greșit)

Soluție: Verificați adresa URL în browser înainte de a lipi în ATK-Pro

🔵 P: Descărcarea foarte lentă sau întreruptă?

A: Încercați:

  1. Verificați stabilitatea rețelei dvs. Wi-Fi sau utilizați o conexiune prin cablu, dacă este disponibilă.
  2. Încercați o altă adresă URL publică IIIF pentru a vedea dacă încetinirea este legată de server.
  3. Reduceți sarcina alegând profilul de resurse Ușor.
  4. Dacă problema afectează doar un portal, așteptați și încercați din nou: serviciul de la distanță poate fi aglomerat sau temporar indisponibil.

🔵 P: Reconstrucția imaginilor este lentă — cum poate fi accelerată?

A: Viteza depinde în principal de răspunsul serverului IIIF, de dimensiunea imaginilor, de conexiune și de resursele disponibile pe computer.

  • Utilizați profilul Ușor pentru a reduce consumul de resurse sau Rapid numai pe sisteme adecvate.
  • Procesați registre cu mai puține pagini simultan dacă memoria sau rețeaua sunt sub presiune.
  • Rețineți că unele portaluri necesită acces secvenţial, indiferent de profilul ales.

🔵 P: Ieșirea PDF este coruptă sau nu se deschide?

A: Încercați:

  1. Păstrați o copie pentru diagnosticare, apoi eliminați sau redenumiți PDF incomplet.
  2. Reîncărcați înregistrarea de la Fișier de intrare → Deschide input și regenerează PDF.
  3. Verificați dacă destinația poate fi scrisă și are spațiu suficient pentru procesare.
  4. Verificați imaginile individuale generate pentru a înțelege dacă problema afectează numai PDF.

🔵 P: Cum folosesc fișierele TIFF pentru arhivare?

A: TIFF este format fără pierderi, perfect pentru stocare:

  1. Selectați TIFF dintre formatele de imagine.
  2. ATK-Pro salvează TIFF cu compresie fără pierderi LZW.
  3. Păstrați o copie pe suporturi separate și verificați periodic integritatea copiei de rezervă.
  4. Conservarea în timp depinde și de suporturi, copii și verificări de integritate, nu doar de format.

🔵 P: Pot procesa mai multe înregistrări în același timp (în paralel)?

A: Înregistrările dintr-un lot sunt procesate secvenţial. În cadrul unei singure înregistrări, paginile și tile-urile pot fi procesate în paralel în funcție de portal și profilul de resurse.

  1. Pregătiți un fișier de intrare cu toate înregistrările acceptate, una după alta.
  2. Selectați-l din Fișier de intrare → Deschide input.
  3. Începe o singură dată Ieșire → Proces.
  4. ATK-Pro continuă automat cu înregistrările ulterioare.

Exemplu: Dacă intrarea conține 5 înregistrări, ATK-Pro procesează automat:

  • Înregistrarea 1 (descărcare + reconstrucție)
  • Înregistrarea 2 (descărcare + reconstrucție)
  • ... până la Înregistrarea 5

Rezultatele sunt salvate în folderele configurate; nu trebuie să reporniți manual procesarea pentru fiecare înregistrare.

🔵 P: Fișierele sunt salvate exact unde?

A: Calea implicită:

  • Instalare standard: folder ATK-Pro/output în documentele dvs.
  • Modul portabil: folder output lângă executabil.

Puteți schimba destinația de la Setări → Selectați folderul de ieșire. Folderele implicite sunt create automat ori de câte ori este posibil.

🔵 P: De ce ATK-Pro raportează sau blochează o cale de ieșire?

A: Înainte de a crea fișiere, ATK-Pro verifică cea mai lungă cale așteptată pentru înregistrare. Rezumatul final distinge două situații:

  • Eroare de blocare: numele conține caractere ilegale, folosește un nume rezervat Windows, se termină cu un spațiu sau punct sau un segment depășește limita acceptată. Numai înregistrarea afectată este oprită și dosarul de lucru aferent nu este creat.
  • Notă de compatibilitate: calea este aproape de un prag conservator sau poate crea dificultăți cu aplicațiile Windows mai vechi. Procesarea poate continua, dar cel mai bine este să alegeți o destinație mai scurtă.

Profilul OneDrive/SharePoint se aplică numai atunci când folderul selectat se află de fapt sub o rădăcină OneDrive sau OneDrive - Organizzazione. Dacă apare o eroare, scurtați numele înregistrării sau alegeți un folder de destinație mai aproape de rădăcina unității; nu este necesar să redenumiți sau să mutați fișierele deja produse de alte procese.

🔵 P: Pot muta fișierele de ieșire după procesare?

A: Da, fișierele finale pot fi mutate după procesare.

După finalizare:

  1. Mutați folderul de înregistrare la noua destinație.
  2. PDF-ul final este autonom; păstrați, de asemenea, imaginile și metadatele dacă fac parte din arhiva dvs. de lucru.
  3. Dacă intenționați să reluați înregistrarea, păstrați manifestul și alte fișiere sursă.

🔵 P: Blocări bruște — ce trebuie făcut?

A: Dacă programul se blochează:

  1. Verificați atkpro.log sau, cu diagnosticarea extinsă activă, atkpro_debug.log. Locația depinde de tipul de instalare: căutați lângă executabil sau în directorul de lucru al aplicației.
  2. Copiați mesajul de eroare sau faceți o captură de ecran.
  3. Reporniți programul și repetați operația.
  4. Dacă eroarea reapare, încercați o altă înregistrare IIIF pentru a distinge o problemă generală de una specifică manifestului.

⚠️ ERORI FRECVENTE ȘI SOLUȚII

Eroare Cauza Soluție
„Expirarea conexiunii” Server IIIF lent/offline Încercați din nou cu o adresă URL diferită
„Format IIIF nevalid” Adresa URL nu indică un manifest IIIF Verificați adresa URL în browser
„Spațiu pe disc plin” Spațiu insuficient pe disc Eliberați spațiu pe unitate
„Permisiune refuzată” Dosar protejat/numai citire Alegeți un folder aparținând utilizatorului dvs. și verificați dacă acesta poate fi scris; Evitați folderele de sistem sau protejate.
„Adresa URL nu a fost găsită (404)” Manifestul IIIF a expirat Verificați ID-ul pe portal
„Fereastra nu răspunde” Procesare lentă/grea Așteptați sau faceți clic pe Anulare

🔵 P: Portalul este recunoscut, dar descărcarea este respinsă. De ce?

A: Compatibilitatea tehnică nu elimină condițiile de acces. ATK-Pro respinge sau restricționează resursele care necesită autentificare sau acces instituțional, nu expun un endpoint public stabil, sunt marcate nodownload sau nu au drepturi sau licențe compatibile cu operațiunea solicitată. Deschideți pagina publică a obiectului, verificați licența și termenii de utilizare și testați numai cu adresa URL oficială acceptată.

🔵 P: Pot recupera un lot OCR întrerupt?

A: Verificați folderul ales pentru OCR pentru fișier *_trascrizione_parziale.txt și metadate aferente. Acestea conțin lucrarea salvată progresiv, care trebuie verificată și finalizată înainte de a fi considerată definitivă.
