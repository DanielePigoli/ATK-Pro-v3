1 - التركيب والاحتياجات

────────────────────────────────────────────────────────────────────────────────

نظام التشغيل

  • Windows: Windows 10 or later (64-bit) - Professional, Home, Server
  • Linux: 20-04 + أو توزيعات متوافقة (حزمة ديب أو محفوظات من طراز تارغيس)
  • macOS: macOS 11 Big Sur or later - .dmg distribution (real equipment in progress)
  • 64-bit mandatory on all platforms
  • 2 GB على الأقل من طراز RAM متاح (4 GB الموصى بتجهيز دفعة)
  • 1 GB of free disk space

التركيب

Windows

  1. تحميل ATK-Pro-Setup-vx.x.x.exe من صفحة الإصدار الرسمي
  2. بقع مزدوجة في ملف (سلاتلر)
  3. "إختار "إحكام مع امتيازات الإدارة
  4. إتبعوا الساحر (المصدر التالي)
  5. وسيُطلب اختيار اللغة (20 متاحا) أثناء التركيب
  6. في النهاية، تحقق من (ستارت ATK-Pro) لبدء البرنامج
  7. تقبل أي تنبيه من Windows Firewall/Defender

Linux

  1. تحميل ATK-Pro-vx.x.x.deb (ديبيان/أوبونتو) أو .tar.gz من صفحة الإصدار
  2. حزمة ديب: sudo dpkg -i ATK-Pro-vx.x.x.deb أو نقر مزدوج في نوتيلوس/فايلز
  3. المحفوظات في الخارج ./ATK-Pro من الملف المستخرج
  4. يتم اختيار اللغة في البداية الأولى وإنقاذها في ملف تشكيلة المستخدمين

macOS

  1. تحميل ATK-Pro-vx.x.x.dmg من صفحة الإصدار
  2. افتح ملف (ديمغ) وسحب (زك كيوبرتمب) إلى ملف الطلبات
  3. في البداية: النقرة الصحيحة &quot; المفتوحة &quot; (اللازمة للتطبيقات غير المعلن عنها)
  4. يتم اختيار اللغة في البداية الأولى وإنقاذها في ملف تشكيلة المستخدمين

الوظائف المؤقتة

Windows

  • Program: C:\Program Files\ATK-Pro\
  • ناتج المستعملين: C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • المدخلات (اختيارية): C:\Users\[TuoNome]\Documents\ATK-Pro\input\

Linux

  • Program: /opt/ATK-Pro/ (د) أو مطوّر مستخرج (طر - ز)
  • ناتج المستعملين: ~/Documents/ATK-Pro/output/
  • المدخلات (اختيارية): ~/Documents/ATK-Pro/input/

macOS

  • Program: /Applications/ATK-Pro.app
  • ناتج المستعملين: ~/Documents/ATK-Pro/output/
  • المدخلات (اختيارية): ~/Documents/ATK-Pro/input/

الاحتياجات من الشبكات

  • اتصال إنترنت مستقر (إلزامي للوصول إلى بيانات IIIF)
  • الجدار الناري: يسمح بقطع وصلات نظام المعلومات الإدارية المتكامل (الوارد 443)
  • الوكيل (Proxy): لا تحتوي ATK-Pro على قائمة داخلية لإعداد الوكيل. اضبط الوكيل في نظام التشغيل أو بيئة الشبكة، وتحقق مع المسؤول من السماح باتصالات HTTPS بالبوابات.

تشكيلة الملف

عندما تركض أولاً، البرنامج يخلق تلقائياً الملفات التالية:

  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\doc\ (وثائق التقصير)
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\reg\ (سجلات العجز)
  • Linux/macOS: متشابهة أدناه ~/Documents/ATK-Pro/output/
  • Folder input\ analog (optional, for file input)

في الوقت الذي يتم فيه تجهيز الملفات المؤقتة لتنزيلها (الملفات)tiles_canvas_X/و، عند الاقتضاء، الملفات المؤقتة لجيلها.

وتحذف جميع الملفات والملفات المؤقتة تلقائيا في نهاية التجهيز.

تبقى الملفات النهائية المعالجة فقط (الصور بالتنسيقات المختارة وملفات PDF والبيانات الوصفية).

لتغيير ملفات النواتج تستخدم مينو ستينغز وتخزن الخيارات وتعاد تلقائيا إلى الدورة المقبلة.

موجز بيانات الموارد

القيادة Settings s Resource Profile ينظم التوازي المستخدم أثناء التنزيل، وإعادة بناء الصور، وتوليد PDF:

  • الوزن الخفيف: :: الحد من العمليات المعاصرة وذروة الذاكرة؛ والمبينة بالنسبة للحواسيب الأقل قوة أو التجهيز الطويل جدا.
  • الرصيد: :: حل توفيقي بين السرعة والاستقرار، مناسب لمعظم الحالات.
  • بسرعة: استخدام المزيد من الموارد لتقليص الوقت؛ واختياره فقط على الحواسيب بشكل جيد بما فيه الكفاية.

ولا يغير الملف نوعية أو حقوق أو كمية الوثائق التي يتم الحصول عليها. ولا تزال الحدود الحكيمة المحددة للبوابة لها الأسبقية.

مخطط النافذة

تتميز النافذة الرئيسية لـ Antenati Toolkit Pro ببنية بسيطة وبديهية.

:

  • [الل] Program icon (Antenati Toolkit Pro logo)
  • "ATK-Pro"
  • [] Reduce to icon (minimizes window)
  • D) Expand/Collassa (maximum or restore window)
  • اغلق البرنامج بشعار الدعم

والشعار اللاتيني &quot; كوي آنت نوفس &quot; ، إحياء لذكرى منا، يشير إلى أهمية الجذور والذاكرة الجماعية.

قائمة الطعام

في أعلى النافذة تحت الرأس

[مدخل الملف] [الناتج] [Services] [الصدور] [الجلسات]

وتتضمن كل قائمة أزرار وخيارات محددة (انظر الفرع التالي).

القائمة

1 - مدخلات الملفات

إدارة تحميل سجلات IIIF:

├─ Esempio input
│  └─ Visualizza il file di esempio (mostra formato coppie: modalità D/R + URL)
├─ Apri input
│  └─ Seleziona un file .txt con i tuoi record IIIF
│     (Deve contenere coppie: modalità D/R su riga 1, URL su riga 2)
└─ Modifica input
   └─ Modifica il file input attualmente caricato
      (Aggiungi/rimuovi record, cambia URL, salva modifiche)

2 - الناتج

تجهيز الطلبات والناتج:

├─ Elabora
│  └─ Avvia il download, la ricostruzione e il salvataggio delle immagini
│     (Mostra finestra di progresso in tempo reale)
├─ Apri cartella output
│  └─ Apre in Esplora Risorse la cartella con i file elaborati
└─ Visualizza elaborazioni precedenti
   └─ Lista dei record già elaborati

3 - الخدمات

قائمة الخدمات المتكاملة:

├─ Ricerca assistita AI
│  └─ Suggerisce portali, piste di ricerca e query genealogiche da verificare
├─ Visualizzazione Immagini
│  └─ Viewer immagini scaricate e/o PDF generati
├─ Visualizzazione Metadati JSON
│  └─ JSON originali e metadati (genealogici, tecnici, EXIF)
├─ OCR Avanzato
│  └─ Testi manoscritti ottocenteschi, latino ecclesiastico, tardo-medievali
├─ Traduzione OCR
│  └─ Traduzione automatica testi estratti nelle lingue selezionate
└─ Esportazione GEDCOM
   └─ GEDCOM, Gramps, Family Tree Maker, Ancestry, MyHeritage, WikiTree, etc.

4 - الوثائق

الحصول على الموارد والوثائق:

├─ Disclaimer - Clausole legali e termini d'uso
├─ Presentazione autore - Background dell'autore del progetto
├─ Presentazione progetto - Storia, motivazioni, roadmap di ATK-Pro
├─ Guida - Indice principale della guida modulare
└─ Informazioni - Versione, copyright, email di contatto

5 - البيئات

التشكيل العام للبرنامج:

├─ Cambia lingua
│  └─ Seleziona la lingua dell'interfaccia (richiede riavvio)
├─ Seleziona formati immagine
│  └─ Scegli tra PNG, JPG, TIFF e PDF (almeno 1 obbligatorio)
│     PDF può essere selezionato da solo o insieme ai formati immagine
│     La scelta viene memorizzata e pre-selezionata automaticamente alla sessione successiva
├─ Seleziona cartelle output
│  └─ Apre prima la scelta della modalità cartelle, poi le finestre di selezione:
│     • Cartella unica per tutti    → una sola cartella per documenti e registri
│     • Cartelle separate doc/reg   → una cartella per tutti i doc, una per tutti i reg
│     • Cartella per ogni record    → una cartella distinta per ciascun record
│     La modalità e le cartelle vengono memorizzate e ripristinate alla sessione successiva
├─ Esporta configurazione
│  └─ Salva le impostazioni attuali in un file
├─ Importa configurazione
│  └─ Carica un file di impostazioni precedentemente salvato (ripristina tutte le preferenze e percorsi)
├─ Verifica aggiornamenti
│  └─ Controlla la disponibilità di nuove versioni del programma
└─ Chiudi
    └─ Termina il programma (mostra banner di supporto PayPal.me)
