1. 取付けおよび条件

────────────────────────────────────────────────────────────────────────────────

オペレーティング システム

  • Windows: Windows 10以降(64ビット) — プロフェッショナル、ホーム、サーバー
  • Linux: Ubuntu 20.04+ または互換性のある配布 ( .deb パッケージまたは .tar.gz アーカイブ)
  • macOS: macOS 11ビッグサー以降 — .dmg分布(進行中の実際のハードウェア)
  • すべてのプラットフォームで64ビット必須
  • 利用可能なRAMの少なくとも2 GB(4 GBはバッチ処理のために推奨)
  • 1 GBの無料ディスクスペース

導入事例

Windowsの特長

  1. ダウンロード ATK-Pro-Setup-vx.x.x.exe 公式リリースページより
  2. インストーラファイルをダブルクリック
  3. 必要に応じて「管理者権限で除外」を選択します。
  4. ウィザード(次へ → 次へ → インストール)に従ってください
  5. インストール中に言語選択(20可)が要求されます
  6. 最後に、「ATK-Proを起動」をチェックしてプログラムを開始
  7. Windowsの防火壁/擁護者からの警報を受け入れて下さい

Linuxの特長

  1. ダウンロード ATK-Pro-vx.x.x.deb (Debian/Ubuntu) または .tar.gz リリースページから
  2. .debのパッケージ: sudo dpkg -i ATK-Pro-vx.x.x.deb または Nautilus/Files のダブルクリック
  3. .tar.gz アーカイブ: 外部からスタート ./ATK-Pro 抽出されたフォルダから
  4. 最初の起動時に言語を選択し、ユーザ設定ファイルに保存されます。

macOSの特長

  1. ダウンロード ATK-Pro-vx.x.x.dmg リリースページから
  2. .dmgファイルを開き、ATK-Proをアプリケーションフォルダにドラッグします
  3. 初回起動時:右クリック→[開く](未指定のアプリケーションに必要な)
  4. 最初の起動時に言語を選択し、ユーザ設定ファイルに保存されます。

デフォルト位置

Windowsの特長

  • プログラム: C:\Program Files\ATK-Pro\
  • ユーザー出力: C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • 入力(任意): C:\Users\[TuoNome]\Documents\ATK-Pro\input\

Linuxの特長

  • プログラム: /opt/ATK-Pro/ (deb) または抽出されたフォルダー (.tar.gz)
  • ユーザー出力: ~/Documents/ATK-Pro/output/
  • 入力(任意): ~/Documents/ATK-Pro/input/

macOSの特長

  • プログラム: /Applications/ATK-Pro.app
  • ユーザー出力: ~/Documents/ATK-Pro/output/
  • 入力(任意): ~/Documents/ATK-Pro/input/

ネットワーク要件

  • 安定したインターネット接続(IIIFマニフェストにアクセスするための必須)
  • ファイアウォール: アウトバウンド HTTPS 接続を許可 (ポート 443)
  • 企業プロキシ: ATK-Pro はプロキシの資格情報のための内部メニューを持っていません。 オペレーティングシステムまたはネットワーク環境でプロキシを設定し、HTTPS 接続がポータルに許可されている管理者に確認します。

📂 フォルダー構成

最初に実行すると、プログラムは次のフォルダーを自動的に作成します。

  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\doc\ (デフォルト文書)
  • Windows: C:\Users\[TuoNome]\Documents\ATK-Pro\output\reg\ (デフォルトレジスタ)
  • Linux/macOS: 下記のような ~/Documents/ATK-Pro/output/
  • フォルダ input\ アナログ(任意、ファイル入力用)

暫定フォルダの処理は、ダウンロードされたタイルのために作成されます()tiles_canvas_X/) そして、必要に応じて、PDF、その生成のための一時的なファイル。

処理終了時に、一時フォルダとファイルが自動的に削除されます。

最終的なファイルのみを処理する(選択した形式、PDF、マニフェスト、メタデータ)。

出力フォルダを変更するには、メニュー→設定→「出力フォルダの選択」を使用します。 選択肢は、次のセッションに自動的に保存され、復元されます。

PROFILOリソースプロファイル

コマンド 設定 → リソースプロファイル PDFのダウンロード、画像再構築および生成時に使用される並列性を調整します。

  • 軽量: 現代のプロセスとメモリピークを制限します。強力なコンピュータや非常に長い処理のために示されています。
  • バランス: ほとんどの場合のために適した速度および安定性間のデフォルト妥協。
  • 速い: より多くのリソースを使用して時間を減らします。 十分によくコンピュータでそれを選択します。

プロファイルは、取得された文書の品質、権利、数量を変更しません。 ポータルの特定のプルーデンシャル制限は、引き続き優先されます。

3. 主要なインターフェイス

────────────────────────────────────────────────────────────────────────────────

ウィンドウレイアウト

Antenati Toolkit Proのメインウィンドウには、シンプルで直感的な構造があります。

: テストされた凡例:

  • [🔲] プログラムアイコン(Antenati Toolkit Proロゴ)
  • 「ATK-Pro」ウィンドウタイトル
  • [ ] アイコンに縮小(ウィンドウを最小化)
  • D) 拡大/Collassa(最大または復元ウィンドウ)
  • [ja] サポートバナーでプログラムを閉じる

ラティナモットー “Qui ante nos venerunt, 私たちのvivuntのメモリで”, 根と集団的な記憶の重要性を思い出させます.

メニューバー

ウィンドウの上部に、頭の下に:

[ファイル入力] [出力] [サービス] [ドキュメント] [設定]

各メニューには、特定のボタンとオプション(次のセクションを参照してください)が含まれています。

メニュー

1. ファイル入力

IIIFレコードの読み込みを管理します。

├─ Esempio input
│  └─ Visualizza il file di esempio (mostra formato coppie: modalità D/R + URL)
├─ Apri input
│  └─ Seleziona un file .txt con i tuoi record IIIF
│     (Deve contenere coppie: modalità D/R su riga 1, URL su riga 2)
└─ Modifica input
   └─ Modifica il file input attualmente caricato
      (Aggiungi/rimuovi record, cambia URL, salva modifiche)

2. 出力

処理および出力を管理して下さい:

├─ Elabora
│  └─ Avvia il download, la ricostruzione e il salvataggio delle immagini
│     (Mostra finestra di progresso in tempo reale)
├─ Apri cartella output
│  └─ Apre in Esplora Risorse la cartella con i file elaborati
└─ Visualizza elaborazioni precedenti
   └─ Lista dei record già elaborati

3. サービス

統合サービスの一覧:

├─ Ricerca assistita AI
│  └─ Suggerisce portali, piste di ricerca e query genealogiche da verificare
├─ Visualizzazione Immagini
│  └─ Viewer immagini scaricate e/o PDF generati
├─ Visualizzazione Metadati JSON
│  └─ JSON originali e metadati (genealogici, tecnici, EXIF)
├─ OCR Avanzato
│  └─ Testi manoscritti ottocenteschi, latino ecclesiastico, tardo-medievali
├─ Traduzione OCR
│  └─ Traduzione automatica testi estratti nelle lingue selezionate
└─ Esportazione GEDCOM
   └─ GEDCOM, Gramps, Family Tree Maker, Ancestry, MyHeritage, WikiTree, etc.

4. 文書

リソースとドキュメントへのアクセス:

├─ Disclaimer - Clausole legali e termini d'uso
├─ Presentazione autore - Background dell'autore del progetto
├─ Presentazione progetto - Storia, motivazioni, roadmap di ATK-Pro
├─ Guida - Indice principale della guida modulare
└─ Informazioni - Versione, copyright, email di contatto

5. 設定

プログラムの一般的な構成:

├─ Cambia lingua
│  └─ Seleziona la lingua dell'interfaccia (richiede riavvio)
├─ Seleziona formati immagine
│  └─ Scegli tra PNG, JPG, TIFF e PDF (almeno 1 obbligatorio)
│     PDF può essere selezionato da solo o insieme ai formati immagine
│     La scelta viene memorizzata e pre-selezionata automaticamente alla sessione successiva
├─ Seleziona cartelle output
│  └─ Apre prima la scelta della modalità cartelle, poi le finestre di selezione:
│     • Cartella unica per tutti    → una sola cartella per documenti e registri
│     • Cartelle separate doc/reg   → una cartella per tutti i doc, una per tutti i reg
│     • Cartella per ogni record    → una cartella distinta per ciascun record
│     La modalità e le cartelle vengono memorizzate e ripristinate alla sessione successiva
├─ Esporta configurazione
│  └─ Salva le impostazioni attuali in un file
├─ Importa configurazione
│  └─ Carica un file di impostazioni precedentemente salvato (ripristina tutte le preferenze e percorsi)
├─ Verifica aggiornamenti
│  └─ Controlla la disponibilità di nuove versioni del programma
└─ Chiudi
    └─ Termina il programma (mostra banner di supporto PayPal.me)
